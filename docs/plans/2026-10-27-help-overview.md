## 方針

- **画面の写真は、アプリのテストの基準の写真から作る（作り物のデータ）。** 持ち主や利用者の PC で撮った写真は使わない（本物の議事録・名前・会社の情報が写るため。リポジトリは公開）。写真は明るい版だけ。
- **写真がアプリと食い違わない仕組み:** 記事で使う写真は、`help/assets/shots/` に置き、「元にしたテストの写真の名前」と「指紋（SHA-256）」を1つの表（`help/shots-from-app.json`）に書く。テストで「元の写真の指紋と今のアプリの基準の写真の指紋が同じ」を見る。アプリの画面が変わって基準を撮り直したら、このテストが赤になり、ヘルプの写真も撮り直しを忘れない（RF51 と同じ考え）。
- **写真に印を付ける:** 「ここを押す」は、写真に番号の丸（①②）と細い枠を足した SVG で示す（写真は PNG のまま埋め込み、印だけ SVG の線で描く。ヘルプの白黒の決まりに合わせ、印の色は黒の枠と黄色の地の番号だけ）。
- **仕組みの図は手で描く SVG:** 「PC の中（NaTsu・議事録の保存）／NaTsu のサーバー（中継）→ OpenAI（文字起こし）／ご自分の Claude Code → Anthropic（要約）／Claude デスクトップ（MCP で読む）」の流れを箱と矢印で描く。文字は SVG の中に書かず、図の下の番号つきの説明（読み上げ・検索・翻訳で読める）と対にする。白黒・線の太さで強調（DADS の決まり）。

## Review Focus（起きそうで、まだテストの無い失敗）
