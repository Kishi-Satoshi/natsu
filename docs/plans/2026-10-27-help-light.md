## 持ち主の頼み（2026-10-27。そのまま）

「NaTsuヘルプセンターのデザインですが、ダークモードとWindowsシステムに合わせるはやめて、ライトモードのみにしたいです。」（暗い版のヘルプセンターの画面を添えて）

## 目的・方針

- **目的:** ヘルプセンター（`natsu-help`。アプリとは別のサイト）は、Windows の設定が暗いときでも、いつも白地の明るい版で出す。
- **方針:** 色の札は今の明るい版の値（DADS の札）のまま使い、暗い版の札の上書きだけを外す。見た目を新しく作らない。アプリの外観（設定の「外観」の システム・ライト・ダーク）は変えない。ヘルプの記事の「外観」の説明（`help/articles/settings/appearance.md`）はアプリの話なので変えない。

## 出し方

ヘルプセンターはアプリの版と別に出す（`help-deploy` は `main` にヘルプの変更が入ったときに走る）。`main` への push は持ち主のはっきりした言葉があるときだけ（HL3）。アプリの版の番号と CHANGELOG は動かさない。

## Review Focus（起きそうで、まだテストの無い失敗）

1. 暗い版の札を外しても、どこかの規則が暗い色の値を直に書いていて、白地に暗い面が残る → 「`help.css` に `#111111`・`#1f1f1f`・`#3d3d3d` が無い」のテスト。
2. `color-scheme` が `light dark` のまま残り、Windows が暗いと検索の箱やスクロールバーだけ暗くなる → `:root` の `color-scheme` の値を見るテスト。
3. 門のページだけ暗いまま残る（HL1）→ 門のテスト。
4. 撮る画面の指紋（`help/shots.json` の `css`）を撮り直さず、`help-deploy` の確かめが落ちる → HL-3 で撮り直す。
5. キーボードの輪が暗い版の白のまま残る → 輪は明るい版の黒＋黄色だけ、のテスト。

## 持ち主の試作から参考にしたこと

持ち主の試作（2026-10-17 の `db-server.js`・`main.js`・`preload.js`・`state-store.js`・`README.md`）を読み直した。ヘルプセンターの見た目の話で、試作に当てはまる考えは無い（試作は保存とプロセスの作り）。強いて言えば、試作の `state-store.js` の「既定の値を1か所に持ち、上書きを足すだけ」の考えに合わせ、色の札は `:root` の1か所だけにし、上書きの塊を外す形にした。
