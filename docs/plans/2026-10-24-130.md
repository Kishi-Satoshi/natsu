## 目的

1. **（E1）行の左の ⠿ と ＋:** 行にマウスを乗せると左に ＋ と ⠿ が出る。＋ は下に行を足して `/` メニューを開く。⠿ はドラッグで並べ替え、押すと「削除・複製・変換」のメニュー（右クリックでも同じメニュー）。
2. **（E2）`/` メニュー:** 行頭か空白の後の `/` で出る。「みだし」「todo」「h1」でも絞り込める。↑↓・Enter・Esc で選ぶ。
3. **（E3）行頭の記法:** `- `・`* `・`+ `→ 箇条書き、`[] `→ ToDo、`1. `→ 番号付き、`# `・`## `・`### `→ 見出し 1〜3、`" `→ 引用、`---`→ 区切り線（`> ` の行き先は EQ10）。打った時点で変わる。文中の飾り（`**太字**`）は第2b回。
4. **（E4）分割と結合:** Enter はカーソルの位置で行を分け、Shift+Enter は行の中の改行。行頭の Backspace は、型の付いた行ならまずテキストに戻し、テキストの行なら前の行と結合する。↑↓ で隣の行へ移る。描き直すのはその行だけ。
5. **（E5）新しい型:** 見出し 1〜3（古い見出しは 2）・番号付き・引用・区切り線・コールアウト（0.13.0）、トグル・トグル見出し（0.13.1）。［コピー］の Markdown と Claude から読む文（MCP）も新しい型を写す。
6. **（E10。0.13.1）入れ子:** Tab と Shift+Tab で字下げする。トグルを ▸ で開閉し、Ctrl+Alt+T ですべて開閉する。ドラッグで中へも移せる。
7. **（E11）近道:** Ctrl+Shift+0〜7（テキスト・見出し 1〜3・ToDo・箇条書き・番号付き・トグル）・Ctrl+D（複製）・Ctrl+Shift+↑↓（動かす）・Ctrl+Enter（ToDo のチェック・トグルの開閉）・Ctrl+/（行のメニュー）。
8. **（RF9）録音中の Esc:** 音声入力や会議を録っている間でも、NaTsu の窓で `/` メニューを開いていれば、Esc はメニューを閉じるだけ。
9. **壊さない:** 出典（`cite.js` は変えない）・要約の欄の鍵・ToDo の担当と期限・アクション一覧・MCP・検索・0.11.0 の並べ替えと印と打ち合わせの質・0.12.0 の文字起こし・0.12.1 の会議を出たら止める動きが、今と同じに動く。古いページは開いても変わらない。

## 決めたこと（0.13.0・0.13.1。理由つき。違う答えなら直す）

**A. 分け方と編集する所**

1. **新しい編集は要約の欄だけ**（EQ2 (a)）。メモ（`<textarea>` の欄 `memo`）と文字起こしの行は今のまま。理由: メモは 0.11.0 の雛形・録音中のメモ・下書き・MCP の箇所の区切り・要約への入力の柵が「文字」を前提にしていて、ブロックにすると 0.11.0 の大半を作り直す。文字起こしは0.12.0 の文ごとの行と出典の印が `segments` の ID に頼る。会議でないページは第5回まで無い。
2. **0.13.0 は平らな行の編集、0.13.1 は入れ子とトグル**（EQ1 (a)）。0.13.0 では読む所（出典・アクション一覧・MCP・一覧・［コピー］・0.11.0 の並べ替え）は平らな並びのまま。0.13.1 で `children` を組み立て、読む所の全部に「木を平らにしてから読む」を入れる（設計書「素の文字の使い道」の「照合の前に木を平らにする」）。トグルは子が無いと意味が無いので 0.13.1。
3. **版の番号:** 分けたら 0.13.0 と 0.13.1（後の回の番号をずらさない。0.10.1 と同じく、patch の番号で機能を出す）。

**B. 保存の形（第2a1回で決めた形の上に。表の形の版は上げない）**

4. **型の欄:** 型は `type`。見出しの段は `attrs.level`（1〜3）、トグル見出しは `attrs.toggle: true`（0.13.1）、コールアウトの絵文字は `attrs.icon`、トグルの開閉は `attrs.open`（0.13.1。EQ18）。番号付きの番号は保存しない（描くときに、同じ親の続いた番号付きの行を数える。間に別の型が入れば 1 から）。
5. **見出しの段:** `markdownToBlocks` は `#` → 1・`##` → 2・`###` と `####` → 3 を `level` に書く（設計書「見出しの段数」）。段の無い見出し（今までの全部の要約）は、読むときに段 2 として扱い、データは書き換えない。**段 2 の見た目は今の `.blk.heading` と1画素も変えない**（今の撮る画面が変わらない）。段 1 は大きく、段 3 は小さく。
6. **知らない型:** 画面は知らない `type` の行を消さずに「テキスト」の見た目で描き、文を直せる（型は変えない）。MCP と［コピー］も文だけを写す。
7. **（0.13.1）木:** `loadPage` は `parent_id` から `children` を組み立て、`page.blocks` は最上位の行の並び（子は `children`）。`diffPage` は木を平らにして比べ、親が変わったら `move` の操作に `parent`・`oldParent` を足す（後ろへ当てれば前の親と鍵に戻る）。行を消すと子も一緒に消える（`trash` の操作を子の分も積む）。表の形の版は上げない（`parent_id` は v1 からある）。
8. **`rich`:** この回は飾りを作らない（第2b回）。行の `rich` はそのまま通し、分割と結合では `rich` の区切りも同じ位置で分ける・つなぐ（純粋な `splitRich`・`joinRich`。今の要約に `rich` は無いので、テストの種だけで確かめる）。
9. **画面の役の型の照らし:** `block.insert`・`block.turnInto`・`block.update` の `patch.type` は `BLOCK_TYPES` の鍵だけを通す（ほかは `bad-args`）。main の役の `page.put`・`meeting.*` は今の `NAME_RE` のまま（AI の要約は4つの型だけを書くが、新しい版が書いた型を古い版で壊さないため）。

**C. 命令（1つの動作＝1つの命令＝1つのトランザクション＝ `oplog` の1行。持ち主の試作）**

10. **新しい命令（役 `app` と `main`）:**
    - `block.split { pageId, blockId, text, at }` → 今の行の文を `text`（画面の今の文）にしてから `at` で分け、前を今の行・後ろを新しい行（すぐ下）にする。新しい行の型は EQ5 の表で決める。答えは `{ page, blockId }`（新しい行の ID）。同じ `tx` を送り直しても行は1つしか増えない（今の `block.insert` の `dupResult` の形）。
    - `block.merge { pageId, blockId, text }` → 今の行の文を `text` にしてから、すぐ前の文のある行の後ろにつなぎ、今の行を消す。答えは `{ page, blockId: つないだ先, at: つないだ所 }`（画面はそこへカーソルを置く）。前の行が区切り線なら区切り線を消すだけ（決めたこと 17）。前に行が無ければ何もしない。
    - `block.turnInto { pageId, blockId, type, level?, toggle? }` → 型を変える。文と `cites`・`assignee`・`due`・`checked`・`mark` は消さずに残す（見えなくなるだけ。戻せば見える）。区切り線へは文も子も無い行だけ（EQ16）。
    - `block.duplicate { pageId, blockId }` → すぐ下に写しを作る（0.13.1 からは子も新しい ID で）。答えは `{ page, blockId }`。
    - `block.insert` に `type` の照らし（9）と `level`・`icon` と `parentId`（0.13.1）を足す。今の `afterBlockId` の形はそのまま。
    - `block.move` に `{ afterId, parentId? }` の形を足す（`afterId` が `''` なら親の頭）。今の `toIndex` の形も受ける（古い画面の頼みのため）。
    - （0.13.1）`block.indent { pageId, blockId, dir: 'in' | 'out' }`・`block.setOpen { pageId, blockId, open }`・`block.setOpenAll { pageId, open }`。
11. **画面の今の文を命令に入れる:** Enter・Backspace・型の変換・複製・動かす、のどれも、編集中の行の今の文を同じ命令で送る（分割・結合は `text`、ほかは命令の前に `_commit` を待つ）。打つたびには書かない（blur・別の行へ移る・構造の命令のとき）。
12. **鍵:** 新しい命令はどれも `editPage(…, { summary: true })` を通る（要約の欄の鍵なら `locked`。0.11.0 の印のある行も鍵の間は直せない）。分割した後ろの ToDo は担当・期限を持たない（0.11.0 の「要確認」の札が出る）。
13. **印と出典:** 分割・結合は文を変えるので、今の `block.update` と同じに `citeState` を `stale`（`manual` なら `manual` のまま）にし、0.11.0 の `mark`・`unconfirmed` を消す。分割した後ろの行・＋ で足した行は人の行（`citeState: 'manual'`・`cites: []`）。結合したときの出典は前の行のものを残す（後ろの行の出典は捨てる。文が変わったので `stale`）。型の変換は文を変えないので印も出典も残す（箇条書きと ToDo 以外ではチップが見えないだけ。設計書の「消える（許容）」を「見えなくなる」と読んだ）。**（2026-10-25 に足した）** ただし `citeState` を持たない行（AI の見出し・テキストの行。`cite.js:283` が照らさない型）を、見出し以外の型から変えたら `citeState: 'manual'` にする（人が型を決めた行。`pagerules.citeStatOf: src/pagerules.js:82` の分母に入れず、「根拠なし」でなく「手書き」の札。見出しの段の付け替え（見出し → 見出し）では付けない）。変異 `ed-turn-manual`。
14. **命令の数と表:** preload の `APP_COMMANDS` と DB の役 `app` の命令の表に足す。画面へは `koeApp.blockSplit`・`blockMerge`・`blockTurnInto`・`blockDuplicate`（0.13.1 で `blockIndent`・`blockSetOpen`・`blockSetOpenAll`）の名前で出す（今の 14 の名前と同じ形）。`natsuDb.call` を画面に出すのは第2b回（「元に戻す」で命令を汎く呼ぶとき）にする。`json-backend`（今の JSON の保存の答えの比べ相手）には新しい命令を足さない（`unknown-cmd`）。

**D. 画面の動き**

15. **カーソルの位置は1か所の継ぎ目で読む:** `caretOf(el)`・`setCaret(el, n)`（本物の DOM では `getSelection`・`Range`。文の UTF-16 の位置）。偽の DOM（`simrun`）には `getSelection` を足さず（本物の動きを偽ると嘘の緑になる）、テストの台が継ぎ目を差し替える（`simrun` の `caret` の旗）。位置は `Intl.Segmenter` で書記素の境に寄せる（「𠮷」・絵文字・結合文字の途中で分けない）。DB も `at` がサロゲートペアの間なら断る。
16. **Enter と Shift+Enter と Backspace（EQ5・EQ6）:** 変換確定の Enter（`imeEnter`）は何もしない。Enter は `block.split`。Shift+Enter は行の中の改行（文に `\n`。描くときは `white-space: pre-wrap`、読むときは改行を保つ）。行頭（`caretOf` が 0）の Backspace は EQ6 (a)（型の付いた行はテキストに戻す（`block.turnInto`）、テキストの行は `block.merge`）。空の箇条書き・ToDo・番号付きでの Enter は、EQ5 (a) でテキストに戻す（0.13.1 からは字下げされていればまず戻す）。
17. **区切り線:** 文も ⠿ 以外の部品も持たない行（フォーカスはできる）。区切り線の次の行の頭で Backspace を押すと、区切り線を消す（`block.merge` の中で）。区切り線にフォーカスして Enter を押すと下にテキストの行を足す。
