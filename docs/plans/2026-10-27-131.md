## 目的

1. **（E10）字下げ:** 要約の行で Tab を押すと前の行の子になり、Shift+Tab で1段戻る。字下げできないときの Tab は何もしない（EQ17 (a)）。行の中で Esc を押すと ⠿ へ出て、そこから Tab で欄の外の次の部品へ行ける（決めたこと 25）。
2. **（E5・E10）トグル:** 行の頭で `> ` と打つか、`/` メニューの「トグル」で、▸ で中を開け閉めできる行を作る（EQ10 (a)）。見出しもトグル見出し1〜3にできる。開け閉めは議事録に覚え、次に開いても同じ（EQ18 (a)）。Ctrl+Enter で今のトグルを、Ctrl+Alt+T でページのトグルをまとめて開け閉めする（EQ19 (a)）。
3. **（E10）中へのドラッグ:** ⠿ を引っ張って右へずらして落とすと、上の行の子になる。左へずらすと浅い段に落とせる（NR12）。
4. **（E11）近道:** Ctrl+Shift+7（トグル）を足す。Ctrl+Enter はトグルの開け閉めにも効く。
5. **読む所:** 出典・一覧のまとめ・アクション一覧・Claude から読む文（MCP）・［コピー］・0.11.0 の並べ替えが、子の行も読む（閉じたトグルの中の ToDo もアクション一覧に出る）。`cite.js` は変えない。

## 実機で利用者に見てもらうこと（0.13.1 を出した後。Windows x64・JIS のキーボードと Microsoft IME・拡大 100／150／200%）

1. **字下げ:** 要約の箇条書きで Tab → 上の行の中に入る。Shift+Tab で戻る。いちばん上の行・区切り線の下の行では Tab で何も起きない。日本語入力のオンとオフの両方。
2. **キーボードで欄から出る:** 行の中で Esc → 行の左の ⠿ が見えてフォーカスが乗る → Tab で要約の欄の外へ出る（次の行に入らない）。Shift+Tab で［AI 要約］のタブへ。
3. **トグル:** 行の頭で `> ` と打つとトグルになる。▸ と Ctrl+Enter で開け閉めし、別のページを開いて戻っても同じ形。Ctrl+Alt+T でまとめて開け閉め。`/` で「とぐる」「とぐるみだし」。閉じたトグルの中の ToDo がアクションのタブに出る。
4. **Enter と Backspace（入れ子の中）:** 子の行の頭で Enter → 空の行がその行のすぐ上の同じ段に出る。字下げした空の箇条書きで Enter・Backspace → まず段が戻る。子のある行の終わりの Enter → 新しい行が最初の子に出る（TQ3）。子のある行の下の行頭の Backspace → 画面で上に見えている孫の行の終わりにつながる（TQ1）。
5. **ドラッグ:** ⠿ を引っ張って右へずらして落とす → 上の行の中に入る。子の後ろで左へずらす → 親と同じ段に入る。落とす線の左の端が段を示す。
6. **［コピー］と Claude:** 入れ子とトグルのある要約を［コピー］して Teams・Word に貼る（子は下がって出る）。Claude に「この議事録を読んで」と頼むと子も出る。

**TQ3（子が見えている行（開いたトグル・子のある箇条書き）の終わりで Enter を押したとき、新しい行をどこに出すか）と TQ4（新しく作ったトグルを開いた形で作るか、閉じた形で作るか。開け閉めは議事録に覚える（EQ18 (a)）ので、これはまだ一度も開け閉めしていないトグルの形）:** 2つは一緒に聞いた。

**TQ5（見出しをトグル見出しに変えたとき、その見出しの下の行を中へ入れるか）:**
- **答え: 入れない（下の行はそのまま）。** 中へ入れるのは Tab かドラッグで1行ずつ。理由: 型の変換で行の並びが動かず、行って戻っても同じ。0.11.0 の並べ替えとぶつからない。失うもの: 節をたたむには行を1つずつ Tab で入れる（0.14.0 の複数の行の選択でも、まとめて字下げはしない: 0.14.0 R19）。
