## 目的・方針・使うもの・覆う設計書の項目

**目的（利用者から見て）**
1. **（E6）文字の飾り:** 要約の行の文字を選ぶと道具の帯が出て、太字・斜体・下線・取り消し線・コード・文字の色と背景の色・リンクを付けられる。Ctrl+B／I／U・Ctrl+Shift+S・Ctrl+E・Ctrl+K（文字を選んでいるとき）。`**太字**` などを打った時点でも変わる。行（ブロック）ごとの色も ⠿ のメニュー・Ctrl+/・`/` で付けられる。

## 決めたこと（理由つき。違う答えなら直す）

**A. 元に戻す・やり直す（E7）**

1. **戻すのは要約の欄の操作だけ:** `block.*`・`blocks.*`・`block.paste`・`edit.revert`（0.13.1 の `block.indent` も。`block.setOpen`・`setOpenAll` は入れない: P6）。題名・メモ・文字起こしの行・会議の種類は今のまま（入力の欄の中の戻し）。理由: 新しい編集は要約の欄だけ（EQ2 (a)）。
2. **1歩＝1命令（設計書 E7）。** 画面が1つの動作で続けて送った命令（記法の `---` の「変換＋下に行を足す」・型を変える前の打った文の保存）は、1つの歩みにまとめる（`stepGroup`）。DB の命令 `edit.revert { pageId, steps }` は渡された tx の行を**新しい順に後ろから当て**、1つのトランザクション・`oplog` の1行（`action: 'edit.revert'`・後ろへ当てた操作）にする。やり直しは「戻した行（`edit.revert` の行）をもう一度戻す」で、同じ命令を使う。
3. **戻せるのは自分の行だけ:** `edit.revert` は役 `app` だけが呼べ、渡された tx の行が (呼んだ役, tx) で見つかり、`actor` が `me`・`page_id` が `pageId`・`action` が戻せる命令（1 の表）であるものだけ。どれか1つでも違えば `bad-args`。Claude・MCP・main の行（要約の書き戻し・出典の付け直し）は戻さない（設計書 E7）。
4. **後から変わっていたら戻さない:** 当てる前に、戻す操作の「後の値」が今の DB と同じかを1つずつ見る（`opsMatch`）。1つでも違えば何も変えずに `stale`（新しい断りの符号。`retry` は偽）。画面はそのページの列を空にして「ほかの所で変わったので、元に戻せませんでした」と出す（中途半端に戻さない）。理由: ［要約を再生成］・文字起こしを直した後の出典の付け直し・後の版の Claude の書き込みを、古い歩みで上書きしない（F100）。
5. **ページの行の `updatedAt`・`citeStat` は戻さず作り直す:** 戻す操作からページの行の `set` を外し、ブロックを後ろへ当てた後に今の `saveOps` と同じに作り直す（直した時刻は「今」・出典の数は今の行から）。
6. **画面が歩みの tx を知る道:** DB の答えに `changed: true`（真偽だけ。何か変えたときだけ）を足し（`server.js:153`）、preload は戻せる命令の答えが `ok` で `changed` のときだけ、画面の受け口 `koeApp.onEditStep(cb)` に `{ cmd, pageId, step: tx }` を渡してから答えを返す。読む命令・断られた命令・何も変えなかった命令は渡さない（何も変えない命令を戻す1歩にしない: 試作の節）。`natsuDb.call` は画面に出さない（R34）。
7. **列は窓のメモリ・ページごと（BQ1 (a) の形で書いた）:** `undoBook`（純粋）が `pageId → { undo: [], redo: [] }` を持つ。1ページ 100 歩まで（古いものから捨てる）。新しい歩みが入るとそのページのやり直しは空。NaTsu を終える・画面を読み直すと消える（設計書 E7「窓ごとのメモリ」）。
8. **打った文字の区切り（設計書 E7）:** 打った文は今どおり blur・別の行へ移る・構造の命令の前に保存し、**それに加えて打つ手が 2 秒止まったら保存する**（`TYPE_PAUSE_MS`。日本語の変換の候補選びと短い迷いで歩みが細かくなりすぎないように決めた NaTsu の値。実機 4 で使いにくければ直す）。変換中（`compositionstart`〜`compositionend`）は数えない。1回の保存が1歩。
9. **打っている途中の Ctrl+Z:** 行に保存していない文があれば、先に保存して（1歩）、その歩みを戻す（行は前に保存した文に戻る）。何も打っていなければ、そのページの最後の歩みを戻す。
10. **記法で変えた直後の Ctrl+Z:** 型を戻し、打った記号（`- `・`## ` など。インラインの `**` も）を行の頭（その所）に戻す（打った文として次の区切りで保存）。公開の資料に無い（notion-behavior Q-04）ので Ruling（R6）。
11. **キー:** Ctrl+Z（戻す）・Ctrl+Shift+Z と Ctrl+Y（やり直す。設計書 E7）。受けるのは開いているページの要約の欄（行の文・選んだ行・⠿・道具の帯）にフォーカスがあるときだけ。変換中は何もしない（`imeEnter`）。メモ・題名・文字起こし・設定・検索の窓の中では、今どおり入力の欄の中の戻し。
12. **戻せないとき:** 列が空なら「これ以上は戻せません」（やり直しは「やり直せるものはありません」）を左下に一度。要約の欄の鍵（録音中の写し・要約を作っている間）なら `locked` で何もしない（鍵の一言が出ている）。控えを回して `oplog` の行が消えていたら `stale` と同じ扱い。
13. **［要約を再生成］（BQ2 (a) の形で書いた）:** 作り直しは戻せない。押して作り直しが済んだら（`page:updated` か答え）、そのページの列を空にする。

**B. 文字の飾り（E6）**

14. **`rich` の形（第2回「保存の形」の上に。表の形の版は上げない）:** 1つの区切りは `{ t: 文字, m: [飾り] }`。飾りは `'b'`・`'i'`・`'u'`・`'s'`・`'code'` と `['color', 色]`・`['bg', 色]`・`['link', 住所]`。色は `COLORS`（`gray`・`brown`・`orange`・`yellow`・`green`・`blue`・`purple`・`pink`・`red`。BQ3 (a) の形）だけ。文字の色と背景の色は1つの区切りに両方持てる（R9）。並びは決まった順に整え、隣の同じ飾りの区切りは1つにする（`normalizeRich`）。飾りの無い行は `rich` を持たない（`null`）。
15. **DB の照らしを強める:** `validate.richText` が `color`・`bg` の値を `COLORS` で、`link` を `richText.linkOk`（`http(s)://`・`mailto:`・`natsu://page/`・0.10.0 のリンクの頭）で照らす（全部の役。AI は `rich` を書かないので今の要約は変わらない）。`code` と `link` は同じ区切りに持てない（コードの中のリンクは開かない）。
16. **文と飾りを食い違わせない:** `block.update` は `patch.rich` を保存する（`text` は `rich` から作る。今の `retext` と同じ印と出典の決まり）。**`rich` を持つ行に `text` だけの直しが来たら `bad-args`**（黙って飾りを捨てない・ずらさない。画面はいつも `rich` を送る）。`block.split`・`block.merge` は画面の今の `rich` を引数 `rich?` で受け、それで分ける・つなぐ（今の行の飾りを捨てない）。
17. **画面の描き方と読み戻し:** 行の文の欄は `rich` から `span` を `createElement` と `textContent` で作る（`richNodes`。`innerHTML` を使わない）。打った後は欄の子から `rich` を読み戻す（`richFromNodes`。知らない要素は文字だけにする）。打った文字は、カーソルの前の文字の飾りを引き継ぐ（コードとリンクの終わりでは引き継がない）。Chromium の既定の太字など（Ctrl+B・I・U）は `preventDefault` で止め、こちらの決まりで付ける。
18. **飾りの付け方:** 選んだ所に `toggleMark`（全部に付いていれば外す・どこか無ければ付ける）。Ctrl+B・I・U・Ctrl+Shift+S・Ctrl+E。打って変える記法（M-10〜M-13）は `**文字**`・`*文字*`・`` `文字` ``・`~文字~`（半角の記号だけ: R10）。閉じた記号を打った時に変え、記号は消す。
19. **道具の帯:** 1つの行の中で文字を選んだら、選んだ所の上に `role="toolbar"` の帯（太字・斜体・下線・取り消し線・コード・リンク・色 ▸）。押してもフォーカスと選んだ所は行に残す（`mousedown` を止める）。キーボードの人は近道を使う（ボタンに `aria-keyshortcuts`）。AI の項目は置かない（BQ4 (a)）。
20. **リンク:** Ctrl+K（文字を選んでいるとき）か帯の［リンク］で小さな欄（`#linkPop`）を出し、住所を貼って Enter。照らしに外れれば「開けるのは https・http・mailto と NaTsu のリンクだけです」。選んだ文字の上に URL を貼っても（K-25）リンクになる。リンクの文字は Ctrl を押しながらクリックで開く（ふつうのクリックはカーソルを置く: R11）。乗せると `title` に住所。開くのは main の新しい口 `app:open-link`（`http(s)`・`mailto` は照らしてから `shell.openExternal`、NaTsu のリンクは今の `parseLink` の道でページを開く。ほかは開かずに記録に符号だけ）。

**C. 貼り付けの変換（E8・SEC2）**

**E. SEC2（他人の内容の扱い）**

**F. 窓の中の近道（U3）**

35. **既定のメニューを外す:** main が起きたときに `Menu.setApplicationMenu(null)`（R24）。理由: 既定のメニューの「閉じる」（Ctrl+W）・「元に戻す」（Ctrl+Z）・「読み直す」（Ctrl+R）が、この版の近道と元に戻すを横取りする（調べた結果 5）。コピー・貼り付け・全部を選ぶは Chromium の入力の欄が自分で受ける（EK-5 の頭と EB-3 で Windows の `electron-smoke` で確かめる）。拡大は今どおり main の `before-input-event`。
36. **Ctrl+W:** 選んでいるタブを `closeTab` で閉じる（録音中のタブは閉じずに「録音中のページは閉じられません（［■ 終了して作成］で止めます）」・録音の前のページは RD14 の確かめ）。タブが1つだけのときは BQ7 (a) の形（閉じて空のページ。窓は閉じない）。設定のポップアップの間は何もしない。
37. **Ctrl+Shift+N:** BQ8 (a) の形（サイドバーの［＋ 新しい議事録］と同じ `openReady`。録音中は何もしない）。
38. **近道の一覧を設定に（U3）:** 純粋な表 `src/shortcuts.js` の `SHORTCUTS`（キー・動き・効く所）を1か所にし、設定の［一般］の「ホットキー」の下に読むだけの表「NaTsu の窓の中の近道」として出す。ヘルプ `settings/hotkeys` と `summary/edit-summary` の表は同じ表と一字ずつ照らす（`help-content` のテスト）。0.13.0 の近道（E11）・この回の近道・Ctrl+\・Ctrl+P などを全部載せる。

**G. ページの中の音声入力（U4）**

39. **キー:** 設定の新しいキー `pageDictateHotkey`（既定 `Control+Alt+V`。設定の［一般］の「ホットキー」の3つ目「ページの中の音声入力」）。全体のホットキーにはしない（窓の中だけ。画面の `keydown` で受ける）。2つの全体のホットキーと同じ組は断る（JS6 の照らしの表に足す）。Ctrl+Shift+Space は既定にしない（U4）。
40. **入る所（BQ9 (a) の形）:** 要約の行の文（区切り線と鍵の間は除く）とメモの欄（保存した議事録・録音の前のページ・録音中のページ）。押したときのカーソルの所（行の ID と位置、メモなら `selectionStart`〜`selectionEnd`）を覚え（`dictAt`）、口述の文はそこへ入れる。題名・文字起こし・設定・検索では何もしない。
41. **始める・止める:** 押すと `koeApp.dictateInPage()` → main は今の `startRecording()` を、引数を足さずに、前に置く変数 `dictTarget = 'page'` で始める（録音バーは今と同じ）。もう一度押す・全体の音声入力のホットキー・録音バーの停止で止める。変換中（`imeEnter`）は始めも止めもしない。議事録の録音中は BQ10 (a) の形（始めずに「議事録の録音中は、ページの中の音声入力は使えません」）。
42. **文の渡し方:** `handleDictationAudio` の `deliver` が `dictTarget === 'page'` のときは `deliverText` を呼ばず（**クリップボードを通さない**）、`sendToMainWin('dictation:text', { text })` を送る。履歴には今どおり入る。画面はカーソルの所に打った文として入れ、すぐ保存する（要約の行は `block.update` の1つの命令＝1歩。0.13.0 の申し送り。メモは今の 500ms の保存）。入れる所の行が消えた・ページが替わった・窓が閉じていたら入れず、「入れる所が無くなったので、音声入力の履歴に残しました」（R27）。変換中に文が届いたら `compositionend` まで待つ（R28）。
43. **Esc:** ページの中の音声入力の録音中に Esc を押すと、`/` メニュー・⠿ のメニュー・道具の帯・リンクの欄が開いていればそれだけを閉じる（0.13.0 の決めたこと 30〜32・RF9）。何も開いていなければ音声入力を取り消す（R29）。窓が前に無いときは今どおり全体の Esc で取り消す（`syncEscapeHotkey` は変えない）。

**H. ページが替わるとき・書き直している途中**

44. **`summaryBusy()` に足す:** 道具の帯・リンクの欄・色のメニューが開いている・行を選んでいる・ページの中の音声入力が入る所を覚えている、も「書き直している途中」（EQ22 (a)。保存した議事録を前に出さない）。`flushEdits` は帯・欄・選びを閉じる（0.13.0 の決めたこと 41 と同じ）。

### 3. 持ち主にしか決められないこと（BQ1〜BQ12。おすすめを先頭に）

**BQ1 元に戻すは、ページごとですか？**
- **(a) おすすめ: ページごと。** 開いているページの直前の操作から戻します。ほかのページへ移って戻ってきても、そのページの分は NaTsu を終えるまで残ります。理由: Notion の「ページでの直前の操作を取り消す」と同じで、見ていないページを Ctrl+Z で変えません。失うもの: 別のページでした操作を戻すには、そのページへ移ります。
- **(b) 窓で1つ。** どのページでも、最後の操作から順に戻します（戻すときにそのページへ移ります）。失うもの: Ctrl+Z でページが勝手に替わることがあります。
- **(c) ページを離れたら捨てる。** 失うもの: タブを行き来すると戻せなくなります。

**BQ2 ［要約を再生成］を、Ctrl+Z で戻せるようにしますか？**
- **(a) おすすめ: 戻せない（今の確かめのまま）。** 作り直したら、そのページの元に戻すの記録も消します。理由: 設計書の「アプリ自身の書き込みは本人の元に戻すに入れない」どおりで、作り直しは出典や打ち合わせの点まで入れ替える大きな書き込みです。失うもの: 作り直した後で「前の方がよかった」は戻せません。そのため、作り直す前の確かめ（0.13.0）が、人が消した・動かした行も見ていることが前提です（0.13.0 の点検で抜けが見つかっています。直っていなければ作る前にもう一度聞きます）。
- **(b) 戻せる（作り直しを1回の操作にする）。** 失うもの: 設計書の決まりを変え、Claude の書き込みを本人の操作として扱う作りが要り、0.14.0 が大きくなります。

**BQ3 文字の飾りと色は、どこまで入れますか？**
- **(a) おすすめ: 全部。** 太字・斜体・下線・取り消し線・コード・リンクと、9色（灰・茶・橙・黄・緑・青・紫・桃・赤）の文字の色と背景の色。理由: 設計書と Notion の公開資料のとおりで、Notion から移る人が迷いません。失うもの: 帯が少し大きくなり、暗い画面でも読める 18 通りの色を撮る画面で確かめる手間が増えます。
- **(b) 飾りとリンクは全部、色は「赤い字」と「黄色の背景」の2つだけ。** 理由: 議事録で使う色はほぼこの2つ。失うもの: ほかの色を探す人がいます。後で色を足すと帯の形が変わります。
- **(c) 色は入れない（飾りとリンクだけ）。**

**BQ4 文字を選んだときの帯に、AI（Claude）の項目を置きますか？**
- **(a) おすすめ: 置かない。** 理由: NaTsu の AI は各自の Claude（Claude Code・Claude デスクトップ）に任せる決まりです。帯から呼ぶと、選んだ文が外へ出る道が1つ増えます。失うもの: 「この文を言い換えて」をその場ではできません（Claude デスクトップから頼みます）。
- **(b) 置く（後の版で、別の問答で決める）。**

**BQ5 Word や Teams から貼ったときの、文字の色は？**
- **(a) おすすめ: 落とす。** 太字・斜体・下線・取り消し線・コード・リンク・見出し・箇条書き・番号は残し、文字の色・背景の色・字の大きさ・書体は落とします。理由: Word や Teams の色は会社の雛形の色で、NaTsu の9色に無く、暗い画面で読めなくなることが多いからです。失うもの: 赤字で目立たせた所が普通の字になります（太字なら残ります）。
- **(b) いちばん近い9色に寄せて残す。** 失うもの: 寄せ方が思ったのと違うことがあります（濃い赤 → 赤、紺 → 青など）。
- **(c) 黄色の蛍光ペンだけ、背景の黄として残す。**

**BQ6 まとめて選んだ行を消すとき、確かめますか？**
- **(a) おすすめ: 確かめない。** Backspace か Delete ですぐ消え、Ctrl+Z の1回で戻ります。理由: Notion と同じで、元に戻すがあるので確かめは要りません。失うもの: 気づかずに消した行は、NaTsu を終えると戻せません。
- **(b) 10 行以上をまとめて消すときだけ確かめる。** 失うもの: 確かめの窓が1つ増え、Notion と動きが違います。

**BQ7 タブが1つだけのときに Ctrl+W を押したら？**
- **(a) おすすめ: そのタブを閉じて、「左の一覧から議事録を選んでください」の画面にする（窓は閉じない）。** 理由: 今のタブの × と同じです。窓まで閉じると、トレイに常駐しない設定では NaTsu が終わり、音声入力のホットキーも止まります。失うもの: 「最後の Ctrl+W で窓が閉じる」ブラウザーの動きとは違います。
- **(b) 何もしない。**
- **(c) 窓を閉じる（ブラウザーと同じ）。**

**BQ8 Ctrl+Shift+N は何をしますか？（0.13.0 で［＋ 新しい議事録］は録音の前のページを開くだけになりました）**
- **(a) おすすめ: サイドバーの［＋ 新しい議事録］と同じ（録音の前のページを開くだけ）。** 理由: 2026-10-26 の頼み「勝手に録音を始めず」とそろい、同じ名前のボタンとキーで動きが同じです。すぐ録音したいときは Alt+M があります。失うもの: 窓の中のキーだけでは録音を始められません（［文字起こしを始める］を押すか Alt+M）。
- **(b) すぐ録音を始める（設計書の「記録開始」の文字どおり）。** 失うもの: サイドバーのボタンとキーで動きが違い、Alt+M と同じことが2つになります。
- **(c) 1回目で録音の前のページを開き、そのページでもう1回押すと録音を始める。** 失うもの: 2回押しを間違えて録音が始まらないよう、0.13.0 と同じ守りの作りが要ります。

**BQ9 ページの中の音声入力（Ctrl+Alt+V）は、どこに入りますか？**
- **(a) おすすめ: 要約の行とメモ。** 題名と文字起こしの行には入れません。理由: 自分で書くのは要約とメモで、文字起こしは録った声の文なので、口述で足すと出典の照らしが崩れます。失うもの: 題名を口述できません。
- **(b) 要約の行だけ。** 失うもの: 会議の前や後にメモを口述できません。
- **(c) カーソルのある入力ならどこでも（題名・文字起こしも）。**

**BQ10 議事録を録音している間に、ページの中の音声入力を使えますか？**
- **(a) おすすめ: 使えない。** 押すと「議事録の録音中は、ページの中の音声入力は使えません」と出ます（今の音声入力も、議事録の録音中は始まりません）。理由: マイクを2つの録音で取り合わず、話した声は会議の文字起こしにもう入っています。失うもの: 会議の最中に口述でメモを取れません（打つか、会議の後で）。
- **(b) 使える（議事録の録音を自動で一時停止して口述し、終わったら再開）。** 失うもの: 口述の間の会議の声は録れません。作りと確かめが大きくなります。

**BQ11 メモの欄にも、太字などの飾りを付けられるようにしますか？**
- **(a) おすすめ: 付けない（メモは今の文字の欄のまま）。** 理由: メモを飾れる形にすると、0.11.0 の雛形・録音中のメモ・下書き・Claude に渡すメモの区切りを作り直すことになります（0.13.0 で要約だけを編集の形にしたのと同じ理由）。失うもの: メモに太字やリンクは付けられません（Ctrl+Z は欄の中で今どおり効きます）。
- **(b) 付ける（メモを行の形にする。別の版で、別の問答で決める）。**

**BQ12 0.14.0 を分けますか？（大きさ: 14 タスク・変異 70・新しい画面 8 枚）**
- **(a) おすすめ: 2つに分ける。** 0.14.0 は「文字の飾り・元に戻す・SEC2」（EB-1〜EB-6）、0.14.1 は「貼り付けの変換・複数の行の選択・Ctrl+W と Ctrl+Shift+N・ページの中の音声入力」（EK-1〜EK-7）。理由: 元に戻すは全部の命令に、飾りは全部の行の描き方に手が入るので、先に出して実機で見てから、その上に貼り付けと選択を作る方が、壊れたときの切り分けが易しくなります。0.13.0／0.13.1 と同じ分け方で、後の版の番号はずれません。失うもの: 貼り付けの変換と近道・音声入力が1回分遅れて届き、リリースの手間が1回増えます。
