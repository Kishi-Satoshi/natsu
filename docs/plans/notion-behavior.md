# NaTsu — 「Notion と同じ動き」の仕様書（公開資料から）

> **この文書の役目:** 設計書（`docs/plans/natsu-design.md`）の第1b・2a・2b・3・5・11a・16・17回で「Notion と同じ」と書いたところを、**どう動けば同じと言えるか**を1項目ずつ決める。各回の実装計画は、ここの項目番号（例 `K-05`）を引いてテストを書く。
>
> **出典の決まり（厳守）:**
> - 使ったのは Notion の**公開のヘルプセンター**（notion.com/help）と**公開の開発者向け資料**（developers.notion.com）だけ。Notion のアプリのコードは落とさない・ほどかない・のぞかない。
> - 文は自分の言葉で書いた。Notion の画面の名前（`Turn into` など）は短い名前だけをそのまま使う。
> - どの項目にも出典（下の「出典の一覧」の記号）を付けた。公開資料で決まらないものは、項目にせず「利用者に確かめること」に回した。
> - 調べた日: 2026-10-17。ヘルプセンターは予告なく変わるので、実装の回の直前に出典を開き直して、変わっていないか確かめる。
>
> **キーの書き方:** Windows の名前で書く（Ctrl・Alt・Shift・Win）。Mac の cmd は Ctrl、option は Alt に読み替えてある。
