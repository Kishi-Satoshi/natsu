## 目的

1. **会議のアプリ（Teams・Zoom・Chrome・Edge）を出たら、聞かずに録音を止めて議事録を作る。** 会議のアプリがマイクを放して 60 秒たっても戻らなければ、帯も数え下げも出さずにすぐ止める（LQ1「黙ってすぐ止める」・LQ2「60 秒」）。
2. **止めたことは Windows の知らせで1回だけ伝える。** 止めた直後に「会議を出たので録音を止めました。議事録を作っています。」を1回出し、押すとそのページを開く（LQ1 の続き）。議事録を保存したときの今の動き（録音バーの「議事録を保存しました」・ページを開く）はそのまま。
3. **誤って出て、すぐ入り直したときは止めない。** 放してから 60 秒の間に同じアプリ（同じブラウザの実行ファイルを含む）がまたマイクを使えば、同じ議事録のまま録り続ける（新しい議事録を作らない。LQ6）。
4. **相手がまだ話しているうちは止めない。** 0.12.0 で相手の声を別の流れで取り込んでいる会議では、相手の声が最近まで聞こえていれば止めずに待ち、相手の声も 30 秒（LQ11 の案）途切れてから止める（LQ9「使う」）。相手の声を取り込んでいない会議では、この確かめを飛ばす。
5. **止めた理由を後から追える。** 議事録の経過（0.10.0 の `stateLog`）に「会議のアプリがマイクを放した」「会議に入り直した」と、止めたきっかけ「会議を出たので自動」を積む（持ち主の試作の考え）。
6. **止めてはいけないときに止めない。** 見張りの記録が読めない・見張りが落ちた・読みが途切れた・一時停止の間・会議のアプリが一度もマイクを使わなかった録音では止めない。分からないときは止めない側に倒す（0.9.1 の決めたこと 7 と同じ考え）。

## 決めたこと（理由つき。問いの答えで変わる所は印 ［LQn］）

1. **L1 判断は純粋な状態機械 `leaveStep`（新しい `src/meetleave.js`）。** 状態は3つ: `wait`（まだ会議のアプリを見ていない）・`in`（会議中）・`grace`（見張る会議のアプリが全部マイクを放した後の猶予）。答えは `{ st, act }` で、`act` は `''`・`'left'`（放した）・`'back'`（入り直した）・`'hold'`（猶予は過ぎたが相手の声が最近まであるので待つ。その猶予で1回だけ）・`'reset'`（データが無い・一時停止・設定で数え直す）・`'stop'`。理由: 0.9.1 の `quietStep`・0.9.3 の `nudgeStep` と同じく、表のテストで全部の移り変わりを固定でき、main は答えのとおりに止める・積むだけになる（持ち主の試作の「きっかけと一緒に移す」）。初版の `ask`（聞いている）・`kept`（［続ける］の後）は、聞かなくなったので無くした（LQ1）。
2. **L2 見張る会議のアプリ（W）にしてよいアプリ:** `LEAVE_IDS = ['teams', 'zoom', 'chrome', 'edge']`（Teams・Zoom ［LQ7］と、ブラウザは Chrome・Edge だけ ［LQ5］）。Firefox・Webex・Slack は入れない（Webex・Slack は持ち主の確かめの後: LQ12）。ブラウザもアプリと同じ決まりで黙って止める（LQ5 の続き）。NaTsu 自身のマイクは今どおり見張りの文が除く（議事録の録音バーも、0.12.0 の2つの流れも同じ実行ファイル）。
3. **L3 W の決め方:** パネルから始めた録音は、パネルのアプリ（main の `nudgeShown.id`。画面から受けない）が `LEAVE_IDS` にあれば初めから W に入れる（Chrome・Edge のパネルも同じ。Firefox・Webex・Slack のパネルなら初めは空）。どの録音でも（パネル・ホットキー・ページのボタン・トレイ ［LQ4］）、録音中に `LEAVE_IDS` のアプリが**2回続けて**（2 秒ごとの読みで2回）マイクを使っているのを見たら W に足す（録音を始める前から会議に入っていても、始めた後に入っても）。理由: 0.9.3 の「2回続けて見たら出す」と同じく、一瞬の使い（音声メッセージの試しなど）で取り違えない。W は増えるだけで、録音の間は減らない。会議のアプリが一度もマイクを使わなかった録音（対面の会議など）は `wait` のままで、止めない。
4. **L4 放した:** W が空でなく、W のアプリが1つもマイクを使っていない読みが来たら `grace` に移り、その時刻（`leftAt`）を覚える（`act: 'left'`）。1回の読みで移る（2回を待たない: 待つ時間が 60 秒あるので、一瞬の読み損ねは入り直しで戻る）。
5. **L5 入り直した:** `grace` のときに W のアプリがまたマイクを使ったら `in` に戻る（`act: 'back'`）。同じアプリの `Start` が変わっていてもよい（機器の切り替え・入り直しは開き直しなので `Start` が変わる）。**同じブラウザの実行ファイル（同じ id）なら、どのタブの使いでも同じアプリ**として入り直しにする（Windows の記録はタブを見分けない。LQ6 の答え）。Teams の2つの exe とパッケージは、今の一覧どおり1つの id `teams`。**新しい議事録は作らない**（録音は止めていないので、同じ議事録のまま続く）。W に無い別のアプリの使いは入り直しにしない ［LQ6］（猶予はそのまま進む）。
6. **L6 待つ時間と止める時:** `grace` に移ってから `LEAVE_GRACE_MS = 60000` ［LQ2］たち、相手の声の確かめ（L9）も通れば `act: 'stop'`。聞かない・数え下げを出さない ［LQ1］。`stop` は条件が続く間は毎回返す（止めるかは main が決める: `quietStep` と同じ）。
7. **L7 時計は見張りの行・読みが途切れたら数え直す:** main に新しいタイマーを作らず、見張りの読み（2 秒ごとの `mic …` の行）を `leaveStep` に渡すたびに時間を進める。だから本当に止まるのは 60 秒の後の、次の読み（最大 2 秒遅れ）。理由: 見張りが落ちた・止まったら数えも止まり、**データの無いまま止めることが起きない**。さらに、`grace` の間に前の読みから `LEAVE_GAP_MS = 10000` より空いた読みが来たら（PC が眠った・PowerShell が固まった）、見ていなかった間を数えず、その読みから猶予を数え直す（`act: 'reset'`）。初版は「時計が飛んでもまず聞く」で守っていたが、聞かなくなったので、この数え直しで守る。時計が戻った（`now` が前の読みより前）ときも、その読みから数え直す。
8. **L8 データが無いときは止めない:** 見張りの `err read`・`err proc` の行と、見張りが落ちた（`onMicWatchGone`）ときは `leaveStep` に `{ type: 'lost' }` を渡し、`grace` なら `in` に戻す（`act: 'reset'`。経過には積まない）。次に読めた行で、まだ W が放していれば、そこから猶予を数え直す。
9. **L9 相手の声の確かめ ［LQ9・LQ11］:** main は、0.12.0 の level-ask の答えを `checkLevel` で照らした後、`sysOk` で `sys >= VOICE_LEVEL` のフレームが来るたびに `meeting.sysVoiceAt = Date.now()`、答えが来るたびに `meeting.levelAt = Date.now()` を上書きする（100ms ごとの値を積まない: 持ち主の試作の間引き）。見張りの読みのたびに `leaveStep` へ `remote: { on, at }` を渡す: `on` は「2つの流れの会議で、最後の答えの `sysOk` が真で、`Date.now() − levelAt ≤ LEVEL_STALE_MS`（5000）」、`at` は `sysVoiceAt`（無ければ `null`）。`leaveStep` は、猶予が過ぎたとき `on` が真で `now − at < LEAVE_VOICE_QUIET_MS`（30000 ［LQ11］）なら止めずに `grace` のまま待ち（その猶予で初めてなら `act: 'hold'`。記録に1行）、相手の声が `LEAVE_VOICE_QUIET_MS` 途切れた読みで `stop`。`on` が偽（相手の声を取り込まない会議・取り込みが切れた・答えが 5 秒来ない）なら確かめを飛ばし、60 秒で止める（LQ9 の答え）。`at` が猶予の前でもよい（「最後に相手の声が聞こえてからの時間」だけを見る）。本当に会議を出たときは相手の声もその時に止むので、止まる時は 60 秒のまま。上限は置かない（相手の声が続く限り待つ）: PC で別の音が鳴り続けても、0.9.1 の「話し声が無いとき」（文字起こしの中身で見る）が今どおり後ろで守る。0.12.0 の作った形で、PC の文字起こしの側（オフラインモード）で level-ask が回っていなければ、`leave.phase === 'grace'` の間だけ同じ口で 100ms ごとに問う（猶予の 60 秒が 30 秒の窓より長いので、猶予の頭から問えば足りる。録音バーは今の受け口で答えるだけで、変えない）。
10. **L10 止め方:** `stop` を受けたら、`state === 'meeting'` で止めていないときだけ `stopByLeave()` → `stopMeetingBy('auto-leave')`（今の1つの道）。`STOP_BY['auto-leave'] = 'leave'`、経過は `auto-stop`（「終了」）できっかけ `leave`（「会議を出たので自動」）。`m.leaveStopped = true` を付ける。0.9.1 の `m.autoStopped` は付けない（`quietDoneNotice` を出さない）。
