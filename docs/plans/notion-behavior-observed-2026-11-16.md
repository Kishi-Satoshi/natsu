# NaTsu — 「Notion と同じ動き」実機で確かめた結果（2026-11-16）

> **この文書の役目:** 0.17.0 の計画（`docs/plans/2026-11-13-170.md`）の「Notion の画面で確かめてほしいこと（第5版）」の S1〜S12 と、同じ計画の R66（ロックしたデータベースを親のページごと消す）に、本物の Notion を操作して確かめた答えを付ける。2026-11-14 の結果（`docs/plans/notion-behavior-observed-2026-11-14.md`）の続き。取り込むか、NaTsu をどう直すかは、いつもの計画と問答で決める。
>
> **出典の決まり:**
> - 出典は「実機」だけ。持ち主の PC の Notion デスクトップ版（Windows・日本語の画面。この回は版の番号を記録していない）を 2026-11-16 に画面の外から操作して、見えた動きだけを書いた（設計書の「画面の外から見て分かる動き」）。アプリの中を調べて分かったこと（名前・値・コード・データ・通信）は、この文書に入れていない。
> - 文は自分の言葉で書いた。画面の言葉（「ブロックタイプの変換」「n件選択済み」など）は短い名前だけをそのまま使う。
> - 試したのは、試験用に作ったページ「NaTsu test 4 (OK to delete)」の中だけ。最後の確かめ（R66）で、そのページごとゴミ箱へ移した（30 日は戻せる）。
> - Notion は予告なく変わる。実装の回の直前に、使う項目は試し直す。
>
> **試し方の限り:**
> - 自動の画面操作で試した。行の型は Ctrl+Shift+数字 と「ブロックタイプの変換」（Ctrl+/）で作った。キーは本物のキーとして送った。人の手の打鍵とは時間の細かさが違う。
> - 1つの場面を1回ずつ試した（S1 の見出しの場面は、最後の子と真ん中の子の2つの形で試した）。
> - 試していないもの: 下の「3. 確かめていないこと」。日本語入力の変換中の動き・スマホ版・Web 版。

## 1. S1〜S12 の答え

| # | 試した場面 | 実機の動き |
| --- | --- | --- |
| S1 | トグルの中の見出し2の行頭で Backspace（すぐ上にテキストの行） | **見出しが最後の子のとき:** 1 回目で一段上がる（トグルの外へ出る。見出し2のまま）。2 回目で、見えている上の行と結合する（見出しの型は消え、上の行の字の後ろにつながる）。テキストに戻る段は無い。**見出しが真ん中の子のとき（後ろに兄弟の行がある）:** 1 回で上の行と結合する。 |
| S2 | 開いたトグル見出し（中に2行・上にも行）の行頭で Backspace | 1 回では結合しない。1 回目で、トグルが外れてふつうの見出し2になり、中の2行は一段上がって、見出しのすぐ後ろに並ぶ（字下げが無くなる）。2 回目で、上の行と結合する。 |
| S3 | 字下げした最初の子（後ろに兄弟あり。型はテキスト）で Backspace | 1 回で親と結合する（「P」＋「k1」→「Pk1」）。一段上がらない。後ろにいた兄弟は、結合した行（Pk1）の子のまま残る。 |
| S4 | 字下げした真ん中の子（前の兄弟が子を持つ）で Backspace。形: P の子に a・b・c、a の子に a1。b の行頭で Backspace | 見えている上の行（a1）と結合する（「a1b」）。前の兄弟（a）ではない。c は P の子のまま。 |
| S5 | コールアウト | **行末で Enter:** コールアウトの中に空のテキストの行ができる（コールアウトの子）。その空の行で Backspace を押すと、行が消えてコールアウトの字の末に戻る。**行頭で Backspace:** 1 回で上の行と結合する（コールアウトは消え、字が上の行につながる）。テキストに戻る段は無い。 |
| S6 | 空のテキストの行で Ctrl+A を1回 | ページの全部の行が選ばれる（行の選択。上下の行も含めて全部が青くなる）。 |
| S7 | データベースの行を開いたページで、テキストの列を書いている途中に Esc | 書いた字は残る（「ab」に「cd」を足して Esc →「abcd」のまま。表の側にも、書いている間からすぐ出る）。 |
| S8 | 中に行のあるトグル見出しを変える | **「テキスト」に変えた:** 中の行は、テキストの行の子のまま残る（字下げしたまま）。**「見出し2」に変えた:** 中の行は一段上がって、見出しのすぐ後ろに並ぶ（見出しは子を持たない）。 |
| S9 | 表の Tab と Shift+Tab | **最後の行の最後のセル:** 書いている途中で Tab → 書いた字が確定し、同じセルが選ばれたまま。動かない。新しい行もできない。セルを選んでいるだけで Tab → 何も起きない。**最初の行の最初のセル（名前）:** 選んでいるだけで Shift+Tab → 何も起きない。書いている途中で Shift+Tab → 書いた字が確定し、同じセルが選ばれたまま。参考: 途中の行の最後のセルで Tab → 次の行の最初のセルへ（2026-11-14 の Q-19 と同じ）。 |
| S10 | 選ぶ窓で途中に Esc | **選択:** 新しい選択肢の名前を打っている途中（「新規作成：opt」と出ている）に Esc → 窓が閉じ、何も作られず、何も入らない。セルは選ばれたまま。**日付:** 窓を開くと、入力の欄に今日の日付が選ばれた形で入り、カレンダーは今日が光る。打ちかけ（「2026/11/2」）で Esc → 打った日付が入る（2026年11月2日）。何も打たずに Esc → 空のまま（今日は入らない）。**ユーザー:** 窓は検索の欄と「最近選択」の一覧。人を押すと、その人が欄に入り、窓は開いたまま（何人でも選べる形）。そこで Esc → 窓が閉じ、選んだ人は残る。検索の字を打った途中（候補が光っている）で Esc → 何も入らない。 |
| S11 | 2つの行にチェック → 別の行のセルを選ぶ → Esc | 別の行のセルを押した時点で、2つのチェックは外れる（帯「2件選択済み」も消える）。そこから Esc 1 回目 → 書いている状態をやめて、そのセルが選ばれる。Esc 2 回目 → そのセルの行が選ばれる（チェックが入り、帯は「1件選択済み」）。前の2つのチェックは戻らない。Esc 3 回目 → 何も選ばれていない。参考: 新しい行の名前を Enter で確定した後に Esc を押しても、その行が選ばれた（チェックが入る）。 |
| S12 | 文字のある行の行頭で Enter | **箇条書き:** 上に空の箇条書きができる（薄い字「リスト」）。カーソルは元の行に残る。**ToDo:** 上に空の ToDo ができる。元の ToDo にチェックが入っていると、上にできる空の ToDo にもチェックが入る。 |

## 2. ロックしたデータベースを入れた親のページを消す（0.17.0 の計画の R66）

- **手順:** 試験用のページの中にデータベース（インラインの表）を作る →［フルページで表示］→ ··· →［データベースをロック］（入れると、親のページの中の表の帯にも「🔒 ロック中」が出る）→ 親のページの ··· →［ゴミ箱に移動］。
- **親のページの［ゴミ箱に移動］は灰色にならず、押せる。** 確かめの窓も出ず、断られずに消える（「ゴミ箱に移動しました　復元」と出る）。
- **中のデータベースも一緒にゴミ箱に入る。** 検索から親のページを開くと赤い帯「…ゴミ箱に移動しました。30日後に完全に削除されます。［ページを復元］［完全に削除］」が出て、中のデータベースを開いても同じ赤い帯が出る（ロック中のまま）。サイドバーからも消える。

## 3. 確かめていないこと

- 閉じたトグル見出しでの Backspace。中に子のあるコールアウトの結合。
- 複数選択（マルチセレクト）の窓。既にある選択肢を光らせた途中の Esc。
- ロックしたデータベースを、データベースだけ消そうとしたとき（2026-11-14 の確かめで「ロックを解除してください」と出て押せないのは見た）。
