# 0.7.0 の小さな画面の直し — 文字起こしの送り先を OpenAI に固定・外観を設定のいちばん上へ（U-1・U-2）

> **実装する人へ:** 1タスクずつ「落ちるテストを書く → 落ちるのを見る → 実装 → 通るのを見る → commit」の5手で進める。各 commit の前に `npm test` が `# fail 0`・`# skipped 0`、`node tools/risk.js --staged` が `結果: BLOCK 0 件`。
> これは利用者が 2026-10-19 に頼んだ小さな直しで、第2a1回の計画（`docs/plans/2026-10-19-2a1.md`）の外。2a1 と同じ 0.7.0 で出す。2a1 の計画は「`app.html` を1文字も変えない」「`src/main.js`・`test/helpers/mainrun.js`・`test/helpers/json-scenes.js` はレーン M だけ」「`tools/mutants.js` に足すのは G-3 だけ」と決めているが、この直しはそこに触る（下の「2a1 と重なるところ」）。
> 設計書の全体の決まり（npm の依存を足さない・`fetch(` を使わない・飛ばすテストを作らない・テストは1つ 5 秒まで・一時フォルダの名前に日本語と 𠮷・本当の名前やパスを書かない・`overlay.html` は変えない）はそのまま守る。

**目的:** 設計書「利用者が決めたこと（文字起こしの送り先・中継・登録・外観。2026-10-19）」の D5 と D8 を 0.7.0 で入れる。

**設計書の決定（そのまま写す）:**

- **D5:** クラウドの文字起こしの送り先は **OpenAI に固定**する。利用者は OpenAI と契約せず、鍵も入れない。送り先・鍵・同意を利用者ごとに設定する形はやめる ／ 0.7.0 で、設定の画面から送り先の選択と「使う／使わない」の選択を外す（Groq・そのほかの送り先は選べなくする）。中継ができるまでは、利用者本人の PC にしまってある鍵をそのまま使い、鍵の欄は詳細設定の奥に「管理者用」として残す。オフラインのときは今までどおり手元の whisper
- **D8:** 画面の配色（「システム設定を使用」「ライト」「ダーク」）を、Notion と同じく設定のいちばん上の「外観」で選べるようにし、選んだらすぐ切り替える。Ctrl+Shift+L でライトとダークを切り替える ／ 0.7.0。今の設定のキー `theme`（`system`・`light`・`dark`）と main の `nativeTheme.themeSource` はそのまま使い、置き場所・名前・近道だけを変える（近道がほかとぶつからないかを確かめる）
- （関わる D7 の一部）音声を外へ送ることへの同意は、登録のときの利用規約への同意で取り、会議ごと・利用者ごとの確認は出さない。会議を始めたときの「この会議の音声は OpenAI に送られます」の知らせと、1on1・面談向けの［この会議は PC の中だけ］は残す（RF28）

## 決めたこと（既定で決めた。違う答えなら直す）

1. **今までの保存の値の扱い（U-1）。** `settings.json` の `cloudTranscribe`・`sttProvider`・`sttBaseUrl`・`sttModel` は**読まない・消さない・画面から書かせない**。4つのキーを決まりの表（`SETTING_RULES`）と既定から外すので、`readSettings` は「知らないキー」としてそのまま残す（JS6。0.6.0 に戻したときに前の選択が戻る）。
   - `cloudTranscribe` が `ask`（まだ決めていない）・`off`（使わない）でも、**OpenAI の鍵がしまってあれば使う**側に読む。D7 で同意は登録の利用規約で取り、D5 で選ぶ欄を外したため。鍵の無い PC は今までどおり手元の whisper（鍵を入れるのは管理者だけ）。
   - `sttProvider` が `groq`・`custom` でも、送り先は OpenAI（`gpt-4o-transcribe`）。`sttBaseUrl`・`sttModel` も使わない。
   - `secrets.json` の `groq`・`custom` の鍵は**消さず、使わず、OpenAI へも送らない**。main が読むのは `openai` の鍵だけ。画面の［保存］［鍵を確かめる］［鍵を消す］も `openai` だけを扱い、main は `openai` 以外の名前を `bad-id` で断る。
2. **`src/stt-cloud.js` の `PRESETS`（groq・custom）は残す。** 古いページの「☁ 文字起こし: クラウド（Groq（無料枠））」の名前と、`tools/electron-smoke` の偽の送り先の確かめが使うため。main は `sttCloud.fixedProvider()`（新しく足す。`openai` の既定を返す）だけを使い、設定からは groq・custom に届かない。
3. **会議の状態の `cloud`（［この会議は PC の中だけ］を出すか）** は「OpenAI の鍵がしまってあるか」（`secrets.has('openai')`。復号しない）。
4. **経路の決め方 `decideStt` から同意を外す。** 順は「会議の印（localOnly）→ 鍵 → 届くか」。鍵が無ければ届くかの確かめの要求も出さない。［この会議は PC の中だけ］のときは鍵を復号もしない（今の「同意の前は復号しない」の代わり）。
5. **鍵の欄は「オンライン」のカードの中の［詳細設定（管理者用）］を開いた奥**（`<details id="onlineAdv">`）。中継（設計書 D6）ができたら外す仮の欄。
6. **外観（U-2）。** 設定の画面のいちばん上（［アップデート］より上）にカード「外観」。選ぶ欄の id は今の `themeSel` のまま（配線のテストと変異を壊さない）。選んだら今の自動保存（`save` → main の `applyTheme`）ですぐ切り替わる。「動作」のカードの「画面の配色」は消す。
7. **Ctrl+Shift+L（U-2）。** 本体の窓のどこでも（入力欄の中でも。Notion と同じ）ライトとダークを切り替える。「システム設定を使用」のときは、今見えている配色（`prefers-color-scheme`）の反対にする。保存は外観の欄と同じ道。IME の変換中（`isComposing`）と、ほかの受け口が先に止めた打鍵（ホットキーの欄の取り込み）では動かさない。
   - ぶつからないかを確かめた（`src/renderer/app.html`・`src/main.js`・`src/winstate.js`・設計書を `KeyL`・`Shift+L` で探した）: 今の近道は Ctrl+\（サイドバー）・Ctrl+P（検索の窓）・Ctrl+Shift+P（一時停止）・Ctrl+＋／−／0（拡大。main の `before-input-event`）・Ctrl+W・Ctrl+Tab（タブ）・Esc（録音の取り消し。グローバル）・Control+Shift+Space と Alt+M（既定のホットキー。グローバル）。設計書の後の回の近道（E6・E7・E11・U3・U4）にも Ctrl+Shift+L は無い。ホットキーに Ctrl+Shift+L を自分で入れた人は、グローバルの方が先に取る（そのときは近道が効かない。知らせは出さない）。
8. **画面の基準の画像。** 設定の画面の3枚（`settings-light`・`settings-dark`・`settings-zoom200-dark`）を取り直し待ち（`tools/shots/screens.js` の `RETAKE`）に入れる。第1b回と同じく、CI は「取り直し待ち」と出して NG にしない。利用者が新しい画像を見て OK と言ったら、CI の画像を基準にして `RETAKE` を空に戻す。取り直し待ちが残っている間は版を 0.6.0 から上げられない（`test/shots.test.js` の守りを 0.6.0 に合わせる）。
