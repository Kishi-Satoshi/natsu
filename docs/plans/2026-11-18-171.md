## 目的

1. **浮く窓（メニュー・選びの窓・設定の窓）は、どれも同じに閉じる:** 外を押すと閉じる・Esc で閉じる（フォーカスが窓の外にあっても）・開くのは1つ（別の窓を開くと前の窓は閉じる）。
2. **閉じ方を1つの仕組みにまとめる:** 今は窓ごとに閉じ方が違い（`focusout` で閉じる窓・`document` の `pointerdown` で閉じる窓・何も持たない窓）、0.16.0・0.17.0 で足した窓の多くが何も持たなかった。窓ごとに閉じ方を足すのでなく、画面に1つの「開いている窓の帳面」を置き、そこで外の押しと Esc と「開くのは1つ」を受ける。後で窓を足しても、帳面に載せるだけで同じに閉じる。
3. **0.17.1 として、0.18.0 より先に出す**（PQ171-1）。

## 調べた結果（`15a6e98` で調べた）

### 1. 原因（持ち主が見つけた2つ）

1. **列の見出しのメニューには、外を押したときに閉じる受け口が無い。** 列のメニュー（`dbColMenu`。13268）は、データベースのメニューの共通の作り `dbMenuAt`（13155〜13190）で作る。`dbMenuAt` は窓を `st.host` に入れて `st.menu` に覚え、閉じる道は (a) 窓の中にフォーカスがあるときの Esc（13176 の `m.onkeydown`）、(b) 同じ見出しをもう一度押す（13272 の `st.menu.dataset.col === colId` のときの `dbMenuClose`）、(c) 同じ表の別のメニューを開く（`dbMenuAt` の頭の `dbMenuClose()`・`dbPanelClose()`）、(d) 項目を選ぶ、(e) 表の描き直し（`dbPaint` の `box.textContent = ''`。11816）だけ。`focusout` の受け口も `document` の `pointerdown` の受け口も無い。だから外の余白・題名・ほかのボタンを押しても開いたまま。**持ち主の「再度フィルターを選択しないと閉じない」は (b) のこと。**
2. **「ロック中」の［ロックを外す］にも、外を押したときに閉じる受け口が無い。** 0.17.0 LK-1 の `$('pLock').onclick`（7564〜7579）は、サイドバーの行のメニュー（`openTreeMenu`。6309）と同じ形（`blockmenu` の箱・`menuItem`・Esc・Tab）で作ったが、行のメニューの閉じ方の1行（6345 の `box.addEventListener('focusout', …)`）を写していない。閉じる道は、もう一度「ロック中」を押す・窓の中の Esc と Tab・［ロックを外す］を押す、だけ。
3. **2つが同時に開くのは、窓どうしが互いを知らないから。** `dbMenuAt` が閉じるのは同じ表の `st.menu` と `st.panel` だけで、`lockMenu` を閉じない。「ロック中」を押しても `st.menu` を閉じない。どちらも外の押しで閉じないので、列のメニューを開いたまま「ロック中」を押すと2つが並ぶ（持ち主の画面のとおり。下の 2 で本物の Chromium で同じ形を出した）。
4. **Esc は、フォーカスが窓の中にあるときしか効かない。** どちらの窓も Esc の受け口が窓そのもの（`m.onkeydown`・`box.onkeydown`）にあるので、外を押してフォーカスが題名などへ動いた後の Esc では閉じない。

**指された `mousedown` の行（12843・14143）について:** セルの選びの窓（行のページの `rpOpenWriter` と表の `dbOpenWriter`）の `pop.addEventListener('mousedown', … preventDefault)` は、**窓の中**の文字や余白を押したときに、フォーカスを窓の探す欄に残すためのもの（0.16.0 rv48 F2）で、外の押しには効かない。選びの窓が外の余白の押しで閉じないのは、その下の `focusout` の受け口（12849・14151）が「行き先（`relatedTarget`）が窓の外の部品のときだけ閉じ、行き先が無いときは閉じない」形だから（0.16.0 rv49 M-b・R95: 選ぶたびに窓を描き直してフォーカスが行き先無しに外れるので、そのときに閉じないため）。押せない余白（ページの頭など）を押すと、フォーカスは行き先無しに外れるので閉じない。暦（`date`）の受け口は行き先が無くても決めて閉じる（0.16.0 R82）ので、暦は閉じる。

**閉じる窓との違い:** サイドバーの行のメニュー（6345）・⋮⋮ のメニュー（15676）・プライベートの［···］（7112）・パンくずの［…］（2903）・リンクの窓（10967）・/リンクドビュー の窓（11190）は、`focusout` の後に `setTimeout` で `document.activeElement` が窓の外かを見て閉じる。Chromium では押せない所を押してもフォーカスが外れる（`activeElement` が `body` になる）ので、外の押しで閉じる。ページの［···］（`#pMenu`）は `document` の `pointerdown`（7615）で閉じる。ただし `focusout` で閉じる窓も、**押したときにフォーカスを動かさない部品**（`mousedown` を止める部品: 本文の行の ＋（16098）・トグルの ▸（16134）・文字の飾りの帯のボタン（10893）・色の並び（11052）・/ メニュー（15088）・選びの窓の中）を押すと閉じない（下の表の 24 行目。本物の Chromium で、サイドバーの行のメニューを開いたまま本文の行の ＋ を押すと残った）。

## 決めたこと（理由つき。違う答えなら直す）

1. **開いている窓の帳面を1つ置く（`popLayer`）。** `app.html` に、開いている浮く窓を新しい順に覚える帳面と、3つの呼び口 `popOpen(el, o)`・`popDrop(el)`・`popCloseAll(why)` を置く（「受け渡す名前と形」）。外の押しと Esc は、`document` に付けた2つの受け口（`pointerdown` と `keydown`。どちらも捕まえる段 `capture`）だけで受ける。帳面は窓のメモリだけ（覚え書き・DB に書かない）。**理由:** 窓ごとに閉じ方を足す今の作りで、0.16.0・0.17.0 の窓が閉じ方を持たずに出た。1か所にすれば、後で足す窓も帳面に載せるだけで同じに閉じる（「持ち主の試作から参考にしたこと」の 1 行目）。**失うもの:** 今の窓の作りに1行ずつ手を入れる（約 20 か所）。
2. **外の押し:** 押した所が、どの窓の中でも、その窓を開いた部品（`anchors`）の中でもなければ、新しい窓から順にその窓を閉じる（窓の中の子の窓は親と一緒に残る）。主ボタンと右ボタンの押しで閉じ、中ボタン（自動の捲り）では閉じない。捲り棒（スクロールバー）の押しも外の押しとして閉じる（形を見分けない。失うもの: 表を捲り棒で捲ると窓が閉じる。ホイールの捲りでは閉じない）。
3. **開いた部品をもう一度押すと閉じる（今のまま）。** 外の押しは、開いた部品の押しでは窓を閉じず、その部品の `click` の開け閉め（13272 などの今の作り）に任せる。**理由:** 先に閉じると、続く `click` で同じ窓がまた開く（閉じられない）。
4. **開くのは1つ:** `popOpen` は、新しい窓を中に持つ窓（親）のほかを全部閉じる。だから列のメニューを開いたまま「ロック中」を押すと、列のメニューは閉じて［ロックを外す］だけが開く。キーボードで開いても同じ。子の窓（テンプレートの［···］・⋮⋮ の［変換 ▸］・［書体 ▸］・プライベートの［並べ替え ›］）を開いても、親は残る。全面の窓（決めたこと 10）を開くときは `popCloseAll`。
5. **Esc:** 窓が開いていて、フォーカスがいちばん新しい窓の外にあるときは、その窓を閉じて開いた部品へフォーカスを戻し（部品が描き直しで消えていれば戻さない）、その Esc を止める（`preventDefault`・`stopPropagation`）。フォーカスが窓の中にあるときは、今の窓の Esc の受け口に任せる（子の窓の1段戻りも今のまま）。変換中の Esc（`imeEnter` と同じ見分け: `isComposing`・`keyCode 229`）では何もしない。**窓が開いていないときは何もしない**（表の Esc の段（0.17.0 NX-5）・行の選びの Esc・設定の Esc はそのまま）。
6. **外の押しで閉じたときの扱いは、その窓の Esc と同じ。** 例外は打ちかけの字のある欄だけ（1行の欄と設定の窓の値の欄）:
   - データベースのメニュー・［ロックを外す］・設定の窓・⋮⋮ などのメニュー: 何も書かずに閉じる（Esc と同じ）。
   - セルと行のページの選びの窓: 何も書かずに閉じる（選ぶたびにもう書いている。Esc と同じ）。
   - 暦: 打った日付を決めて閉じる（0.17.0 の OQ2 の (a)。Esc と同じ。今の `focusout` の形と同じ）。
   - **1行の欄（`dbMenuInput`: 列の［名前を変える］・［選択肢を足す］・［接頭辞］・列を足した後の名前の欄）: 外を押すと Enter と同じに決める**（空や同じ名前なら何も送らない。Esc は今どおりやめる）。**理由:** 0.15.1 の名前を変えると同じ（欄の外を押すと決まる）・0.17.0 決めたこと 85（打った字を捨てない）。**失うもの:** 打ちかけて「やっぱりやめた」で外を押すと名前が変わる（Ctrl+Z で戻る）。N171-3 で Notion の画面を確かめる。
   - **設定の窓の中の値の欄（絞り込みの値など。今は `change` で書く: 13953 からの `dbFilterGroup`）: 外を押すと、打ちかけの値を `change` と同じに書いてから閉じる**（窓を木から外すと `change` が来ないので、閉じる前に書く）。理由と失うものは上の1行の欄と同じ。
   - タブの［＋］の名前の欄: 外を押してもビューを作らない（Esc と同じ）。**理由:** Enter はビューを作るので、外の押しで作ると知らないうちにビューが増える。
7. **外の押しは、押した所の動きを止めない（初めの形）。** 外の押しで窓を閉じた後も、押した所の `mousedown`・`click` は今どおり届く（別のセルを押せばそのセルが選ばれ、別の列の見出しを押せばその列のメニューが開く）。今の閉じる窓（ページの［···］・サイドバーの行のメニュー・⋮⋮ のメニュー）と同じ。Notion と同じかは N171-1 で確かめ、PQ171-3 で決める。
8. **押した所の動きを描き直しで消さない。** 閉じると表やページを描き直す窓（セルの選びの窓・暦・1行の欄）は、押した部品の `click` が届いた後に描き直す（どう遅らせるかは作り手が決めて Ruling に書く）。**理由:** 0.15.1 の R43（`ps-ren-inplace`）と同じ失敗（描き直しで押した部品が木から外れ、`click` が来ない）を避ける。F222 でテストを持たせる。
9. **フォーカスで閉じる今の受け口は残す。** サイドバーの行のメニューなどの `focusout` の受け口と、選びの窓の `focusout` の受け口は、Tab などのキーでフォーカスが外へ出たときの閉じ方として残す（キーの動きを変えない）。ページの［···］の `document` の `pointerdown`（7615）は、帳面の外の押しと同じことをするので、帳面に移して消す（同じことを2か所でしない）。列のメニューなど `focusout` を持たない窓で Tab を押したときは今のまま（窓は残る。この版の外）。
10. **全面の窓は今のまま。** アイコンの選び・移動先…・新しいページ・ゴミ箱・検索・設定は、後ろの全面を押すと閉じる今の形で、帳面に載せない。開くときに帳面の窓を全部閉じる（`popCloseAll('modal')`）。全面の窓の中を押しても、帳面は何もしない（帳面の窓はもう閉じている）。
11. **設定の窓（並べ替え・絞り込み・グループ・列の表示）も外を押すと閉じる**（PQ171-4。0.16.0 R78 を替える）。窓の中で書いても閉じない・描き直しても残るのは今のまま。
12. **帳面に載せる窓（PQ171-2 の (a)）:** 監査の表の 1〜27 の全部（全面の窓と設定の ⓘ の吹き出しを除く）。今閉じる窓（20〜27）も載せ、「開くのは1つ」と「フォーカスが動かない部品の押し」（24）を同じ決まりで直す。
13. **変えないもの:** 保存の形・DB の命令・`preload.js`・覚え書き・近道の表（`src/shortcuts.js`）・ヘルプの記事（閉じ方を書いた記事は検索の窓（`find/search.md`）だけで、その動きは変わらない）・画面の文（新しい文も変わる文も無い）。0.17.0 に戻しても何も壊れない（何も残さない）。
14. **本物の Chromium で確かめる。** 偽の DOM（`test/helpers/simrun.js`・`simdom.js`）は `pointerdown` を押した部品と `document` にしか送らず、フォーカスの動きも描き直しの後の `click` の行き先も見ない。だから撮る道具（`tools/shots`。Windows の CI の Electron）に、本物のマウスの押し（`webContents.sendInputEvent`）で閉じ方を見る確かめを足す（OD-3）。撮る画像は変えない。

## 受け渡す名前と形

- `popOpen(el, { close, anchors = [], name })`: `el` は入れた後の窓の要素。`close(why)` は窓を閉じる今の関数を呼ぶ物（`why` は `'outside'`・`'esc'`・`'other'`・`'modal'`。外の押しと Esc の扱いの違い（決めたこと 6）は `close` の中で `why` を見て決める）。`anchors` は開いた部品（列の見出しのボタン・「ロック中」・⚙ など。描き直しで替わる物は開いたときの要素）。`name` はテストと記録のための短い名前（`'dbmenu'`・`'lock'`・`'panel'`・`'pick'` など。画面には出さない）。新しい窓を中に持つ窓（親）のほかを `close('other')` で閉じてから帳面に足す。
- `popDrop(el)`: 帳面から外すだけ（閉じる今の関数の頭で呼ぶ。2回呼んでもよい）。帳面の窓が木から外れていたら（描き直し）、次の受け口で黙って外す。
- `popCloseAll(why)`: 帳面の全部を新しい順に `close(why)`。
- テストの口は足さない（テストは窓の要素の有る無し（`.dbmenu`・`.dbpanel`・`.dbpick`・`.lockmenu`・`.treemenu`・`#pMenu` の `hidden` など）と、送った命令（`l.called`）を見る）。
