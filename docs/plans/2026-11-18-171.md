## 目的

1. **浮く窓（メニュー・選びの窓・設定の窓）は、どれも同じ決まりで閉じる:** 外を押すと閉じる・Esc で閉じる（フォーカスが窓の外にあっても）・開くのは1つ（別の窓を開くと前の窓は閉じる）。**メニューの外の押しは閉じるだけで、その1回の押しは押した所に届かない**（Notion の列のメニューと同じ。PQ171-3・N171-1・N171-2）。設定の窓も同じく閉じるだけ（2026-11-21 の PQ171-6 の答え）。
2. **閉じ方を1つの仕組みにまとめる:** 今は窓ごとに閉じ方が違い（`focusout` で閉じる窓・`document` の `pointerdown` で閉じる窓・何も持たない窓）、0.16.0・0.17.0 で足した窓の多くが何も持たなかった。窓ごとに閉じ方を足すのでなく、画面に1つの「開いている窓の帳面」を置き、そこで外の押し（と、その押しを止めること）と Esc と「開くのは1つ」を受ける。後で窓を足しても、帳面に載せるだけで同じに閉じる（PQ171-2）。
3. **0.17.1 として、0.18.0 より先に出す**（PQ171-1）。

## 調べた結果（`15a6e98` で調べた）

### 1. 原因（持ち主が見つけた2つ）

1. **列の見出しのメニューには、外を押したときに閉じる受け口が無い。** 列のメニュー（`dbColMenu`。13268）は、データベースのメニューの共通の作り `dbMenuAt`（13155〜13190）で作る。`dbMenuAt` は窓を `st.host` に入れて `st.menu` に覚え、閉じる道は (a) 窓の中にフォーカスがあるときの Esc（13176 の `m.onkeydown`）、(b) 同じ見出しをもう一度押す（13272 の `st.menu.dataset.col === colId` のときの `dbMenuClose`）、(c) 同じ表の別のメニューを開く（`dbMenuAt` の頭の `dbMenuClose()`・`dbPanelClose()`）、(d) 項目を選ぶ、(e) 表の描き直し（`dbPaint` の `box.textContent = ''`。11816）だけ。`focusout` の受け口も `document` の `pointerdown` の受け口も無い。だから外の余白・題名・ほかのボタンを押しても開いたまま。**持ち主の「再度フィルターを選択しないと閉じない」は (b) のこと。**
2. **「ロック中」の［ロックを外す］にも、外を押したときに閉じる受け口が無い。** 0.17.0 LK-1 の `$('pLock').onclick`（7564〜7579）は、サイドバーの行のメニュー（`openTreeMenu`。6309）と同じ形（`blockmenu` の箱・`menuItem`・Esc・Tab）で作ったが、行のメニューの閉じ方の1行（6345 の `box.addEventListener('focusout', …)`）を写していない。閉じる道は、もう一度「ロック中」を押す・窓の中の Esc と Tab・［ロックを外す］を押す、だけ。
3. **2つが同時に開くのは、窓どうしが互いを知らないから。** `dbMenuAt` が閉じるのは同じ表の `st.menu` と `st.panel` だけで、`lockMenu` を閉じない。「ロック中」を押しても `st.menu` を閉じない。どちらも外の押しで閉じないので、列のメニューを開いたまま「ロック中」を押すと2つが並ぶ（持ち主の画面のとおり。下の 2 で本物の Chromium で同じ形を出した）。
4. **Esc は、フォーカスが窓の中にあるときしか効かない。** どちらの窓も Esc の受け口が窓そのもの（`m.onkeydown`・`box.onkeydown`）にあるので、外を押してフォーカスが題名などへ動いた後の Esc では閉じない。

**指された `mousedown` の行（12843・14143）について:** セルの選びの窓（行のページの `rpOpenWriter` と表の `dbOpenWriter`）の `pop.addEventListener('mousedown', … preventDefault)` は、**窓の中**の文字や余白を押したときに、フォーカスを窓の探す欄に残すためのもの（0.16.0 rv48 F2）で、外の押しには効かない。選びの窓が外の余白の押しで閉じないのは、その下の `focusout` の受け口（12849・14151）が「行き先（`relatedTarget`）が窓の外の部品のときだけ閉じ、行き先が無いときは閉じない」形だから（0.16.0 rv49 M-b・R95: 選ぶたびに窓を描き直してフォーカスが行き先無しに外れるので、そのときに閉じないため）。押せない余白（ページの頭など）を押すと、フォーカスは行き先無しに外れるので閉じない。暦（`date`）の受け口は行き先が無くても決めて閉じる（0.16.0 R82）ので、暦は閉じる。

**閉じる窓との違い:** サイドバーの行のメニュー（6345）・⋮⋮ のメニュー（15676）・プライベートの［···］（7112）・パンくずの［…］（2903）・リンクの窓（10967）・/リンクドビュー の窓（11190）は、`focusout` の後に `setTimeout` で `document.activeElement` が窓の外かを見て閉じる。Chromium では押せない所を押してもフォーカスが外れる（`activeElement` が `body` になる）ので、外の押しで閉じる。ページの［···］（`#pMenu`）は `document` の `pointerdown`（7615）で閉じる。ただし `focusout` で閉じる窓も、**押したときにフォーカスを動かさない部品**（`mousedown` を止める部品: 本文の行の ＋（16098）・トグルの ▸（16134）・文字の飾りの帯のボタン（10893）・色の並び（11052）・/ メニュー（15088）・選びの窓の中）を押すと閉じない（下の表の 24 行目。本物の Chromium で、サイドバーの行のメニューを開いたまま本文の行の ＋ を押すと残った）。

15. **（第2版）止める押し（「閉じるだけ」の作り）:** 外の押しで、閉じるだけの窓を1つでも閉じたとき、帳面はその押しを「止める押し」として覚え（止める印。押しの番号 `pointerId` とボタン）、その押しの事象を、押した所のどの受け口よりも先に止める（`preventDefault` と `stopImmediatePropagation`）: `pointerdown`・`mousedown`・`pointerup`・`mouseup`・`click`・`auxclick`・`contextmenu`・`dblclick`・`dragstart`・`selectstart`。止める受け口は `document` の捕まえる段（capture）に、`app.html` の同じ段のどの受け口よりも先に付ける（同じ段の受け口は付けた順に呼ばれる。今ある `document` の捕まえる段の `mousedown`（3186。押している間の印）より前に付ける）。**理由:** Chromium では `pointerdown` を止めても `click` は来る。フォーカスの移り・字の選び・`draggable` の引っ張りの始まりは `mousedown` の既定の動きなので、`mousedown` を止めないと止まらない。`mousedown` の既定を止めると、フォーカスは動かず（題名に字が入らない: MC-01）、字の選びも引っ張りも始まらない。**失うもの:** 窓が開いているときの1回目の押しは、どの部品にも届かない（決めたこと 7）。
16. **（第2版）止める印を外す時:** その押しの `click`（左）、`contextmenu` か `auxclick`（右）が来たとき。来なくても、離した（`pointerup`・`mouseup`）後の時限 0（`click` はその前に届く: 0.15.1 R44 の `pressEnd` と同じ見込み）・`pointercancel`・窓のフォーカスが外れた（`window` の `blur`）・押してから5秒（押している間の印と同じ上限）で外す。窓が無いときは何も止めない。止める印と違う押しの番号の事象は止めない。**理由:** 印が残ると、次の押しが黙って届かなくなる（どこを押しても効かない画面になる）。

19. **（第2版）窓の中の押し:** 開いている窓の中を押したときは、その窓より新しい窓（子）だけを閉じ、その押しは止めない（親の窓の項目はそのまま1回で押せる。⋮⋮ の［変換 ▸］を開いたまま親の［削除］を押すと、子が閉じて［削除］が動く）。

- `popOpen(el, { close, anchors = [], name })`（2026-11-21: `pass` は作らない。R2）: `el` は入れた後の窓の要素。`close(why)` は窓を閉じる今の関数を呼ぶ物（`why` は `'outside'`・`'esc'`・`'other'`・`'modal'`。外の押しと Esc の扱いの違い（決めたこと 6）は `close` の中で `why` を見て決める）。`anchors` は開いた部品（列の見出しのボタン・「ロック中」・⚙ など。描き直しで替わる物は開いたときの要素）。Esc でフォーカスを戻す先に使う。`name` はテストと記録のための短い名前（`'dbmenu'`・`'lock'`・`'panel'`・`'pick'` など。画面には出さない）。~~**（第2版）`pass`** は外の押しを止めない窓の印（今は設定の窓だけが `true`。決めたこと 11）。~~（2026-11-21: PQ171-6 の答えで使う窓が無くなったので作らない。R2）新しい窓を中に持つ窓（親）のほかを `close('other')` で閉じてから帳面に足す。
