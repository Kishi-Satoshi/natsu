# NaTsu 試験利用のお願い（0.8.0）

NaTsu は、会議を録音して文字起こしし、要約まで作る Windows のアプリです。
試験的に使って、気づいたことを教えてください。

## 用意するもの

- Windows 10 / 11（64bit）の PC。ディスクの空きが約 7GB。
- 会社のメールアドレス（ログインに使います）。
- Claude の有料プラン（Pro・Max・Team など）。要約に使います。

所要時間は 30 分〜1 時間半ほどです。ほとんどは手順3の取り込みの待ち時間です。

---

## 手順1. インストールする

1. https://github.com/Kishi-Satoshi/natsu/releases/latest を開きます。
2. 「Assets」の中の `NaTsu-0.8.0-setup.exe` だけをダウンロードし、ダブルクリックします。
   - 管理者の権限は聞かれません。
   - 「Windows によって PC が保護されました」と出たら、［詳細情報］→［実行］で進めてください（署名を付けていないため出ます）。
   - ダウンロードが途中で止まるときは、同じページの `get-installer.ps1` を落として実行してください。

## 手順2. ログインする

1. NaTsu を起動し、［設定］の「アカウント」の［ログイン］を押します。英語のログインの画面が出ます。
2. 会社のメールアドレスを入れて［Send login code］を押します。
3. Cloudflare から英語のメールが届くので、6 けたのコードを入れて［Sign in］を押します。
   - 届かないときは、迷惑メールのフォルダも見てください。
   - 「already been used」と出たら、［Request new code］で頼み直してください。
4. カードが「ログイン中: …」になれば済みです。ログインは 7 日で切れ、切れたら知らせが出ます。

## 手順3. PC の中の文字起こしを取り込む（約 5.6GB）

この版では、この取り込みが済まないと録音を始められません（次の 0.9.0 から不要になる予定です）。

1. ［設定］→「オフライン」の［PC の中の文字起こしを取り込む］を押します。
2. 回線によって 15 分〜1 時間ほどかかります。途中で切れても、続きから取り込みます。
3. 「PC の中の文字起こし：使えます」と出て、［PC の中で試す］で OK が出れば済みです。

## 手順4. Claude Code を入れる（要約に使います）

1. PowerShell で次を実行します（管理者の権限は要りません）。
   `irm https://claude.ai/install.ps1 | iex`
2. PowerShell を開き直して `claude` と打ち、claude.ai のアカウントでログインします。終わったら `/exit` で閉じます。
3. NaTsu の［設定］→「オンライン」の［Claude Code を確かめる］で「ログイン済み」と出れば済みです。

---

## 使い方

- **Alt+M** で議事録の記録を始め、もう一度 Alt+M（または録音バーの赤い ■）で止めます。止めると要約が作られます。
- Teams などの相手の声も録るときは、［設定］→［動作］の「議事録で相手の声も録る（パソコンから出ている音）」を有効にしてください。
- **Ctrl+Shift+Space** で音声入力（話した言葉を、今開いている場所に入力）ができます。

## 気をつけてほしいこと

- ログインしていてインターネットにつながっているときは、会議の音声を OpenAI に送って文字起こしします（会社の中継を通します。中継は音声も文字も保存しません）。要約は、ご自分の Claude Code に文字起こしの文を渡して作ります。
- **1on1・面談・人事の話など、外に出したくない会議では、記録中に議事録の画面の［この会議は PC の中だけ］を押してください。** 押した後の音声は外へ送りません。
- 議事録は、この PC の中にだけ保存されます。試験中は、大事な記録は別にも残しておいてください。

## 教えてほしいこと

気づいたことは Teams で連絡してください。次の3つがあると助かります。

1. 何をしたか（どの画面で、どのボタンを押したか）
2. 何が起きたか（出た文はそのまま。画面の写真があれば一番助かります）
3. だいたいの時刻

特に見てほしいところ:

- ログインやコードのメールで迷ったところ
- 録音中のページの「文字起こし中（クラウド）・最後の文字 ◯ 秒前」の表示が、実際の動きと合っているか
- 赤い帯が出たときに、何をすればよいか分かったか
- 文字起こしと要約の出来（聞き間違い・抜け・要約の分かりやすさ）
