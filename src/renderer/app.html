一般

アカウント

会社のメールアドレスでログインすると、インターネットにつながっているときに、会議と音声入力の音声を文字起こしの中継に送り、OpenAI で文字起こしします。ログインしていないときと、つながっていないときは、PC の中で文字起こしします。
［ログイン］を押すと、ログインの画面が別の窓で開きます。画面は Cloudflare（中継を守る仕組み）のもので、英語です。会社のメールアドレスを入れて［Send login code］を押し、届いたメール（差出人は Cloudflare。英語）の 6 けたのコードを入れて［Sign in］を押してください。ログインできると、窓は自動で閉じます。
コードのメールが届かないときは、迷惑メールのフォルダも見てください。「already been used」と出たら、［Request new code］でコードを頼み直してください（会社のメールの検査が、先にコードを使ってしまうことがあります）。

録音バー

マイクと相手の声

Windows の「既定の再生デバイス」に出ている音が録音されます。 アプリ側から選ぶことはできない仕組みのため、変えたいときは Windows のサウンド設定で既定のデバイスを切り替えてください。 録音の開始時点のデバイスに固定されます（録音中に切り替えても追従しません）。

文字起こし

ログインしていて、インターネットにつながっているときは、会議と音声入力の音声を文字起こしの中継に送り、OpenAI（gpt-4o-transcribe）で文字起こしします。中継も OpenAI も、音声と文字を保存しません。つながっていないときは、いつも PC の中で文字起こしします。1on1・面談など外に出したくない会議は、議事録の画面の［この会議は PC の中だけ］を押してください。
記録中はエンジンの設定を変更できません

ユーザー辞書（認識ヒント）

固有名詞・社内用語をエンジンへ渡し、認識精度を上げます。

要約（Claude Code）

［Claude Code を入れる］は、PowerShell の窓で Anthropic の公式の入れ方 irm https://claude.ai/install.ps1 | iex を実行します（インターネットから取った命令をそのまま実行します。Git for Windows は無くても動きます）。 ［Claude Code にログイン］はログインの窓を開きます（NaTsu はログインの情報を読みません）。要約は各自の Claude のプランの上限（5時間ごと・週ごと）を使います。

オフライン

インターネットにつながっていないときと、［この会議は PC の中だけ］の会議でも、この PC の中で文字起こしと要約ができるようにする準備です（任意）。準備しなくても、インターネットにつながっていてログインしていれば、会議と音声入力はそのまま使えます。
記録中は PC の中の文字起こしの設定を変更できません

詳細設定

文字起こし（whisper.cpp・オフライン）

通常は変更不要です。スレッド数は文字起こしに使うCPUの数 （初期値はこのPCのコア数−2。増やすと速くなりますが、他の作業が重くなります）。 ポートはこのPCの中だけで使う通信の番号で、他のソフトと番号が ぶつかって PC の中の文字起こしが起動できないときだけ変えてください。

要約（llama.cpp・オフライン）— 議事録の自動要約に使用

初回セットアップ: setup-summarizer.ps1 を実行。未設定でも文字起こしは使えます。
通常は変更不要です。意味は文字起こしエンジンの欄と同じです （こちらは要約に使われます）。2つのエンジンのポートは別の番号にしてください。
要約エンジンに渡すトークン数（-c）。既定 16384。大きいほどメモリを使い、小さいと長い会議の統合で足りなくなります

記録とメモリ

短いほど早く画面に出ますが、文の切れ目が増えます（既定75秒。最初の1回は20秒）。
記録中は PC の中の文字起こしの設定を変更できません
記録も要約もしていない時間がこれを超えたらエンジンを止めてメモリを空けます（次に使うとき起動し直します。0 で止めない）

アップデート

更新はアプリ本体（数百KB）のみを取得します。エンジンやモデル、保存済みの議事録はそのままです。
更新前のバージョンは src.backup-* として1世代だけ残ります。
