会議の検出

会議のアプリがマイクを使い始めたら、録音するか聞きます。

NaTsu は音を聞きません。Windows の「マイクを使っているアプリ」の記録だけを見ます。

  • 見るアプリ: Teams・Zoom・Webex・Slack・ブラウザ（Chrome・Edge・Firefox。Google Meet など）。
  • 録音しているときと、NaTsu が自分でマイクを使っているときは出しません。同じ会議では1度だけです。
  • 30 秒で消えます（カーソルを乗せている間は消えません）。押さなければ何も録りません。
  • 窓の題名・URL は読みません。何も外へ送りません。
  • Windows でだけ動きます。Mac では出ません。
Esc で閉じる
会議のアプリがマイクを使わなくなったら、録音を止めて議事録を作ります。

会議のアプリがマイクを使わなくなったら、会議を出たとみなして、聞かずに録音を止めて議事録を作ります。止まるのは出てから 6 秒ほど後で、止めた後に Windows の知らせを 1 回出します。

  • 見るアプリ: Teams・Zoom・Chrome・Edge。ブラウザでは、会議でないタブがマイクを使って放したときにも止まることがあります。
  • 数秒だけマイクを放したとき（会議に入るとき・マイクの機器を素早く替えたときなど）は止めません。6 秒ほどより長く放すと止まるので、そのときは新しい議事録で録り直してください。
  • 一時停止の間は数えません。
  • 録音中も 2 秒ごとに、Windows の「マイクを使っているアプリ」の記録を読みます。
Esc で閉じる

  • アプリの側からは選べない仕組みです。変えたいときは［Windowsの設定］で既定のデバイスを切り替えてください。
  • 録音を始めた時点のデバイスに固定されます（録音中に切り替えても追いかけません）。

話し声が無いとき

話し声が続けて無いと「会議は終わりましたか？」と聞きます。

聞いてから 5 分たっても答えが無ければ、録音を止めて議事録を作ります。

  • 聞くのは、録音中のページ・録音バー・Windows の知らせです。
  • 話し声の無い終わりの部分は、所要時間に入れません。
  • 一時停止の間は数えません。

文字起こし

つながっているときはクラウド、つながっていないときは PC の中で文字起こしします。

中継も OpenAI も、音声と文字を保存しません。

  • ログインしていて、インターネットにつながっているときは、会議と音声入力の音声を文字起こしの中継に送り、OpenAI（gpt-4o-transcribe）で文字起こしします。
  • つながっていないときは、いつも PC の中で文字起こしします。
  • ネットワークが不安定なときは、議事録の画面の［オフラインモード］で、その会議の文字起こしを PC の中で行います。
Esc で閉じる

要約（Claude Code）

要約は各自の Claude Code で作ります。

要約は、各自の Claude Code で作ります。

  • ［Claude Code を入れる］は、PowerShell の窓で Anthropic の公式の入れ方（irm https://claude.ai/install.ps1 | iex）を実行します。インターネットから取った命令をそのまま実行します。Git for Windows は無くても動きます。
  • ［Claude Code にログイン］はログインの窓を開きます（NaTsu はログインの情報を読みません）。
  • 要約は各自の Claude のプランの上限（5 時間ごと・週ごと）を使います。
  • 要約のモデルは Claude の Sonnet の最新版に固定しています（選べません。新しい Sonnet が出ると自動で切り替わります）。
Esc で閉じる

Claude との連携（MCP）

Claude デスクトップから議事録を読めるようにします。
※ 読んだ議事録は Claude（Anthropic）へ送られます。

Claude に「10/20 の議事録を読んでレポートして」のように頼めます。

  • Claude は議事録を読むだけで、書き換えません。
  • Claude に頼むと、Claude が読んだ議事録の題名・要約・メモ・文字起こしは、Claude（Anthropic）へ送られます（オフラインモードで録った会議も同じです）。
  • 1on1・面談の議事録を扱う前に、Claude の設定のプライバシーで、会話をモデルの学習に使わない設定にしてください。
  • 登録の前と、NaTsu を入れ直す前は、Claude デスクトップを終了してください（タスクトレイのアイコンからも）。
  • 議事録を消しても、Claude が一度読んだ内容は Claude の会話に残ります。
Esc で閉じる
Claude デスクトップの設定に NaTsu の MCP を足します。

打ち合わせの質

要約の最後に、会議の進め方の目安を 25 点で付けます。

目的と結論・抜け・重なり・決定事項・ToDo の具体さ・型の埋まり具合を 5 点ずつ見ます。

  • 人の評価ではありません。
  • 同じ会議でも作り直すと 1 点ほど動くので、何回かの会議の流れで見てください。
  • 1on1 と採用面接・事前面談にも付けます。外すときは「1on1 と採用面接・事前面談を除いて付ける」を選びます。
  • 点を付けない会議にも、要約の最後に「次に気をつけること」は付きます。
Esc で閉じる
人の評価ではなく、会議の進め方の目安です。
