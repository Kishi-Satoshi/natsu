録音中に文字起こしの問題が起きると、録音中のページの頭に帯が出ます。
帯には理由と、すること（ボタンがあれば1つ）が書いてあります。直れば帯は自分で消えます。

> [!NOTE]
> どの帯が出ていても、録音はそのまま続いています。録音を止める必要はありません。

## ボタンのある帯 {#with-button}

| 帯の文（はじめの部分） | すること |
| --- | --- |
| PC の中の文字起こしエンジンが動いていません（音声は残してあります）。 | ［エンジンを確かめる］ を押します。［設定］の「オフライン」が開くので、取り込みが済んでいるかを見て、［PC の中で試す］ を押します |
| 文字起こしが止まっているかもしれません（音はあるのに、約 … 秒文字が出ていません）。 | ［もう一度］ を押して、その区間を送り直します |
| … 区間の文字起こしに失敗しました（音声は残してあります）。 | ［もう一度］ を押します |
| ログインが切れたため、PC の中で文字起こししています。 | ［ログインし直す］ を押します。［設定］の「アカウント」が開くので、［ログイン］ からもう一度ログインします |

## ボタンの無い帯 {#no-button}

その区間から PC の中で文字起こしを続けています。多くは待つだけです。

| 帯の文（はじめの部分） | すること |
| --- | --- |
| 中継につながりません。 | 待ちます。続くときは、インターネットにつながっているかを見ます |
| 文字起こしの中継が混み合っているため、PC の中で文字起こししています。 | 待ちます |
| OpenAI が混み合っているため、… 秒待ってから送り直しています。 | 待ちます |
| 今日のクラウドの文字起こしの上限に達したため、… | 今日の残りは PC の中で文字起こしします。翌日（日本の日付）には戻ります |
| 文字起こしの中継が今は使えないため、… | 続くときは管理者に知らせます |
| 文字起こしの中継につながりません（会社の通信の検査で止められている可能性があります）。 | 続くときは、情報システムに、帯に出た接続先への通信の許可を頼みます |

## 録音中のページを見ていないとき {#windows}

止まる・行動が要る問題（エンジンが動いていない・止まっているかもしれない・ログイン切れ・失敗した区間がある）は、Windows の知らせで1回知らせます。
知らせが出たら、NaTsu の録音中のページを開いて、帯を見てください。
