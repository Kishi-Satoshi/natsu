録音中に文字起こしの問題が起きると、録音中のページの頭に帯が出ます。
帯には理由と、すること（ボタンがあれば1つ）が書いてあります。直れば帯は自分で消えます。

> [!NOTE]
> どの帯が出ていても、録音はそのまま続いています。録音を止める必要はありません。

## ボタンのある帯 {#with-button}

| 帯の文（はじめの部分） | すること |
| --- | --- |
| PC の中の文字起こしエンジンが動いていません（音声は残してあります）。 | ［エンジンを確かめる］ を押します。［設定］の「ローカル AI の設定」が開くので、取り込みが済んでいるかを見て、［PC の中で試す］ を押します |
| 文字起こしが止まっているかもしれません（音はあるのに、約 … 秒文字が出ていません）。 | ［もう一度］ を押して、その区間を送り直します |
| … 区間の文字起こしに失敗しました（音声は残してあります）。 | ［もう一度］ を押します |
| ログインが切れたため、この PC で文字起こしを続けていますが、精度が落ちます。 | ［ログインし直す］ を押します。［設定］の「アカウント」が開くので、［ログイン］ からもう一度ログインします |
| ログインしていないため、音声を残しています。 | ［ログイン］ を押してログインします。残した音声は、ログインすると文字起こしします |
| この会議はオフラインモードです。PC の中の文字起こしが入っていないので、音声だけを残しています（外には送りません）。 | 外へは送りません。PC の中で文字起こしするときは、［ローカル AI の準備］ を押して取り込みます（[ローカル AI の設定](settings/offline.md)） |
| … 分ほど話し声がありません。会議は終わりましたか？ このままなら 5 分後に録音を止めて議事録を作ります。 | 会議が続いているなら ［続ける］、終わっていれば ［終了して作成］ を押します。押さずに 5 分たつと、録音を止めて議事録を作ります（[話し声が無いときに自動で止める](record/start-stop.md#auto-stop)） |

## ボタンの無い帯 {#no-button}

多くは待つだけです。「この PC で文字起こしを続けていますが、精度が落ちます」と書いた帯は、その区間から PC の中で文字起こしを続けています。

| 帯の文（はじめの部分） | すること |
| --- | --- |
| NaTsu のサーバーにつながりません。この PC で文字起こしを続けていますが、精度が落ちます。 | 待ちます。続くときは、インターネットにつながっているかを見ます |
| ネットワークにつながっていません。この PC で文字起こしを続けていますが、精度が落ちます。 | 会議の途中でネットワークから外れました。つながると消えます |
| 文字起こしの中継が混み合っているため、この PC で文字起こしを続けていますが、精度が落ちます。 | 待ちます |
| OpenAI が混み合っているため、… 秒待ってから送り直しています。 | 待ちます |
| 今日のクラウドの文字起こしの上限に達したため、今日の残りはこの PC で文字起こしします。精度が落ちます。 | 今日の残りは PC の中で文字起こしします。翌日（日本の日付）には戻ります |
| 文字起こしの中継が今は使えないため、この PC で文字起こしを続けていますが、精度が落ちます。 | 続くときは管理者に知らせます |
| 文字起こしの中継につながりません（会社の通信の検査で止められている可能性があります）。 | 続くときは、情報システムに、帯に出た接続先への通信の許可を頼みます |

## 音声を残している帯 {#kept}

ローカル AI の準備をしていない PC では、クラウドで文字起こしできない区間の音声を残し、次の帯で知らせます。
残した区間は、文字起こしに「（文字起こし待ち: 音声は残してあります）」と出ます。

| 帯の文（はじめの部分） | すること |
| --- | --- |
| PC の中の文字起こしが入っていないので、音声を残しています。オンラインに戻ると文字起こしします。 | 待ちます。つながると自動で文字起こしします |
| 文字起こしの中継が今は使えないため、音声を残しています。使えるようになると自動で文字起こしします。 | 待ちます |

会議を止めた後も、残した音声はつながると自動で文字起こしし、済むと要約も自動で作ります（[文字起こしが止まる](trouble/transcription-stops.md#kept)）。

## 録音中のページを見ていないとき {#windows}

止まる・行動が要る問題（エンジンが動いていない・止まっているかもしれない・ログイン切れ・失敗した区間がある）は、Windows の知らせで1回知らせます。
知らせが出たら、NaTsu の録音中のページを開いて、帯を見てください。
ネットワークから外れた帯と、音声を残している帯は、Windows の知らせにはしません。
