録音を止めると、文字起こしとメモから要約を作ります。
どこで作ったかは、議事録の上の行に「✨ 要約: Claude Code」「🖥 要約: PC（オフライン）」のように出ます。

## どこで作るか {#where}

- **インターネットにつながっているとき:** ご自分の Claude Code に、文字起こしの文・メモ・要約タイプの指示を渡して作ります。Claude Code はそれを Claude（Anthropic）へ送ります。要約は中継を通りません。
- **つながっていないとき:** PC の中の要約エンジンで作ります。
- **［オフラインモード］ を押した会議:** つながっていても、PC の中の要約エンジンで作ります。

オンラインで Claude Code が使えないとき（入っていない・ログイン切れ・上限）は、PC の中の要約に黙って切り替えません。要約の欄に理由と直し方を出します。

## 作り直す {#regenerate}

- 要約の無いページでは、右上の ［要約を生成］ を押します。
- 要約のあるページでは、上の帯の「···」の ［要約を再生成］ を押します。要約タイプを変えたときや、出典を付け直したいときに使います。

## 要約に使うモデル {#model}

要約のモデルは、Claude の Sonnet の最新版に固定しています。選べません。新しい Sonnet が出ると、自動で切り替わります。
要約は、ご自分の Claude のプランの上限を使います（下の「上限」）。

## 上限 {#limits}

要約は、ご自分の Claude のプランの上限（5時間ごと・週ごと。Claude のチャットと同じ上限）を使います。
上限に達すると、戻る時刻を要約の欄に出します。戻ってから ［要約を生成］ を押してください。
Claude Code が 15 分たっても要約を返さないときは止めます。［要約を生成］ でもう一度試せます。
