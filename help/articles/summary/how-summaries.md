録音を止めると、文字起こしとメモから要約を作ります。
どこで作ったかは、議事録の上の行に「✨ 要約: Claude Code」のように出ます（0.9.x で PC の中で作った要約は「🖥 要約: PC（オフライン）」のままです）。

## どこで作るか {#where}

- **いつも:** ご自分の Claude Code に、文字起こしの文・メモ・要約タイプの指示を渡して作ります。Claude Code はそれを Claude（Anthropic）へ送ります。要約は中継を通りません。
- **［オフラインモード］ を押した会議:** ほかの会議と同じく Claude Code で作ります（0.10.0 から。0.9.x までは PC の中で作っていました）。
- PC の中では要約しません（0.10.0 から）。

## つながっていないとき（要約待ち） {#wait}

会議の終わりにインターネットにつながっていないときは、要約を作らずに、要約の欄に「要約待ち（つながったら作ります）」と出します。
つながったら、NaTsu が自動で1回作ります（［要約を生成］ を押して先に作ることもできます）。
Claude が混み合っていて断ったときは要約待ちのまま、次につながったときにもう一度試します。Claude Code が入っていない・ログインが切れたなど、ほかの理由で作れなかったときは、要約の欄に理由と直し方を出します。

録音中・要約を作っている間・要約待ちの間は、要約の欄を直せません（欄の上に理由が出ます）。書きたいことはメモに書いてください。要約ができると直せます。

## 作り直す {#regenerate}

- 要約の無いページでは、右上の ［要約を生成］ を押します。
- 要約のあるページでは、上の帯の「···」の ［要約を再生成］ を押します。要約タイプを変えたときや、出典を付け直したいときに使います。

## 要約に使うモデル {#model}

要約のモデルは、Claude の Sonnet の最新版に固定しています。選べません。新しい Sonnet が出ると、自動で切り替わります。
要約は、ご自分の Claude のプランの上限を使います（下の「上限」）。

## 上限 {#limits}

要約は、ご自分の Claude のプランの上限（5時間ごと・週ごと。Claude のチャットと同じ上限）を使います。
上限に達すると、戻る時刻を要約の欄に出します。戻ってから ［要約を生成］ を押してください。
Claude Code が 15 分たっても要約を返さないときは止めます。［要約を生成］ でもう一度試せます。
