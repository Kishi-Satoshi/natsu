要約の欄の行は、1行ずつ書き直せます。行を押して打ち、ほかの所を押すか別のページへ移ると保存します。打つ手が 2 秒止まったときも保存します。
録音中・要約を作っている間・要約待ちの間は直せません（欄の上に理由が出ます）。メモの欄も同じ行の欄で、同じように書けます（[メモも行で書く](#memo)）。文字起こしの直し方は今までどおりです。

## 行を分ける・つなぐ {#rows}

- **[[Enter]]:** カーソルの所で行を2つに分けます。後ろの行は同じ型です（見出しの後は箇条書き、引用とコールアウトの後はテキスト）。空の箇条書き・ToDo・番号付きで押すと、テキストの行に戻ります。
- **[[Shift+Enter]]:** 行を分けずに、行の中で改行します。
- **行の頭で [[Backspace]]:** 見出し・箇条書きなど型の付いた行は、まずテキストの行に戻します。テキストの行は、すぐ上の行の終わりにつなぎます。
- **行の頭で [[↑]]・行の終わりで [[↓]]:** 上・下の行へ移ります。
- **貼り付け:** 貼った文の見出しや箇条書きは行に、太字などは飾りになります（[貼り付け](#paste)）。

日本語入力で変換を確定する [[Enter]] は、行を分けません。

## / のメニューで型を選ぶ {#slash}

行の頭か空白の後で、半角の `/` を打つとメニューが出ます。
続けて打った言葉で絞り込めます（「みだし」「todo」「h1」など）。「とぐる」で「トグル」、「とぐるみだし」で「トグル見出し1〜3」が出ます。[[↑]]・[[↓]] で選び、[[Enter]] で決めます。[[Esc]] で閉じると、打った `/` と言葉はそのまま残ります。

- 何も書いていない行では、その行の型が変わります。
- 文のある行では、その下に選んだ型の行を足します。
- 色の名前を打つと、型の後ろに「文字の色」「背景の色」が出ます（[行の色](#marks)）。
- 日本語入力がオンのままだと `/` が「・」になります。半角に切り替えてから打ってください。

メニューの頭には、メニューで選んだ型のうち新しい3つが「最近使ったもの」として出ます。覚えるのは型の名前だけで、この PC に覚えます（会議の題名や文は覚えません）。

## 行の頭の記法 {#markdown}

行の頭で打つと、その行の型に変わります。後ろに文がある行でも変わり、文はそのまま残ります（全角の記号と空白でも変わります）。

| 打つもの | 変わる型 |
| --- | --- |
| `- `・`* `・`+ ` | 箇条書き |
| `[] ` | ToDo |
| `1. ` | 番号付き |
| `# `・`## `・`### ` | 見出し1・見出し2・見出し3 |
| `" ` | 引用 |
| `> ` | トグル |
| `---` | 区切り線（何も書いていない行だけ。下にテキストの行を足します） |

文の途中では変わりません。日本語入力の変換中も変わりません（確定した後に変わります）。
貼り付けた文の記法は、貼り付けたときに行に変えます（[貼り付け](#paste)）。
変わった直後に [[Ctrl+Z]] を押すと、型が戻り、打った記号（「- 」など）が行の頭に戻ります。

## 文字の飾り・リンク・色 {#marks}

行の中で文字を選ぶと、選んだ所の上に、太字・斜体・下線・取り消し線・コード・リンク・［色 ▸］ のボタンの帯が出ます。ボタンに乗せると、名前とキーが出ます。キーでも付けられます。

| 飾り | キー | 打って付ける |
| --- | --- | --- |
| 太字 | [[Ctrl+B]] | `**文字**` |
| 斜体 | [[Ctrl+I]] | `*文字*` |
| 下線 | [[Ctrl+U]] | （ありません） |
| 取り消し線 | [[Ctrl+Shift+S]] | `~文字~` |
| コード | [[Ctrl+E]] | 文字を半角のバッククォートで挟む |

- 選んだ所が全部その飾りなら外し、一部だけなら全部に付けます。文字を選んでいないときは、キーを押しても何も起きません（先に打ってから選んでください）。
- 打った文字は、すぐ前の文字の飾りを引き継ぎます（コードとリンクの終わりでは引き継ぎません）。
- 「打って付ける」の記号は半角だけです。閉じる記号を打ったときに飾りに変わり、記号は消えます。日本語入力の変換中は変わりません（確定した後に変わります）。変わった直後に [[Ctrl+Z]] を押すと、記号のある文に戻ります。

**リンク:** 文字を選んで [[Ctrl+K]] を押すか、帯のリンクのボタンを押すと、小さな欄が出ます。住所を貼って [[Enter]] か ［リンクを付ける］ を押します。［外す］ で、選んだ所のリンクを外します。

- 付けられるのは https・http・mailto と NaTsu のリンク（議事録へのリンク）だけです。ほかの住所では「開けるのは https・http・mailto と NaTsu のリンクだけです」と出ます。
- 文字を選んだまま URL を貼り付けても、文字はそのままでリンクになります。
- リンクの文字は、[[Ctrl]] を押しながらクリックすると開きます（ふつうのクリックはカーソルを置くだけです）。乗せると住所が出ます。

**文字の色:** 帯の ［色 ▸］ で、「文字の色」と「背景の色」の2列から選びます。どちらの列も「既定」と9色（灰・茶・橙・黄・緑・青・紫・桃・赤）です。

- 1つの所に付く色は1つです。どちらの列で選んでも、選んだ所の前の色（文字の色も背景の色も）を、選んだ色に置き換えます。
- 「既定」は、選んだ所の色を全部外します。
- [[Ctrl+Shift+H]] は、最後に使った色を選んだ所にもう一度付けます。

**行の色:** 行の全体に色を付けるときは、⠿ のメニュー（[[Ctrl+/]] でも出ます）の ［色 ▸］ で選びます。/ のメニューでも、`/あか`・`/red` のように色の名前を打つと文字の色、「/あかいはいけい」のように打つと背景の色が出ます。

飾りは ［コピー］ で Markdown の記号（太字は `**`・斜体は `*`・取り消し線は `~~`・コードはバッククォート・リンクは `[文字](住所)`）で写ります。下線と色は文字だけが写ります。検索と、Claude デスクトップから読む要約には、文字だけが渡ります。

## ＋ と ⠿ {#handles}

行にマウスを乗せると、左に ＋ と ⠿ が出ます。

- **＋:** 下に行を足して、/ のメニューを開きます。
- **⠿ を引っ張る:** 行を並べ替えます。落とした所の、画面で上に見えている行の後ろに入ります。[[Alt]] を押しながら落とすと、そこへ写しを作ります。
- **⠿ を押す:** ［削除］［複製］［変換 ▸］［色 ▸］ のメニューが出ます（行を右クリックしても、行の中で [[Ctrl+/]] を押しても同じです）。文のある行と、中に行のある行は区切り線にできません。

## 入れ子とトグル {#nest}

行は、上の行の中に入れて（字下げして）まとめられます。

- **[[Tab]]:** 行を、すぐ上の行の中に入れます。[[Shift+Tab]] で1段戻します。いちばん上の行・すぐ上が区切り線か見出し（トグル見出しでないもの）の行・AI が書いた節の見出し（「決定事項」など。トグル見出しにしても同じ）では、何も起きません。
- **字下げした行:** 空の箇条書き・ToDo・番号付きで [[Enter]] を押すか、行の頭で [[Backspace]] を押すと、まず1段戻ります。番号付きの番号は、同じ段の中で数えます。
- **中の行が見えている行の終わりで [[Enter]]:** 中のいちばん上に行を足します。閉じたトグルでは、すぐ下に次のトグルを足します。
- **欄から出る:** 行の中で [[Esc]] を押すと、その行を選びます（[行を選ぶ](#select)）。もう一度 [[Esc]] を押すと、選びを外して左の ⠿ に移ります。そこで [[Tab]] を押すと要約の欄の外へ、[[Shift+Tab]] で ［AI 要約］ のタブへ移ります。[[Esc]] で行に戻ります。
- **⠿ を引っ張る:** 右へずらして落とすと、上の行の中に入ります。左へずらすと浅い段に入ります。落とす線の左の端が、入る段です。

**トグル** は、▸ で中を開け閉めできる行です。行の頭で `> ` と打つか、/ のメニューの「トグル」で作ります（できたときは開いています）。見出しも「トグル見出し1〜3」にできます。

- ▸ を押すか、行の中で [[Ctrl+Enter]] を押すと、開け閉めします。開け閉めは議事録に覚え、次に開いても同じです（書き直しには数えません）。
- [[Ctrl+Alt+T]] は、ページのトグルをまとめて開け閉めします。1つでも閉じていれば全部開き、全部開いていれば全部閉じます。
- 閉じたトグルの中の行へリンクで飛ぶと、そのときだけ開いて見せます。
- トグルをテキストに、トグル見出しを見出しに戻すと、中の行はその下に並びます。見出しをトグル見出しにしても、下の行は中に入りません（[[Tab]] で1行ずつ入れます）。
- 閉じたトグルの中の ToDo も、検索の窓の ［アクション］ と Claude から読む議事録に出ます。［コピー］ では、中の行を2つの空白で下げて写します（閉じたトグルの中も写します）。

## 貼り付け {#paste}

要約の行に [[Ctrl+V]] で貼ると、貼った文を行と飾りに変えます。

- **Word・Web のページ・Teams から写した文:** 見出し・箇条書き・番号付き（入れ子は中の行に）・チェックの付いた項目（ToDo）・引用・区切り線・段落が、それぞれの型の行になります。表は1行ずつ「セル / セル」の箇条書きになります。太字・斜体・下線・取り消し線・コード・リンクは残り、文字の色・背景の色・字の大きさ・書体は落とします。
- **Markdown の文:** 行の頭の `#`・`- `・`* `・`1. `・`- [ ]`・`- [x]`・`> `（引用）・`---` と、`**太字**`・`[文字](住所)` などを、行と飾りに変えます。字下げした箇条は中の行になります。
- **ふつうの文:** 1行ずつテキストの行になります。空の行は詰めます。
- **1行だけの文:** 行を分けずに、カーソルの所へ入ります（飾りがあれば飾りのまま）。
- 開けない住所のリンク（https・http・mailto と NaTsu のリンクのほか）は、文字だけになります。

貼った行の入る所:

- 文の途中なら、行をそこで分け、貼った行を間に入れます。後ろの文は貼った行の下の新しい行になります（型は [[Enter]] で分けたときと同じ）。
- 文のある行の頭なら、貼った行をその行の上に足します（その行の文・担当・期限・出典はそのまま）。
- 空のテキストの行なら、最初に貼った行がその行になります。
- 中の行が見えている行（開いたトグルなど）なら、貼った行は中のいちばん上に入ります。

どの貼り付けも、[[Ctrl+Z]] の1回で全部戻ります。

- **[[Ctrl+Shift+V]]:** 変えずに、文字だけをカーソルの所へ貼ります（改行は行の中の改行になります）。
- 文字を選んだまま URL を貼ると、選んだ文字のリンクになります（[文字の飾り・リンク・色](#marks)）。
- 貼れるのは 2,000 行・1MB までです。越えると「貼り付けが大きすぎます（2,000 行・1MB まで）。分けて貼ってください。」と出て、何も貼りません。
- 日本語入力の変換中は、文字だけを貼ります。
- 題名と文字起こしの行への貼り付けは、今までどおり文字だけです。

## 行を選ぶ {#select}

いくつかの行をまとめて消す・動かす・型を変えるときは、行を選びます。選んだ行は地の色が変わります。

- 行の中で [[Esc]] を押すと、その行を選びます。[[Shift+↑]]・[[Shift+↓]] で上下へ広げます。
- [[Shift]] を押しながらクリックすると、そこまでの行を選びます。[[Alt+Shift]] を押しながらクリックすると、1行ずつ足す・外すができます。
- 行の左右の余白から引っ張ると、通った行を選びます。行の文から別の行へ引っ張っても、行の選びに替わります。
- 行の中の [[Ctrl+A]] は、1回目は行の文字を全部、2回目はその行を、3回目はページの行を全部選びます。
- 中に行のある行を選ぶと、中の行も一緒です。
- 選んでいる間に文字を打っても、何も起きません。別の行を押す・別のページへ移ると、選びは外れます。

選んでいるときのキー:

| キー | 動き |
| --- | --- |
| [[↑]]・[[↓]] | 選ぶ行を替える |
| [[Shift+↑]]・[[Shift+↓]] | 選ぶ行を広げる・狭める |
| [[Backspace]]・[[Delete]] | 選んだ行を消す |
| [[Ctrl+C]]・[[Ctrl+X]]・[[Ctrl+V]] | 選んだ行を写す・切り取る・後ろに貼り付ける |
| [[Ctrl+D]] | 選んだ行を複製する |
| [[Ctrl+Shift+↑]]・[[Ctrl+Shift+↓]] | 選んだ行を上・下へ動かす |
| [[Ctrl+Shift+0〜7]] | 選んだ行の型をまとめて変える |
| [[Ctrl+/]] | 選んだ行のメニューを開く（削除・複製・変換・色） |
| [[Ctrl+A]] | ページの行を全部選ぶ |
| [[Ctrl+Z]] | 元に戻す |
| [[Ctrl+Shift+Z]]・[[Ctrl+Y]] | やり直す |
| [[Enter]] | 選んだ行の文に戻って直す |
| [[Tab]] | 選びを外して、欄の外の次の部品へ |
| [[Shift+Tab]] | 選びを外して、［AI 要約］のタブへ |
| [[Esc]] | 選びを外して ⠿ へ |

- 消すときは確かめません。[[Ctrl+Z]] の1回で戻ります。どの操作も、選んだ行の全部で1回の操作です。
- [[Ctrl+C]] で写した行は、ほかのアプリには Markdown の文と飾りのある文で、NaTsu の行に貼り戻すと同じ型の行になります。
- [[Ctrl+/]] のメニューの ［変換 ▸］ で、選んだ行のどれかに文か中の行があると、区切り線は選べません。

## 元に戻す・やり直す {#undo}

要約の欄とメモの欄の行では、[[Ctrl+Z]] で直しを元に戻し、[[Ctrl+Shift+Z]] か [[Ctrl+Y]] でやり直します。

- 1回で戻るのは、1つの操作です（行を分ける・つなぐ・型を変える・貼り付け・並べ替え・複製・削除・字下げ・飾りや色・ToDo のチェック・担当と期限・選んだ行のまとめた操作）。
- 打った文字は、打つ手が 2 秒止まるか、ほかの行やほかの所へ移るたびに1つの操作になります。打っている途中で [[Ctrl+Z]] を押すと、その前に保存した文に戻ります。
- トグルの開け閉めは、元に戻すには数えません。
- 戻す歩みは、ページごと・欄ごと（要約とメモは別々）に、100 回分まで覚えます。新しく直すと、やり直しの歩みは消えます。
- 覚えるのは窓の中だけで、NaTsu を終えると消えます（画面を読み直したときも消えます）。
- 戻せるのは、自分が NaTsu の画面で直した所だけです。［要約を再生成］ で作り直したことは、元に戻せません（作り直すと、そのページの要約の歩みは消えます。メモの歩みは残ります）。
- 戻す所が後からほかの所で変わっていたら（作り直した・文字起こしを直して出典が付け直された、など）、戻さずに「ほかの所で変わったので、元に戻せませんでした」と出て、そのページの歩みは消えます。
- 戻すものが無いと「これ以上は戻せません」、やり直すものが無いと「やり直せるものはありません」と出ます。
- 録音中・要約を作っている間は、要約の欄は戻せません（メモの欄は戻せます）。
- [[Ctrl+Z]] で全部戻しても、書き直した要約として数えます（作り直す前の確かめは出ます）。
- 題名・文字起こしの行・設定・検索の窓の欄では、今までどおりその欄の中で戻ります。

## 近道 {#keys}

近道は、要約とメモの欄の行を直しているときだけ効きます（文字起こし・題名では効きません）。行を選んでいるときのキーは [行を選ぶ](#select)、ほかの所のキーは [ホットキー](settings/hotkeys.md#in-app) にあります。

| キー | すること |
| --- | --- |
| [[Ctrl+Z]] | 元に戻す |
| [[Ctrl+Shift+Z]]・[[Ctrl+Y]] | やり直す |
| [[Ctrl+B]]・[[Ctrl+I]]・[[Ctrl+U]]・[[Ctrl+Shift+S]]・[[Ctrl+E]] | 選んだ文字を太字・斜体・下線・取り消し線・コードにする（もう一度押すと外す） |
| [[Ctrl+K]] | 選んだ文字にリンクを付ける |
| [[Ctrl+Shift+H]] | 選んだ文字に、最後に使った色を付ける |
| [[Ctrl+Shift+V]] | 文字だけを貼り付ける |
| [[Ctrl+Shift+0]] | テキスト |
| [[Ctrl+Shift+1]] | 見出し1 |
| [[Ctrl+Shift+2]] | 見出し2 |
| [[Ctrl+Shift+3]] | 見出し3 |
| [[Ctrl+Shift+4]] | ToDo |
| [[Ctrl+Shift+5]] | 箇条書き |
| [[Ctrl+Shift+6]] | 番号付き |
| [[Ctrl+Shift+7]] | トグル |
| [[Ctrl+D]] | 行を複製する |
| [[Ctrl+Shift+↑]]・[[Ctrl+Shift+↓]] | 行を上・下へ動かす |
| [[Ctrl+Enter]] | ToDo のチェックを付ける・外す。トグルを開く・閉じる |
| [[Ctrl+/]] | 行のメニューを開く |
| [[Tab]] | 行を上の行の中に入れる（字下げ） |
| [[Shift+Tab]] | 字下げを1段戻す |
| [[Ctrl+Alt+T]] | ページのトグルをまとめて開く・閉じる |
| [[Esc]] | 行を選ぶ（もう一度押すと選びを外して ⠿ へ） |
| [[Ctrl+A]] | 行の文字を全部選ぶ（もう一度押すとその行を選び、さらにもう一度でページの行を全部選ぶ） |

[[Ctrl+Shift+0]] では画面の大きさは戻りません（[[Ctrl+0]] は今どおり戻します）。
全体のホットキーに Ctrl+Alt+T を選んでいると、NaTsu の窓でもそちらが先に効きます。

## メモも行で書く {#memo}

［メモ］ のタブのメモも、要約と同じ行の欄です。保存した議事録・録音中のページ・録音の前のページのどれでも、この記事の書き方（/ のメニュー・行の頭の記法・飾りとリンクと色・貼り付け・行を選ぶ・元に戻す・＋ と ⠿・入れ子とトグル・近道）がそのまま使えます。

要約の欄と違うところ:

- 出典・担当・期限の札は出ません。行の右の × もありません（消すときは ⠿ のメニューか、行を選んで [[Backspace]]）。
- 見出しは書いた順のままです（要約のように決まった順に並べ替えません）。
- トグルの開け閉めは覚えません（ページを開くと開いた形です）。
- ⠿ で [[Shift+Tab]] を押すと、［メモ］ のタブへ移ります。
- メモの直しは、書き直した要約には数えません（［要約を再生成］ の前の確かめは出ません）。録音中や要約を作っている間も直せます。
- 元に戻すは要約と別々です。メモの欄の [[Ctrl+Z]] はメモの直しだけを戻します。
- 何も書いていないメモには、書き方の例が灰色で出ます（打つと消えます）。

## 作り直すと元に戻ります {#regenerate}

「···」の ［要約を再生成］ で作り直すと、要約は全部作り直され、書き直した所（足した行・消した行・並べ替え・字下げ・変えた型や見出しの段・分けた行やつないだ行・直した文やチェック・飾りや色・貼り付けた行）は元に戻ります。入れ子もトグルの開け閉めも消えます。作り直したことは元に戻せません（[[Ctrl+Z]] でも戻りません）。メモは変わりません。
要約を書き直した後は（どんな直しでも）、作り直す前に「書き直した要約を作り直しますか？」と確かめます（［作り直す］ か ［やめる］）。

［コピー］ と Claude デスクトップから読む要約（[Claude との連携（MCP）](start/claude-mcp.md)）にも、見出しの段・番号付き・引用・区切り線と、入れ子の中の行が写ります。
