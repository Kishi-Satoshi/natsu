ページの上の「会議の種類」で、会議の種類を選べます。
種類から「メモの型」（メモの見出しと、要約の組み立て）が決まります。型を別に選ぶ欄はありません。

## 種類とメモの型 {#types}

| 会議の種類 | メモの型 | 見出し |
| --- | --- | --- |
| 朝会・内部定例会 / 部会・報告会 | 進捗・報告の確認（空・雨・傘） | 前回の宿題の状況 / 報告ごとに 事実（進捗・課題）・見立て（原因・リスク）・打ち手の案 |
| ブレスト・意見交換 | 会議の要点（論点整理） | 目的 / 論点ごとの要点 |
| 1on1 | 1on1の振り返り（GROW） | テーマ・目標（G） / 現状と困りごと（R） / 選択肢・上司の助言（O） |
| 採用面接・事前面談 | 面接の確認（STAR） | 経歴・スキル / 行動の具体例 / 本人からの質問・懸念 / 条件 |
| 商談 | 商談の確認（BANTC） | 課題・要望（N） / 時期（T） / 決め方・決裁者（A） / 予算（B） / 競合・比較先（C） |
| プレゼン形式 | プレゼン形式（要旨・質疑） | 発表の要旨 / 質疑応答 / 出た意見・懸念 |

どの型の要約にも、最後に「決定事項」「持ち越し」「ToDo（誰が・何を・いつまでに）」「抜け・重なりチェック」「次に気をつけること」が付きます（[要約の作られ方](summary/how-summaries.md)）。
種類の横の灰色の字に「メモの型: …」が出ます。

## 自動 {#auto}

- 初めは「自動（文字起こしから判定）」です。題名と話の冒頭から、要約のときに種類を決めます。
- 題名と話で決まらないときは、前の同じ曜日・同じ時刻ごろの会議で、手で2回以上同じ種類を選んでいれば、その種類にします。
- それでも決まらないときは「自動」のまま、会議の要点の型でまとめます（灰色の字に「自動判定: 決まらなかったので会議の要点の型でまとめました」と出ます）。
- 「一般・その他」は 0.11.0 でなくなりました。前の版で一般・その他だった会議は「自動」と出ます。要約はそのままで、［要約を再生成］ を押したときに種類を判定し直します。
- 自動のページで題名を直すと、題名から判定した種類が今と違うときに「題名からは「…」です」と出ます。種類も要約も変わりません。［要約を再生成］ で反映します。

## 手で選ぶ {#choose}

- ページの上の「会議の種類」で選び直せます。手で選んだ種類は、自動の判定より先に効きます。「自動」に戻すと、次の要約で判定し直します。
- メモが空か、型の見出しのままなら、選んだ型の見出し（「■ 課題・要望（N）」など）がメモに入ります。自分で書いたメモは上書きしません。
- メモの上に、見出しごとの書き方の手引きが灰色で出ます（メモに書き始めると隠れます）。
- 選び直した後は、「···」の ［要約を再生成］ で要約に反映します。

## 録音中に選ぶ {#live}

録音中のページにも「会議の種類」があります。種類を選ぶと、メモのタブに切り替わって見出しが入ります（書いたメモがあるときはそのまま残します）。
選んだ種類は、会議が終わってできる議事録にそのまま残ります。

担当と期限は、文字起こしとメモに出てくるものだけを載せます。
