会議の種類に合わせて、要約の見出しの組み立てが変わります。
たとえば 1on1 では「決定事項」の代わりに「合意した方針・支援」を立てます。

## 種類 {#types}

| タイプ | 見出し |
| --- | --- |
| 定例・進捗報告 | 概要 / 報告事項 / 決定事項 / アクションアイテム / 課題・持ち越し事項 |
| 部会・報告会 | 概要 / 報告事項 / 決定事項 / 課題・リスク / アクションアイテム / 次回への持ち越し |
| 1on1・面談 | 概要 / 本人の状況・所感 / 相談・課題 / 合意した方針・支援 / 次回までのアクション |
| 商談・協業検討 | 概要 / 先方の状況・ニーズ / 提示・説明した内容 / 先方の反応・懸念 / 決定事項 / ネクストアクション |
| 採用面接・顔合わせ | 概要 / 経歴・スキル / 志向・希望条件 / 確認された懸念点 / 申し送り・次のステップ |
| ブレスト・意見交換 | 概要 / 出たアイデア・意見 / 有望とされた方向性 / 論点・未整理の点 / 次に検討すること |
| 一般・その他 | 概要 / 決定事項 / アクションアイテム / 主なトピックと論点 / 未解決・持ち越し事項 |

## 選び方 {#choose}

- タイプは、題名と話の冒頭から自動で決まります。決め手が無いときは「一般・その他」です。
- ページの上の「要約タイプ」で、手で選び直せます。手で選んだタイプは、自動の判定より先に効きます。
- 選び直した後は、「···」の ［要約を再生成］ で要約に反映します。
- タイプを選ぶと、そのタイプに合ったアジェンダの雛形がメモ欄に入ります（自分で書いたメモがあるときは上書きしません）。

担当と期限は、文字起こしとメモに出てくるものだけを載せます。
