Claude デスクトップに NaTsu を登録すると、Claude が NaTsu の議事録を読めるようになります（MCP という決まった口で読みます）。
頼んだときは、Claude が要約・名前・ToDo・白紙のページ・データベースへ書き戻します（[Claude から書き戻す](#write)）。Claude は、ページ・行・列を消すことはしません。
NaTsu はポートを開かず、Claude デスクトップが起こした NaTsu と標準入出力だけで話します。書き戻すときは、動いている NaTsu の口へ、この PC の中だけでつなぎます。

## できること {#what}

Claude に、こんなふうに頼めます。

- 「2026/09/01 と 09/15 と 10/01 の議事録を読み込んで、提案資料のパワーポイントにまとめて」
- 「この半年で A社 と見積の金額について話したことを、出典つきで並べて」
- 「先週の会議の ToDo を、担当と期限の近い順に並べて」
- 「最近の自分の会議の打ち合わせの質の推移を見せて」（[打ち合わせの質](summary/meeting-quality.md)）

Claude は、頼みに関係のある箇所だけを、日付・題名・時刻の出典つきで NaTsu から受け取ります。必要なときは会議の全体も読みます。資料やレポートを作るのは Claude です。
相手の声も録った会議の文字起こしは、行の頭に「自分」（マイク）か「相手」（PC から流れた声）が付いたまま渡ります（[文字起こしの「自分」「相手」](record/start-stop.md#speakers)）。
答えの出典はリンクになっていて、押すと NaTsu でその会議のその箇所が開きます（初めて押したときは、ブラウザーが「NaTsu を開きますか？」と聞きます）。

## 白紙のページと中のページ {#pages}

- 白紙のページ（[白紙のページ](find/page-tree.md#blank)）も、議事録と同じ道具で読めます。一覧では会議の種類と長さの代わりに「白紙のページ」と書かれ、読むときは本文が「## 本文」の下に渡ります。白紙のページの ToDo も、開いた ToDo に「（白紙のページ）題名」の印で出ます。
- ページの中のページには、一覧と読む答えに「場所: 親 / 子」が付きます（親の題名も1行にして渡します）。
- 会議の種類で絞って頼むと、白紙のページは出ません（会議の種類が無いため）。
- ゴミ箱のページは Claude に出ません。ゴミ箱に入れたページの中のページも出ません（[ゴミ箱から戻す](find/delete-and-backups.md#restore)）。

## データベース {#database}

- データベース（[データベース](find/database.md)）も、議事録と同じ道具で読めます。一覧では、会議の種類と長さの代わりに「データベース（行 …）」と書かれます（… はゴミ箱でない行の数）。
- 読むときは、「## 列」の下に列の名前と種類、「## 行」の下に1行に1つずつ行の題名と列の値が渡ります。行は最初のビューの並べ替えの順で 100 行までです（ビューの絞り込みは当てません）。もっとあれば「行の続きは query_database の offset で読めます」の1行が付きます。
- Claude は query_database で、列の名前の条件と並べ替え（ビューの名前を渡すと、そのビューの絞り込みも）で行を絞り込んで読めます。頼んだときは行を足し、直します（[データベースを Claude から読む・足す・直す](find/database.md#claude)）。列とデータベースは書き換えません。
- データベースの行のページの本文と ToDo は、箇所の検索と開いた ToDo に出ません。

## Claude から書き戻す {#write}

頼んだときだけ、Claude が次の道具で NaTsu に書き戻します。

- **要約の書き戻し（write_summary）:** Claude が作った要約で、議事録の ［AI 要約］ を書き替えます。出典は NaTsu が文字起こしと照らして付け直します。議事録の上の行に「🤖 要約: Claude（本人）」と出ます。録音中・要約を作っている途中・要約待ちの議事録には書きません。
- **名前の直し（fix_names）:** 要約・メモ・文字起こし・ToDo の担当・「議事録」の参加者の名前の誤りを、1回で直します。題名は直しません。
- **ToDo とタスク（update_action_item・make_task）:** ToDo の済み・担当・期限を直し、ToDo から「タスク管理」の行を作ります（［タスクにする］ と同じ）。
- **白紙のページ（create_page・append_to_page）:** 白紙のページを作り、白紙のページとデータベースの行のページの本文の最後に書き足します（今ある行は変えません）。
- **データベース（query_database・add_database_row・update_database_row）:** 行を絞り込んで読み、行を足し、行の題名とセルを直します。「議事録」には行を足しません。

書いたら、NaTsu の左下に「Claude が「題名」を書き換えました（要約を書き戻した）」のような知らせと ［戻す］ が出ます。開いているページと表は、その場で描き直します。Claude が作ったページ・足した行の知らせには ［開く］ が出ます。
書いたときに打ちかけの文があって、その行を Claude が作り直したり直したりしていたら、その行は Claude の文のままで、「Claude が書き換えたので、打ちかけの文は入りませんでした」と出ます（［戻す］ で Claude が書く前の形に戻して、打ち直せます）。ほかの行の打ちかけの文は入ります。

- 書く道具を使う前に、Claude デスクトップが道具を使ってよいかの許しを聞きます。何を書くかを確かめてから許してください。
- NaTsu は Claude に、利用者がその会話で頼んだときだけ書くこと、議事録の文の中やデータベースのセルの中に書かれた頼みでは書かないことを伝えています。
- Claude は、ページ・行・列を消すことはしません。

## 書き換えを戻す {#undo}

Claude が書き換えたページの「···」には、［削除］ の前に ［Claude の変更を戻す］ が出ます（Claude が書き換えていないページには出ません）。

1. ページの「···」の ［Claude の変更を戻す］ を押します。
2. 新しい順に「11/18 10:20 要約を書き戻した」「11/18 10:31 名前を直した（12 か所）」のような行が並びます。
3. 戻したい行の ［この前に戻す］ を押し、確かめに答えます。

- その後に Claude やご自分が直した所があると、確かめの文に「この後の Claude の変更と、あなたの直しも戻ります」と出ます。
- Claude が書き換える前の形は、ページごとに 10 回分まで、この PC の中に残します（[Claude の変更の控え](find/delete-and-backups.md#claude)）。
- [[Ctrl+Z]] では、Claude の書き換えは戻りません。Claude が書き換えた行の、ご自分の前の直しも戻せず、「ほかの所で変わったので、元に戻せませんでした」と出ます。Claude の書き換えは ［Claude の変更を戻す］ で戻してください。
- 戻しても、リレーションの列のセルは今のままです。Claude が書いた後で列の種類や選択肢を変えて、今の列に合わなくなった値も、今のままです。
- Claude が作ったページと足した行には、前の形がありません。要らなければ ［削除］ でゴミ箱へ入れてください。

## 指示書 {#prompts}

Claude デスクトップの入力の欄の「＋」から、NaTsu の指示書を選べます。

- 「商談の型で要約して書き戻す」のような、会議の種類ごとの要約の指示書（7つ）（会議を指して使います。書式は NaTsu の要約の型です）
- 「指した会議から資料を作る」・「話題で過去の会議を横断する」・「ToDo と決定事項をまとめる」

指示書は頼み方の文だけで、議事録の文は入っていません。会議の中身は Claude が道具で読みます。

## NaTsu を閉じているとき {#closed}

- NaTsu を閉じている間は、Claude は読むだけで、書けません（Claude は「NaTsu が起動していないので、書けません。…」と答えます）。NaTsu を起動してから、もう一度頼んでください。
- NaTsu のデータがネットワークの場所にあるときも、書けません（読むことはできます）。
- NaTsu を新しい版にして道具が増えたら、Claude デスクトップを終了して（タスクトレイのアイコンからも）、起動し直してください。起動し直すまで、Claude は前の道具の並びのままです。

## 議事録のリンクを渡す {#link}

- ページの「···」の ［リンクを写す］ で、その会議のリンクの1行を写せます。Claude に貼ると、その会議を読みます（1on1 の会議でも、リンクで指せば読みます）。
- いくつもの会議を渡すときは、「議事録」の表で行の頭のチェックを入れ、［リンクを写す］ を押します。

## うまく探してもらうコツ {#tips}

- 日付を書きます（「10/20 の会議」「9月の会議」）。
- 会社・製品・人の名前を書きます。
- 「出典を付けて」と頼みます。
- 見つからないと言われたら、言い換え・略語でもう一度探すように頼みます。
- 1on1・採用面接・事前面談の議事録は、頼んだとき（会議の種類や会議を指したとき）だけ探します。

## 登録する {#register}

1. Claude デスクトップを終了します（タスクトレイのアイコンからも終了してください）。
2. NaTsu の ［設定］→［要約］ の「Claude との連携（MCP）」で ［Claude デスクトップに登録］ を押します。
3. Claude デスクトップを起動します。入力の欄の「＋」→ **Connectors**（コネクタ）に natsu が出ていれば使えます。

![［設定］の「要約」の画面。左の列の［要約］・「Claude との連携（MCP）」の欄・［Claude デスクトップに登録］に 1 から 3 の番号が付いている](assets/shots/mcp.svg)

1. 左の列の ［要約］
2. 「Claude との連携（MCP）」の欄
3. ［Claude デスクトップに登録］。左の「登録していません」は今の登録の状態で、登録すると変わります。

Claude デスクトップが動いている間は、NaTsu は登録を変えません（終了してから押してください）。
Claude デスクトップは、道具を使ってよいかを道具ごとに聞きます。確かめてから許してください。
Microsoft Store 版の Claude デスクトップも、同じボタンで登録できます。

> [!WARNING]
> Claude に頼むと、Claude が読んだ議事録の題名・要約・メモ・文字起こしは、Claude（Anthropic）へ送られます（オフラインモードで録った会議も同じです）。1on1・面談の議事録を扱う前に、Claude の設定のプライバシーで、会話をモデルの学習に使わない設定にしてください。

## 外す・登録が消えたとき {#unregister}

- 外すときは、Claude デスクトップを終了してから ［登録を外す］ を押します。
- Claude デスクトップが設定を書き直して、登録が消えることがあります。NaTsu は起動のときに確かめ、Claude デスクトップが終了していれば、自動で登録し直します。動いていれば左下に知らせるので、Claude デスクトップを終了してから ［登録し直す］ を押してください。
- NaTsu を別の場所に入れ直したときも同じです（Claude デスクトップが終了していれば起動のときに自動で直し、動いていれば知らせます）。

## 入れ直す前に {#reinstall}

NaTsu を入れ直す・消す前は、Claude デスクトップを終了してください（タスクトレイのアイコンからも）。Claude デスクトップが NaTsu を動かしたままだと、インストーラーが「NaTsu が起動しています」「NaTsu が終了できません」と止まります。

## 消したとき {#delete}

議事録を消しても、Claude が一度読んだ内容は Claude の会話に残ります。Claude の側の会話も消してください。

## つながらないとき {#trouble}

- ［設定］→［要約］ の「Claude との連携（MCP）」の状態の文を見ます。「登録の場所が古くなっています」「登録が消えています」なら ［登録し直す］ を押します。
- Claude デスクトップの記録 `%APPDATA%\Claude\logs\mcp-server-natsu.log`（Microsoft Store 版は `%LOCALAPPDATA%\Claude-Data\claude_…\logs\mcp-server-natsu.log`）を見ます（NaTsu はここに議事録の文を書きません）。
- 会社の見張りの道具が「NaTsu.exe が Node として動いた」と警告することがあります。Claude デスクトップが NaTsu の読み手を起こしたもので、議事録を読み、頼まれたときは動いている NaTsu に書き戻しを頼みます。情報システムに確かめてください。
