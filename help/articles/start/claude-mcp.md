Claude デスクトップに NaTsu を登録すると、Claude が NaTsu の議事録を読めるようになります（MCP という決まった口で読みます）。
Claude は議事録を読むだけで、書き換えません。NaTsu はポートを開かず、Claude デスクトップが起こした NaTsu と標準入出力だけで話します。

## できること {#what}

Claude に、こんなふうに頼めます。

- 「2026/09/01 と 09/15 と 10/01 の議事録を読み込んで、提案資料のパワーポイントにまとめて」
- 「この半年で A社 と見積の金額について話したことを、出典つきで並べて」
- 「先週の会議の ToDo を、担当と期限の近い順に並べて」
- 「最近の自分の会議の打ち合わせの質の推移を見せて」（[打ち合わせの質](summary/meeting-quality.md)）

Claude は、頼みに関係のある箇所だけを、日付・題名・時刻の出典つきで NaTsu から受け取ります。必要なときは会議の全体も読みます。資料やレポートを作るのは Claude です。
相手の声も録った会議の文字起こしは、行の頭に「自分」（マイク）か「相手」（PC から流れた声）が付いたまま渡ります（[文字起こしの「自分」「相手」](record/start-stop.md#speakers)）。
答えの出典はリンクになっていて、押すと NaTsu でその会議のその箇所が開きます（初めて押したときは、ブラウザーが「NaTsu を開きますか？」と聞きます）。

## 議事録のリンクを渡す {#link}

- ページの「···」の ［リンクを写す］ で、その会議のリンクの1行を写せます。Claude に貼ると、その会議を読みます（1on1 の会議でも、リンクで指せば読みます）。
- いくつもの会議を渡すときは、左の一覧の見出し「議事録」の右の ［選ぶ］ を押し、会議を選んで ［リンクを写す］ を押します（Shift を押しながら押すと範囲で選べます。終えるときは ［やめる］ か Esc）。

## うまく探してもらうコツ {#tips}

- 日付を書きます（「10/20 の会議」「9月の会議」）。
- 会社・製品・人の名前を書きます。
- 「出典を付けて」と頼みます。
- 見つからないと言われたら、言い換え・略語でもう一度探すように頼みます。
- 1on1・採用面接・事前面談の議事録は、頼んだとき（会議の種類や会議を指したとき）だけ探します。

## 登録する {#register}

1. Claude デスクトップを終了します（タスクトレイのアイコンからも終了してください）。
2. NaTsu の ［設定］→［要約］ の「Claude との連携（MCP）」で ［Claude デスクトップに登録］ を押します。
3. Claude デスクトップを起動します。入力の欄の「＋」→ **Connectors**（コネクタ）に natsu が出ていれば使えます。

![［設定］の「要約」の画面。左の列の［要約］・「Claude との連携（MCP）」の欄・［Claude デスクトップに登録］に 1 から 3 の番号が付いている](assets/shots/mcp.svg)

1. 左の列の ［要約］
2. 「Claude との連携（MCP）」の欄
3. ［Claude デスクトップに登録］。左の「登録していません」は今の登録の状態で、登録すると変わります。

Claude デスクトップが動いている間は、NaTsu は登録を変えません（終了してから押してください）。
Claude デスクトップは、道具を使ってよいかを道具ごとに聞きます。確かめてから許してください。
Microsoft Store 版の Claude デスクトップも、同じボタンで登録できます。

> [!WARNING]
> Claude に頼むと、Claude が読んだ議事録の題名・要約・メモ・文字起こしは、Claude（Anthropic）へ送られます（オフラインモードで録った会議も同じです）。1on1・面談の議事録を扱う前に、Claude の設定のプライバシーで、会話をモデルの学習に使わない設定にしてください。

## 外す・登録が消えたとき {#unregister}

- 外すときは、Claude デスクトップを終了してから ［登録を外す］ を押します。
- Claude デスクトップが設定を書き直して、登録が消えることがあります。NaTsu は起動のときに確かめ、Claude デスクトップが終了していれば、自動で登録し直します。動いていれば左下に知らせるので、Claude デスクトップを終了してから ［登録し直す］ を押してください。
- NaTsu を別の場所に入れ直したときも同じです（Claude デスクトップが終了していれば起動のときに自動で直し、動いていれば知らせます）。

## 入れ直す前に {#reinstall}

NaTsu を入れ直す・消す前は、Claude デスクトップを終了してください（タスクトレイのアイコンからも）。Claude デスクトップが NaTsu を動かしたままだと、インストーラーが「NaTsu が起動しています」「NaTsu が終了できません」と止まります。

## 消したとき {#delete}

議事録を消しても、Claude が一度読んだ内容は Claude の会話に残ります。Claude の側の会話も消してください。

## つながらないとき {#trouble}

- ［設定］→［要約］ の「Claude との連携（MCP）」の状態の文を見ます。「登録の場所が古くなっています」「登録が消えています」なら ［登録し直す］ を押します。
- Claude デスクトップの記録 `%APPDATA%\Claude\logs\mcp-server-natsu.log`（Microsoft Store 版は `%LOCALAPPDATA%\Claude-Data\claude_…\logs\mcp-server-natsu.log`）を見ます（NaTsu はここに議事録の文を書きません）。
- 会社の見張りの道具が「NaTsu.exe が Node として動いた」と警告することがあります。Claude デスクトップが NaTsu の読み手を起こしたもので、議事録を読むだけです。情報システムに確かめてください。
