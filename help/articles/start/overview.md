NaTsu は、会議を録音して文字起こしし、要約まで作る Windows のアプリです。
このページでは、画面のどこに何があるか、1回の会議で何が起きるか、音声と文字がどこへ行き、どこに保存されるかを、画面の写真と図で説明します。
写真は、作り物の会議のデータで撮った NaTsu の画面です。

## 画面の地図 {#map}

![NaTsu の議事録のページの画面。サイドバー・上のタブ・ページ・ページの中のタブに 1 から 4 の番号が付いている](assets/shots/overview-map.svg)

1. **サイドバー:** 上から ［検索］・［新しい議事録］・議事録の一覧、いちばん下に ［音声入力］・［設定］ があります。録音中は ［■ 終了して作成］・［破棄］ も出ます。
2. **上のタブ:** 開いているページ（議事録・音声入力など）が、ブラウザのタブのように並びます。
3. **ページ:** 議事録の題名と、作成日時・長さ・出典の数・会議の種類などの項目です。
4. **ページの中のタブ:** ［AI 要約］・［メモ］・［文字起こし］ を切り替えます。

［ヘルプ］ は、［設定］ の左の列のいちばん下にあります（このヘルプセンターが開きます）。

録音中は、画面の端に小さな録音バーも出ます。

![録音バーの画面。音の大きさの点・経過時間・一時停止のボタン・停止のボタンに 1 から 4 の番号が付いている](assets/shots/bar.svg)

1. 音の大きさの5つの点（声が入ると揺れます）
2. 経過時間
3. 一時停止のボタン
4. 停止のボタン（録音を止めて議事録を作ります）

録音バーの置き場所や隠し方は [録音バー](record/start-stop.md#bar) を見てください。

## 手順1. 録音の前のページを開く {#flow-open}

サイドバーの ［新しい議事録］ を押すと、録音の前のページが開きます。まだ録音しません。

![録音の前のページの画面。［文字起こしを始める］・［オフラインモードで始める］・会議の種類に 1 から 3 の番号が付いている](assets/shots/ready.svg)

1. ［文字起こしを始める］ を押すと、録音と文字起こしが始まります。
2. ［オフラインモードで始める］ は、ネットワークが不安定なときに、文字起こしを PC の中で行う会議として始めます（クラウドで文字起こしする PC だけに出ます）。
3. 会議の種類を選ぶと、メモにその種類の見出しが入ります。

[[Alt+M]] を押すと、このページを飛ばしてすぐ録音を始めます。

## 手順2. 録音する {#flow-live}

録音中は「記録中」のタブになり、文字起こしが少しずつ流れます。

![録音中のページの画面。経過時間の行・一時停止・終了して作成・オフラインモード・文字起こし・サイドバーのボタンに 1 から 6 の番号が付いている](assets/shots/live.svg)

1. 経過時間と、今の録音の様子です。その下の行は、文字起こしがどこで進んでいるか（クラウドか、この PC か）です。
2. ［⏸ 一時停止］ で録音を止め、［▶ 再開］ で続けます。
3. ［■ 終了して作成］ で録音を止め、議事録を作ります。
4. ［オフラインモード］ を押すと、この会議のその後の文字起こしを PC の中に固定します。
5. 文字起こしです。相手の声も録る会議では、行に「自分」「相手」が付きます。
6. サイドバーにも ［■ 終了して作成］ と、録音を捨てる ［破棄］ が出ます。

## 手順3. 止めると議事録ができる {#flow-done}

止めると、残りの文字起こしと要約が進み、終わると要約の入った議事録のページに替わります。

![議事録のページの画面。［AI 要約］のタブ・要点の出典・項目の出典に 1 から 3 の番号が付いている](assets/shots/minutes.svg)

1. ［AI 要約］ のタブに要約が出ます。
2. 要点の右の時刻（出典）を押すと、文字起こしのその発言へ飛びます（[出典リンク](summary/citations.md)）。
3. 項目の「出典」は、出典の付いた要点の数と、要点の数です。

## 音声と文字はどこへ行くか {#data}

![NaTsu の仕組みの図。太い枠のこの PC の中に NaTsu・議事録の保存・Claude Code・Claude デスクトップがあり、外の NaTsu のサーバー・OpenAI・Anthropic と矢印でつながっている。番号は 1 から 7](assets/diagrams/overview-flow.svg)

太い枠の中が、この PC の中です。太い矢印は音声、細い矢印は文字です。

1. **NaTsu:** 録音して、文字起こしと要約を画面に出します。
2. **議事録の保存:** 議事録は、この PC の中にだけ保存します。
3. **文字起こしの中継（音声を OpenAI へ取り次ぐ NaTsu のサーバー）:** ログインしていて、つながっているときに、会議と音声入力の音声を受けて OpenAI へ渡し、文字だけを返します。音声も文字も保存しません。
4. **OpenAI:** 音声を文字にします。
5. **ご自分の Claude Code:** 会議が終わると、NaTsu が文字起こしの文とメモを渡し、Claude Code が Claude（Anthropic）で要約を作ります。
6. **Anthropic（Claude）:** 要約を作ります。Claude デスクトップから議事録を読んでもらうときも、Claude が読んだ文はここへ送られます。
7. **Claude デスクトップ:** NaTsu を登録すると、議事録を読めます。読むだけで、書き換えません。

| とき | 音声の行き先 | 文字起こし | 要約 |
| --- | --- | --- | --- |
| ログインしていて、つながっている | 中継を通して OpenAI へ | クラウド（OpenAI） | ご自分の Claude Code |
| ログインしていない・つながっていない | 外へ送らない | ローカル AI の準備をした PC は PC の中で（精度が落ちます）。していない PC は音声を残し、つながると文字起こし | つながったら Claude Code で作る（それまで「要約待ち」） |
| ［オフラインモード］ の会議 | 押した後は外へ送らない | PC の中（準備をしていない PC は音声だけを残す） | ご自分の Claude Code |

> [!WARNING]
> ［オフラインモード］ は、守秘のためのボタンではありません。要約を作るときと、Claude に議事録を読んでもらうときは、その会議の文も Claude（Anthropic）へ送られます。1on1・面談の前に [ネットワークが不安定なときの会議](record/pc-only.md) を読んでください。

## どこに保存されるか {#storage}

- 議事録（題名・要約・メモ・文字起こし）は、この PC の中の1つの保存のファイルにまとめて保存し、毎日1回、控えを取ります（[議事録を消す・毎日の控え](find/delete-and-backups.md)）。
- 中継は、音声も文字も保存しません。
- OpenAI と Anthropic での扱いは、それぞれの規約のとおりです。

## Claude とのつながり {#claude}

- 要約は、ご自分の Claude Code で作ります（[Claude Code を入れてログインする](start/claude-code.md)・[要約の作られ方](summary/how-summaries.md)）。
- Claude デスクトップに NaTsu を登録すると、Claude に「10/20 の議事録を読んで」のように頼めます（[Claude から議事録を読む](start/claude-mcp.md)）。
