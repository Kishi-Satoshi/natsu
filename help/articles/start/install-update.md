NaTsu は Windows 10 / 11（64bit）で動きます。管理者の権限は要りません。
ディスクの空きは、ローカル AI を使うとき（PC の中の文字起こしを取り込むとき）だけ約 1GB 要ります。

## インストールする {#install}

1. 配布のページ（[最新のリリース](https://github.com/Kishi-Satoshi/natsu/releases/latest)）を開きます。
2. 「Assets」の中の `NaTsu-<版>-setup.exe` だけを落として、ダブルクリックします。
   - 「Windows によって PC が保護されました」と出たら、**詳細情報** → **実行** で進めます（署名を付けていないため出ます）。
   - ダウンロードが途中で止まるときは、同じページの `get-installer.ps1` を落として実行します。切れても続きから取り直し、最後に壊れていないかを確かめます。
3. インストール先は `%LOCALAPPDATA%\Programs\NaTsu\` です。デスクトップとスタートメニューにショートカットができます。

入れたら、［設定］の「アカウント」でログインします（[ログインする](start/login.md)）。ログインしてインターネットにつながっていれば、会議と音声入力が使えます。

## ローカル AI を使うとき（任意） {#engine}

インターネットにつながっていないときも PC の中で文字起こしをするときだけ、エンジンを取り込みます（約 0.6GB）。しなくても、ログインしてつながっていれば NaTsu は使えます。要約は、いつもご自分の Claude Code で作ります（0.10.0 から）。

1. ［設定］→［ローカル AI］の ［ローカル AI を使う］（約 0.6GB を取り込む）を押します。押すまで、取り込みの通信はしません。
2. 途中で切れても、続きから取り込みます。議事録の記録中は止まり、記録が終わると続きから取り込みます。
3. 「PC の中の文字起こし：使えます」と出て、［PC の中で試す］ で OK が出れば済みです。

くわしくは [ローカル AI](settings/offline.md) を見てください。

## 更新する {#update}

- ［設定］→［更新］の ［更新を確認］ を押し、新しい版があれば ［更新して再起動］ を押します。落ちてくるのは数百KBの差分だけで、議事録・設定・エンジンはそのまま残ります。
- 起動したときにも新しい版を確かめます。トレイ（タスクバーの右下の NaTsu のアイコン）を右クリックして ［更新を確認］ からもできます。
- 録音中と議事録の保存の間は、更新の再起動をしません（「録音中のため、更新と再起動をしませんでした…」と出ます）。録音を終えてから押してください。

## 入れ直しが要る版 {#reinstall}

アプリの土台を入れ替える版では、［更新して再起動］ の代わりに「この版はアプリの土台を入れ替えるため、インストーラーで入れ直してください。…」と ［ダウンロード］ が出ます。
［ダウンロード］ で開くページから新しい `NaTsu-<版>-setup.exe` を落として実行してください。同じ場所に入り、設定・議事録・エンジンはそのまま残ります。

Claude デスクトップに NaTsu を登録しているときは、入れ直す前に Claude デスクトップを終了してください（タスクトレイのアイコンからも）。動いたままだと、インストーラーが「NaTsu が動いています」と止まります（[Claude から議事録を読む](start/claude-mcp.md#reinstall)）。

## 会社の通信の検査で止まるとき {#proxy}

Zscaler などの会社の通信の検査で、取り込みや更新が止まることがあります。
取り込みの欄に ［担当に渡す内容を写す］ が出たら、押して写した内容を情報システムに渡し、次の接続先の許可を頼んでください。

- 取り込み: `github.com`・`release-assets.githubusercontent.com`・`huggingface.co`・`*.hf.co`
- 更新の確かめ: `api.github.com`・`github.com`
