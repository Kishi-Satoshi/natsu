NaTsu は、会議を録音して文字起こしし、要約まで作る Windows のアプリです。話した言葉をそのまま入力する「音声入力」もあります。
このページでは、初めて使うときの準備（10 分ほど）と、会議を記録して議事録を作るまでを順に説明します。
写真は、作り物の会議のデータで撮った NaTsu の画面です。画面のどこに何があるかは [NaTsu の全体像](start/overview.md) を見てください。

## 用意するもの {#prepare}

- Windows 10 / 11（64bit）の PC（管理者の権限は要りません）
- 会社のメールアドレス（ログインに使います）
- Claude の有料のプラン（Pro・Max・Team など。要約に使います）

## 手順1. インストールする {#install}

1. 配布のページ（[最新のリリース](https://github.com/Kishi-Satoshi/natsu/releases/latest)）を開きます。
2. 「Assets」の中の `NaTsu-<版>-setup.exe` だけを落として、ダブルクリックします。
   - 「Windows によって PC が保護されました」と出たら、**詳細情報** → **実行** で進めます（署名を付けていないため出ます）。
   - ダウンロードが途中で止まるときは、同じページの `get-installer.ps1` を落として実行します。
3. デスクトップとスタートメニューに NaTsu ができます。

くわしくは [インストールと更新](start/install-update.md) を見てください。

## 手順2. ログインする {#login}

ローカル AI の準備をしていない PC でログインしていないときは、NaTsu を起動すると ［設定］ が「アカウント」を開いた形で出ます。
出ないときは、サイドバーの ［設定］ を押し、左の列の ［アカウント］ を押します。

![［設定］の「アカウント」の画面。左の列の［アカウント］・［ログイン］・「ログイン」の横の ⓘ に 1 から 3 の番号が付いている](assets/shots/login.svg)

1. 左の列の ［アカウント］
2. ［ログイン］。押すと、ログインの窓が開きます。
3. 「ログイン」の横の ⓘ。押すと、ログインの手順が出ます。

ログインの手順:

1. ［ログイン］ を押します。英語のログインの画面が出ます。
2. 会社のメールアドレスを入れて **Send login code** を押します。
3. Cloudflare から英語のメールが届くので、6 けたのコードを入れて **Sign in** を押します。
   - 届かないときは、迷惑メールのフォルダも見てください。
   - 「already been used」と出たら、**Request new code** でコードを頼み直してください。
4. 「アカウント」が「ログイン中: （メールアドレス）…」になれば済みです。

ログインは 7 日で切れます。切れたら NaTsu が知らせるので、同じ手順でログインし直してください（[ログインする](start/login.md)）。

## 手順3. 要約の準備をする（Claude Code） {#claude-code}

要約は、ご自分の Claude Code で作ります。
PowerShell を打たなくても、サイドバーの ［設定］ を押し、左の列の ［要約］ を押すと出るボタンで用意できます。

![［設定］の「要約」の画面。左の列の［要約］・Claude Code の様子の文・［Claude Code を確かめる］に 1 から 3 の番号が付いている](assets/shots/claude.svg)

1. 左の列の ［要約］
2. Claude Code の様子の文です。「ログイン済み（確かめ済み）」と出れば使えます（写真は、様子を読めなかったときの赤い文です）。
3. ［Claude Code を確かめる］。Claude Code が見つからないときは、この右に ［Claude Code を入れる］ が、見つかったときは ［Claude Code にログイン］ が出ます。

出ているボタンを、上から順に押します。

1. ［Claude Code を入れる］ が出ていれば押します。PowerShell の窓が開いて自動で入るので、終わったら窓を閉じます（NaTsu が確かめ直します）。
2. ［Claude Code にログイン］ を押し、窓の案内に従って claude.ai のアカウントでログインします。終わったら窓を閉じます。
3. ［Claude Code を確かめる］ を押し、「ログイン済み（確かめ済み）」と出れば済みです。

> [!NOTE]
> ［Claude Code を入れる］ は、インターネットから取った Anthropic の入れる命令をそのまま実行します。会社の PC で決まりがあるときは、情報システムに確かめてから押してください（[Claude Code を入れてログインする](start/claude-code.md)）。

## 手順4. 相手の声も録る（Teams などの会議） {#loop}

オンライン会議の相手の声も文字起こしに入れるときは、サイドバーの ［設定］ を押し、左の列の ［録音］ を押して、「議事録で相手の声も録る」を有効にします。

![［設定］の「録音」の画面。左の列の［録音］・「議事録で相手の声も録る」のスイッチ・その下の注意の文に 1 から 3 の番号が付いている](assets/shots/loop.svg)

1. 左の列の ［録音］
2. 「議事録で相手の声も録る」のスイッチ。押して有効にします（写真は、切れている既定の形です）。
3. 「※ 録音していることは、会議の参加者に伝えてください。」

- パソコンから出ている音（通知音や動画の音も）を、マイクと一緒に録ります。
- 声が二重に入るのを避けるため、ヘッドホンを使ってください。
- 文字起こしの行には「自分」「相手」が付きます（[文字起こしの「自分」「相手」](record/start-stop.md#speakers)）。

## 会議を記録する {#record}

### 始める {#record-start}

サイドバーの ［＋ 新しい議事録］ を押すと、録音の前のページが開きます（まだ録音しません）。
［文字起こしを始める］ を押すと、録音と文字起こしが始まります。

![録音の前のページの画面。サイドバーの［＋ 新しい議事録］・［文字起こしを始める］・同意と送り先の文に 1 から 3 の番号が付いている](assets/shots/start.svg)

1. サイドバーの ［＋ 新しい議事録］。録音の前のページを開きます。
2. ［文字起こしを始める］。押すと録音が始まります。
3. 「始めると、録音と文字起こしに参加者全員が同意したものとみなされます。」の文と、音声の送り先です。

始める前に、参加者に録音と文字起こしの了承を取ってください。

すぐ録音したいときは [[Alt+M]] を押します。録音の前のページを飛ばして、すぐ録音が始まります（ほかのアプリを使っていても効きます）。

### 録音中のページ {#record-live}

録音中は「記録中」のタブになり、文字起こしが少しずつ流れます。

![録音中のページの画面。経過時間の行・一時停止・終了して作成・オフラインモード・文字起こし・サイドバーのボタンに 1 から 6 の番号が付いている](assets/shots/live.svg)

1. 経過時間と、今の録音の様子です。その下の行は、文字起こしがどこで進んでいるか（クラウドか、この PC か）です。
2. ［⏸ 一時停止］ で録音を止め、［▶ 再開］ で続けます。
3. ［■ 終了して作成］ で録音を止め、議事録を作ります。もう一度 [[Alt+M]] を押しても止まります。
4. ［オフラインモード］ を押すと、この会議のその後の文字起こしを PC の中に固定します（[ネットワークが不安定なときの会議](record/pc-only.md)）。
5. 文字起こしです。相手の声も録る会議では、行に「自分」「相手」が付きます。
6. サイドバーにも ［■ 終了して作成］ と、録音を捨てる ［破棄］ が出ます。

### 録音バー {#record-bar}

録音中は、画面の下の中央に小さな録音バーも出ます。ドラッグすると、画面の8か所の置き場所の一番近い所に付きます。

![録音バーの画面。音の大きさの点・経過時間・一時停止のボタン・停止のボタンに 1 から 4 の番号が付いている](assets/shots/bar.svg)

1. 音の大きさの5つの点（声が入ると揺れます）
2. 経過時間
3. 一時停止のボタン
4. 停止のボタン（録音を止めて議事録を作ります）

### できあがった議事録 {#record-done}

止めると、残りの文字起こしと要約が進み、終わると要約の入った議事録のページに替わります。

![議事録のページの画面。［AI 要約］のタブ・要点の出典・項目の出典に 1 から 3 の番号が付いている](assets/shots/minutes.svg)

1. ［AI 要約］ のタブに要約が出ます。右の ［メモ］・［文字起こし］ のタブに切り替えられます。
2. 要点の右の時刻（出典）を押すと、文字起こしのその発言へ飛びます（[出典リンク](summary/citations.md)）。
3. 項目の「出典」は、出典の付いた要点の数と、要点の数です。

録音の始め方と止め方のくわしいことは [録音を始める・止める](record/start-stop.md) を見てください。

## 音声入力 {#dictation}

文字を入れたい場所（メールやチャットの入力欄など）をクリックして [[Ctrl+Shift+Space]] を押し、話します。
もう一度 [[Ctrl+Shift+Space]] を押すと止まり、文字がカーソルの位置に入ります（[音声入力](dictation/dictation.md)）。

## 知っておいてほしいこと {#notes}

- ログインしていてインターネットにつながっているときは、会議の音声を、文字起こしの中継（音声を OpenAI へ取り次ぐ NaTsu のサーバー）を通して OpenAI に送って文字起こしします。中継は音声も文字も保存しません。
- 要約は、ご自分の Claude Code で作ります。
- 議事録は、この PC の中にだけ保存されます（[どこに保存されるか](start/overview.md#storage)）。
- インターネットにつながっていないときも PC の中で文字起こしをしたいときだけ、［設定］→［ローカル AI］の ［ローカル AI を使う］ で取り込みます（任意・約 0.6GB。[ローカル AI](settings/offline.md)）。
- 新しい版は、［設定］→［更新］の ［更新を確認］ で確かめ、［更新して再起動］ で更新します。録音中は、更新の再起動をしません（[インストールと更新](start/install-update.md#update)）。

> [!WARNING]
> ［オフラインモード］ は、守秘のためのボタンではありません。要約を作るときと、Claude に議事録を読んでもらうときは、その会議の文も Claude（Anthropic）へ送られます。1on1・面談の前に [ネットワークが不安定なときの会議](record/pc-only.md) を読んでください。

## 困ったとき {#help}

- ［設定］ の左の列のいちばん下の ［ヘルプ］ から、このヘルプセンターを開けます。
- 録音中のページの頭に帯が出たときは [帯ごとの対処](trouble/banners.md) を見てください。

解決しないときは、Teams の NaTsu のチャンネルで聞いてください。次の3つがあると助かります。

1. 何をしたか（どの画面で、どのボタンを押したか）
2. 何が起きたか（出た文はそのまま。画面の写真があると一番助かります）
3. だいたいの時刻
