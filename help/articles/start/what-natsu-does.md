NaTsu は、会議を録音して文字起こしし、要約まで作る Windows のアプリです。
話した言葉をそのまま入力する音声入力もあります。

## 議事録 {#minutes}

- サイドバーの ［新しい議事録］ か [[Alt+M]] で録音を始め、［■ 終了して作成］ か、もう一度 [[Alt+M]] で止めます。
- 録音中は、文字起こしが少しずつページに流れます。止めると要約ができます。
- 要約の要点には、もとの発言へのリンク（出典）が付きます。発言が見つからない要点には「根拠なし」と出ます。
- 議事録は、この PC の中にだけ保存されます。

## 音声入力 {#dictation}

[[Ctrl+Shift+Space]] を押して話すと、今開いている場所（メールやチャットの入力欄など）に文字が入ります。

## オンラインとオフライン {#online-offline}

- **ログインしていて、インターネットにつながっているとき:** 会議と音声入力の音声を、会社の文字起こしの中継（音声を OpenAI へ取り次ぐ会社のサーバー）を通して OpenAI へ送って文字起こしします（中継は音声も文字も保存しません）。要約は、ご自分の Claude Code に文字起こしの文を渡して作ります。
- **ログインしていないとき・つながっていないとき:** 音声を中継へ送りません。ローカル AI の準備（PC の中の文字起こし。約 0.6GB の取り込み）をした PC は、PC の中で文字起こしをします（クラウドより精度が落ちます）。準備をしていない PC は、会議の音声を PC に残し、ログインしてつながると自動で文字起こしします。
- **要約:** いつもご自分の Claude Code で作ります（0.10.0 から。PC の中では要約しません）。会議の終わりにつながっていなければ「要約待ち（つながったら作ります）」と出し、つながったら自動で作ります（[要約の作られ方](summary/how-summaries.md)）。
- どこで処理したかは、議事録の上の行に「☁ 文字起こし: クラウド（OpenAI）」「✨ 要約: Claude Code」のように出ます。

ローカル AI の準備は任意です。取り込みは ［設定］→［ローカル AI］の ［ローカル AI を使う］ から行います（[ローカル AI](settings/offline.md)）。

> [!NOTE]
> ネットワークが不安定な会議では、録音中に ［オフラインモード］ を押すと、その会議の文字起こしを PC の中に固定できます。守秘のためのボタンではありません（要約のときは文が Claude へ送られます）。くわしくは [ネットワークが不安定なときの会議](record/pc-only.md) を見てください。

## Claude から読む {#claude}

Claude デスクトップに NaTsu を登録すると、Claude に「10/20 の議事録を読んで、レポートして」のように頼めます。Claude は議事録を読むだけで、書き換えません。Claude に頼むと、Claude が読んだ議事録の文は Claude（Anthropic）へ送られます（[Claude から議事録を読む](start/claude-mcp.md)）。

## このヘルプを開く {#help}

NaTsu の ［設定］ の左の列のいちばん下の ［ヘルプ］ を押すと、このヘルプセンターがブラウザで開きます。設定の説明の ⓘ の「ヘルプで詳しく見る ↗」からは、その話の記事が開きます。
