NaTsu のページには、録音して作る議事録と、録音しないで書く白紙のページがあります。
どちらのページも、ほかのページの中に入れられます。プロジェクトのページの中に、その会議の議事録や資料のページをまとめる、のように使えます。

## 白紙のページ {#blank}

白紙のページは、題名と本文だけのページです。会議の種類・長さ・［AI 要約］などのタブ・［要約を生成］はありません。

- 本文は、要約の行と同じに書けます（/ で行の型を選ぶ・⠿ で動かす・貼り付け・[[Ctrl+Z]] で元に戻す。[要約を書き直す](summary/edit-summary.md)）。本文が空のときは「ここに書く（/ で行の型を選べます）」を押すと、最初の行から書けます。
- 題名を付けないと、一覧では「無題のページ」と出ます。
- サイドバーとパンくずでは、アイコンを選んでいなければ、白紙のページは 📄、議事録は 🎙️ の印で見分けます（アイコンは選べます: [ページのアイコンと見た目](find/page-look.md#icon)）。
- 「···」には ［コピー］・［リンクを写す］・［移動先…］・見た目の項目（［全幅］・［小さい文字］・［書体 ▸］: [ページのアイコンと見た目](find/page-look.md#look)）・［削除］ があります。
- 白紙のページの ToDo も、検索の窓の ［アクション］ に出ます（[議事録を探す](find/search.md#scope)）。

## 新しいページを作る {#create}

- サイドバーの見出し「プライベート」の右の ［＋］ で、いちばん上に白紙のページを作ります（［＋］ は見出しに乗せると出ます。一覧を畳んでいるときは、開いてから作ります）。作ると開いて、題名から書けます。
- NaTsu の窓のどこでも [[Ctrl+Shift+N]] を押すと「新しいページ」が開きます。［📄 白紙のページ］ か ［🎙️ 議事録（録音の前のページ）］ を [[↑]]・[[↓]] と [[Enter]] で選びます（[[Esc]] で閉じます）。［🎙️ 議事録（録音の前のページ）］ は ［＋ 新しい議事録］ と同じです。録音中は灰色で「録音中です」と出ます。
- ページの中に作るときは、サイドバーの行に乗せると出る右の ［＋］ を押すか、行のメニューの ［中にページを作る］ を押します。
- 本文（白紙のページの本文と、議事録の ［AI 要約］）で /ページ と打って選ぶと、開いているページの中に白紙のページを作って開きます。白紙のページでは、打った所にそのページの行ができます。

新しい議事録はいちばん上にできます。録音を終えてから、中に入れたいページへ動かしてください。

## プライベートの見出し {#private}

サイドバーのページの一覧は、見出し「プライベート」の下に並びます（議事録も白紙のページも、この PC の自分のページです）。

- 見出しを押すと、一覧を畳む・開くが替わります（開いているときは ⌄、畳んでいるときは › の印）。畳んでいる間に検索・タブ・リンクからページを開いても、畳んだままです。畳んだ形は覚えていて、次に起動したときも同じです。
- 見出しに乗せると、右に ↗・［＋］・［···］ が出ます。↗ はライブラリを開きます（[ライブラリ](#library)）。［＋］ はいちばん上に白紙のページを作ります（[新しいページを作る](#create)）。
- ［···］ には ［並べ替え］・［表示］・［ページを選ぶ］ があります。[[→]] か [[Enter]] で下の選びを開き、[[←]] か [[Esc]] で戻ります。選んだ並べ替えと表示は覚えています。
  - **［並べ替え］:** ［手動］ は、いちばん上のページは作った新しい順、中のページは引っ張って並べた順です。［最終更新］ は、どの段も、最後に書いた新しい順に並べます（中のページは親の下のまま）。最終更新は、題名・本文・要約・メモ・アイコン・見た目を変えた時です。ページを動かしただけでは変わりません（白紙のページの中へ入れる・出すときは、その白紙のページの本文の行が変わるので、その白紙のページの最終更新が変わります）。［最終更新］ の間は、行を引っ張って前後へ並べられません（「並べ替えを「手動」に戻すと、手で並べられます」と出ます。行の真ん中へ落として中へ入れるのは、今までどおりできます）。
  - **［表示］:** いちばん上に出すページの数（［5］・［10］・［15］・［20］・［すべて］）。中のページは数えません。出していないページがあると、一覧の下に ［もっと見る］ が出て、押すとライブラリを開きます。
  - **［ページを選ぶ］:** 行の頭がチェックボックスになり、いくつものページのリンクをまとめて写せます（[Claude から議事録を読む](start/claude-mcp.md)）。一覧を畳んでいれば、開いてから選べます。

## サイドバーの木 {#tree}

サイドバーの一覧は、ページの中のページを字下げして並べる木です。

- 中にページのある行は、行の頭の印を押すと開く・閉じるが替わります。開け閉めは覚えていて、次に起動したときも同じです。
- いちばん上のページは、作った新しい順に並びます。中のページの並びは、引っ張って変えられます。白紙のページの中のページは、本文の行の順に並びます。
- 行に乗せると出る右の ［···］ を押すか、行を右クリックするか、行で [[Shift+F10]] を押すと、行のメニュー（［リンクを写す］・［名前を変える］・［移動先…］・［中にページを作る］・［新しいタブで開く］・［削除］）が開きます。メニューのいちばん下に、そのページの最終更新の日時が出ます。

| キー | 動き |
| --- | --- |
| [[↑]]・[[↓]] | 見えているページの行を上・下へ移る |
| [[→]] | 行を開く（開いていれば最初の中のページへ） |
| [[←]] | 行を閉じる（閉じていれば親のページへ） |
| [[Enter]] | ページを今のタブで開く |
| [[Ctrl+Enter]] | ページを新しいタブで開く |
| [[Ctrl+Shift+R]] | ページの名前を変える |

ほかのキーは [ホットキー](settings/hotkeys.md#in-app) を見てください。

## ページの名前を変える {#rename}

- 行のメニューの ［名前を変える］ を押すか、サイドバーかライブラリの行で [[Ctrl+Shift+R]] を押すと、行の題名の所が1行の欄になります。
- 打って [[Enter]] で決めます（日本語の変換を確定する [[Enter]] では決まりません）。欄の外を押すか [[Tab]] で出ても決まります（ほかの窓に切り替えただけでは決まりません）。[[Esc]] でやめます。
- 改行やタブは空白になります。空のまま決めると、元の名前に戻ります（ページの頭の題名と同じです）。
- 題名の無いページ（一覧で「無題のページ」、議事録は「(無題の議事録)」と出るページ）では、欄は空から始まります。
- 開いているページの名前を変えると、タブの名前とページの頭の題名も替わります。名前を変えられなかったときは元に戻り、「名前を変えられませんでした。」と出ます。
- 名前を変えるのは [[Ctrl+Z]] で戻せません（ページの頭の題名と同じです）。

## ライブラリ {#library}

ライブラリは、プライベートのページの全部を1つのタブの表で見る所です。サイドバーの見出しの ↗ か、一覧の下の ［もっと見る］ で開きます（ライブラリのタブは1つで、次に起動したときも戻ります）。

- 表は「ページ名」と「最終更新日時」の2つの列です。最終更新日時は「たった今」「5 分前」「3 時間前」「2 日前」「1 週間前」のように出て、5 週より前は日付です（乗せると「年/月/日 時:分」が出ます）。中のページのある行は、頭の ▸ で開け閉めします（サイドバーの木の開け閉めとは別です）。
- 列の見出しを押すと、その列で並べ替えます。もう一度押すと逆の順です。「ページ名」は名前の順（数は小さい順。漢字は読みの順には並びません）、「最終更新日時」は新しい順から始まります。どちらも、中のページは親の下のまま並べます。
- 「ページを探す」の欄に打つと、題名に語を含むページだけを並べ、題名の下に場所（親のページ）を出します（ひらがなとカタカナ、全角と半角は同じに扱います）。当たりが無ければ「当てはまるページはありません」と出ます。
- 行を押すか [[Enter]] で、ライブラリのタブがそのページに替わります。[[Ctrl]] を押しながら押すか [[Ctrl+Enter]] で、新しいタブに開きます。行のメニュー（右クリック・[[Shift+F10]]）と [[Ctrl+Shift+R]] は、サイドバーの行と同じです。
- ［＋ 新しいページ］ で、いちばん上に白紙のページを作って開きます。
- 並べ替え・探す語・開け閉めは覚えません（ライブラリのタブを閉じるか、起動し直すと元に戻ります）。

## ページを動かす {#move}

- **引っ張る:** サイドバーの行を、ほかの行の真ん中に落とすとその中の最後へ、行の上の端・下の端に落とすとその前・後ろへ動きます。動かしている間に [[Esc]] を押すとやめます。
- **［移動先…］:** 「···」か行のメニューの ［移動先…］ を押すと、行き先の一覧が開きます。題名と場所の語で絞り、[[↑]]・[[↓]] と [[Enter]] で選びます。先頭の ［いちばん上へ］ で、いちばん上のページにします。

自分の中や、自分の中のページの中へは動かせません（行き先の一覧にも出ません）。中のページは、親と一緒に動きます。
録音中のページは動かせません。録音中のページはサイドバーの木にも出ず、録音を終えて議事録ができると、いちばん上に出ます。

## パンくずと親のページへ戻る {#crumb}

- ページの上の帯の左に、いちばん上のページから今のページまでの道（パンくず）が出ます。段を押すと、そのページを開きます。
- 深いページでは、途中の段が「…」にまとまります。「…」を押すと、隠れた段の一覧が出ます。
- [[Ctrl+Shift+U]] で、開いているページの親のページへ移ります（いちばん上のページでは何もしません）。

## ページの中のページの見え方 {#kids}

- 白紙のページでは、中のページは本文の中の「📄 題名」の行です。押すと開き、[[Ctrl]] を押しながら押すと新しいタブで開きます。行は ⠿ でほかの行と同じに動かせます。
- 本文の行を消すと、そのページ（と、その中のページ）はゴミ箱へ入り、「ページ … 件をゴミ箱に入れました（Ctrl+Z で戻せます）」と出ます。[[Ctrl+Z]] で戻せます。
- ページの行は複製できません（「ページの行は複製できません」と出ます）。
- 本文が 2,000 行に達しているときや、本文に行の無い中のページは、本文の後ろの「このページの中のページ」に並びます。
- 議事録の中のページは、［AI 要約］ の最後の「このページの中のページ」に並びます。

## 消す・戻す・探す {#more}

- 中のページのあるページを消すと、中のページも一緒にゴミ箱へ入ります。［ゴミ箱］ から戻すと、一緒に消した中のページも戻ります（[ページを消す・戻す・毎日の控え](find/delete-and-backups.md)）。0.15.0 より前の版で消した議事録も ［ゴミ箱］ に並び、戻せます（[ゴミ箱から戻す](find/delete-and-backups.md#restore)）。
- 検索の窓の結果では、中のページの2行目の頭に「場所: 親 / 子 ・ 」が出ます（[議事録を探す](find/search.md)）。
- Claude から読むときも、中のページには場所が付き、白紙のページも読めます（[Claude から議事録を読む](start/claude-mcp.md)）。
