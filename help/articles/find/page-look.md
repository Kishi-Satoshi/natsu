ページごとに、アイコンと見た目（全幅・文字の大きさ・書体）を選べます。議事録にも白紙のページにも使えます。

## アイコンを選ぶ {#icon}

1. ページの頭の大きなアイコン（議事録は 🎙️、白紙のページは 📄）を押します。
2. アイコンの選びが開きます。上の欄に名前かよみを打つと絞れます（「しょるい」「ショルイ」「書類」のどれでも 📄 が出ます）。
3. 使いたい絵文字を押します。キーボードでは [[↓]] で並びへ移り、[[↑]]・[[↓]]・[[←]]・[[→]] で選んで [[Enter]] を押します。

- 欄が空のときは、いちばん上に ［最近使ったもの］（新しい順に 24 まで）、その下に分類ごとの並び（顔・人と手・動物と自然・食べ物・活動・旅と場所・物・記号）が出ます。
- ［外す］ を押すと、既定のアイコン（議事録は 🎙️、白紙のページは 📄）に戻ります。
- [[Esc]] で閉じると、アイコンは変わりません。
- 選べるのは NaTsu の絵文字の一覧（約 500）にあるものだけです。旗の絵文字はありません。

選んだアイコンは、サイドバーの行・ページのタブ・上の帯のパンくず・検索の窓の結果・白紙のページの本文の「📄 題名」の行・議事録の「このページの中のページ」にも出ます。Claude から読む答えには出ません。

## 見た目を選ぶ {#look}

上の帯の右の「···」を押すと、見た目の項目があります。押すたびに、そのページだけに効きます。

| 項目 | 動き |
| --- | --- |
| ［全幅］ | 本文の列の幅の決まりを外し、窓の幅いっぱいに広げます（左右に余白を残します） |
| ［小さい文字］ | ページの中の字を1段小さくします |
| ［書体 ▸］ | 標準・明朝・等幅から選びます（明朝と等幅は Windows にある書体で描きます） |

- ［全幅］ と ［小さい文字］ は、もう一度押すと外れます。付いている項目には ✓ が出ます。
- ［書体 ▸］ は、押すか [[→]] で 標準・明朝・等幅 が出ます。[[←]] で ［書体 ▸］ に戻ります。
- 効くのは、そのページの題名・本文・メモ・文字起こしです。サイドバー・タブ・上の帯・設定と、ほかのページには効きません。ページを替えると、そのページの見た目になります。

## 録音中は {#live}

録音中の会議のページでは、アイコンと見た目は変えられません（ページの頭のアイコンを押しても開かず、「···」に見た目の項目は出ません）。議事録ができてから選んでください。
