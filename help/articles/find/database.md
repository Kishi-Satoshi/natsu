データベースは、行と列でものごとをまとめるページです。1つの行は、題名と列の値を持ち、行のページを開くと本文も書けます。
同じ行を、表やリストの「ビュー」で、並べ替えたり絞り込んだりして見ます。

## データベースを作る {#create}

- NaTsu の窓のどこでも [[Ctrl+Shift+N]] を押し、「新しいページ」の ［🗃️ データベース］ を選ぶと、いちばん上にデータベースを作って開きます。
- サイドバーの行のメニュー（右クリックか [[Shift+F10]]）の ［中にデータベースを作る］ で、そのページの中に作ります。白紙のページの中に作ると、本文の最後に「🗃️ 題名」の行ができます。
- 白紙のページの本文で /データベース と打って選ぶと、打った所に表を置きます（[インラインの表とリンクドビュー](#inline)）。

新しいデータベースは、題名が「無題のデータベース」で、列は題名の列（見出し「名前」）だけ、ビューは「表」が1つ、行はありません。作るとすぐ題名から書けます。

サイドバーでは、データベースは 🗃️ の印で、ほかのページと同じ木に並びます。行は木に出ません。データベースの中へページを入れることはできません（[ページの中のページ・白紙のページ](find/page-tree.md#tree)）。

## 表とリスト {#table}

- ［＋ 新しい行］ で行を足し、すぐ題名を書けます。表の最後の行の題名で [[Enter]] を押しても、次の行を足します。
- セルを押す（か、選んで [[Enter]]）と、列の種類ごとの書き手が開きます（[列の種類](#columns)）。
- 行の頭の ⋮⋮ を引っ張ると、行の並びを変えられます。並べ替えのあるビューでは引っ張れず、「並べ替えを外すと、手で並べられます」と出ます。
- 行に乗せると出るチェックで行を選びます。題名の列の見出しのチェックで、全部の行を選びます。選んだ行には ［削除］・［リンクを写す］・［列の値を変える ▸］（選んだ行の1つの列を同じ値にする）が出ます。
- 行を右クリックするか、⋮⋮ を押すと、行のメニュー（［開く］・［新しいタブで開く］・［リンクを写す］・［削除］）が開きます。

行を消すと、確かめずにゴミ箱へ入り、「行 … 件をゴミ箱に入れました（Ctrl+Z で戻せます）」と出ます。[[Ctrl+Z]] か ［ゴミ箱］ から戻せます（[ページを消す・戻す・毎日の控え](find/delete-and-backups.md#restore)）。

表計算のソフトや表から写した、タブで区切った何行何列かの文字は、選んだセルに [[Ctrl+V]] で貼れます。選んだセルから右下へ埋め、行が足りなければ行を足します。読めなかった値は空にして、その数を知らせます。

リストのビューでは、行ごとに 📄 と題名、その右に出すと決めた列の値が並びます。

## ビュー（タブ） {#views}

ビューは、同じ行の見せ方です。並べ替え・絞り込み・グループ・出す列と幅は、ビューごとに覚え、ほかのビューには写りません。

- タブの右の ［＋］ で「ビューを足す」が開き、［表］ か ［リスト］ を選んで名前を付けます。
- 今のタブを押すか、タブを右クリックすると、タブのメニュー（［名前を変える］・［複製］・［リンクを写す］・［削除］）が開きます。最後の1つのビューは消せません。
- ［リンクを写す］ で写したリンクを開くと、そのビューのタブを選んで開きます。
- タブは引っ張って並べ替えられます。入り切らないタブは「他 … 件」から選びます。
- 行が 3 つ以上あると、タブの並びの右に「この中を探す」の欄が出ます。題名と、テキストなどの列の値・選択肢の名前で絞ります。語はビューに覚えません（[[Esc]] で消えます）。

ビューを消すときは「ビュー『名前』を削除します。並べ替えや絞り込みの設定も消えます。行は消えません。」と確かめます。

## 並べ替え・絞り込み・グループ {#sort-filter}

タブの並びの右の ⚙（ビューの設定）を押すと、［並べ替え］・［絞り込み］・［グループ］・［列の表示］・［消した列］ が出ます。どれも今のビューの設定です。

- **並べ替え:** ［並べ替えを足す］ で列と「昇順」か「降順」を選びます。いくつも重ねられ、⋮⋮ で優先を替えます。空の値は、いつも最後に並びます。
- **絞り込み:** ［条件を足す］ で、列と条件と値を選びます。条件は ［かつ］ か ［または］ でつなぎ、［グループを足す］ で条件をまとめられます（3 段まで）。
- **グループ:** 列を選ぶと、値ごとにまとめて並べます。日付は日・週・月・年で、ステータスは3つのまとまりか選択肢ごとにまとめます。グループの頭の ▸ で開け閉めし、グループの ［＋］ でそのグループに入る値の行を足します（日付の週や月のように値が1つに決まらないグループでは、値の無い行を足します）。［空のグループを隠す］・［昇順に並べる］ もあります。
- **列の表示:** 列ごとのチェックで出す・隠すを替え、⋮⋮ で並びを替えます。表の列の見出しを引っ張っても並べ替えられ、見出しの右の端を引っ張ると幅が変わります。

表の下の列ごとの欄を押すと、集計（全件・空の数・合計・平均・最も早い・チェック済みの割合 など）を選べます。集計は、絞り込んだ後の行で数えます。

並べ替え・絞り込みなどのビューの設定は、[[Ctrl+Z]] では戻りません。

## 列の種類 {#columns}

表の右端の ［＋］ で列を足します。列の見出しを押すと、列のメニュー（［名前を変える］・［種類 ▸］・［左に入れる］・［右に入れる］・［折り返す］・［集計 ▸］・［隠す］・［削除］）が開きます。［隠す］ はそのビューだけで隠し、［削除］ は列を消します（[消した列](#gone)）。

| 種類 | 書き方 |
| --- | --- |
| ［テキスト］ | 文字を書きます |
| ［数値］ | 数を書きます。数として読めない文字は「この列の値として読めませんでした。」と断ります。列のメニューの ［見せ方 ▸］ で、数・3桁区切り・%・円・ドルの見せ方を選べます（値は数のままです） |
| ［選択］・［複数選択］ | 選択肢から選びます。無い名前を打つと ［選択肢を足す］ で足せます。選択肢の色は列のメニューの ［色 ▸］ で選びます |
| ［ステータス］ | 選択肢が「未着手」「進行中」「完了」のまとまりに分かれた選択です |
| ［日付］ | 暦で選びます。［今日］ と、終わりの日・時刻も入れられます |
| ［ユーザー］ | 人の名前を書きます。そのデータベースで使った名前と、議事録の ToDo の担当の名前が候補に出ます |
| ［チェック］ | 押すか [[Enter]] で、付ける・外すが替わります |
| ［URL］・［メール］ | 値の文字を押すと開きます（URL は http と https だけ） |
| ［電話］ | 値の文字を押すと写します（「コピーしました」） |
| ［リレーション］ | ほかの行とつなぎます（[リレーション](#relation)） |

- 種類を変えると、今の値を新しい種類に読み替えます。読めずに空になる値があるときは「種類を変えると、… 個の値が読めずに空になります。よろしいですか？（Ctrl+Z で戻せます）」と確かめます。リレーションへ・リレーションからは変えられません。
- 列を足す・名前を変える・種類を変える・消す・戻す、セルを書く、行を足す・動かす・消すは、表のセルを選んでいるときの [[Ctrl+Z]] で戻せます。
- 計算式とロールアップは後の版です。今の版では、ほかの列やつないだ行の値から計算する列はありません（表の下の集計は、同じデータベースの中だけで数えます）。

## 消した列 {#gone}

列のメニューの ［削除］ で消した列は、確かめずに表から消えます。消した列は戻せます。⚙ の ［消した列］ に並び、［戻す］ で値ごと元に戻ります。

［完全に消す］ は「この列と、すべての行のこの列の値を完全に消します。元に戻せません。よろしいですか？」と確かめてから、列と値を消します。[[Ctrl+Z]] でも戻りません。
完全に消した列の値は、操作の記録と控えを整理するまで、NaTsu のデータの中にしばらく残ります。

リンクドビューやインラインの表の列のメニューで［削除］した列は、元のデータベースから消えます（ほかのビューやリンクドビューからも消えます）。［ビューの設定］の［消した列］から戻せます。そのビューで見せたくないだけなら［隠す］を使います（隠すのはそのビューだけです）。

## リレーション {#relation}

リレーションの列は、ほかのデータベース（同じデータベースでもかまいません）の行とつなぎます。

1. 表の右端の ［＋］ で ［リレーション］ を選ぶと、「つなぐデータベース」の窓が開きます。
2. 相手の列も要るときは「相手のデータベースにも列を作る」にチェックを入れ、つなぐデータベースの名前を押します。
3. セルを押すと「行を探す」の窓が開きます。題名で探し（ひらがなとカタカナは同じに当たります）、押すとつなぎ、もう一度押すと外します。［新しい行を作ってつなぐ］ で、打った題名の行を相手に作ってつなぎます。

- セルには、つないだ行が「📄 題名」で並びます。押すと、その行のページを開きます。窓の中の行で [[Ctrl+Enter]] を押しても開きます（つなぐ・外すはしません）。
- 相手にも列を作ったときは、こちらでつなぐ・外すと、相手の行のセルも同じに替わります。同じデータベースの中で列を1つだけ作ったときも、つないだ2つの行は互いを指します。
- ゴミ箱に入れた行は、セルに出ません（戻すとまた出ます）。

## サブアイテム {#subitems}

サブアイテムは、同じデータベースの行を親と子の木にする形です。

- データベースのページの「···」の ［サブアイテム］ で入れると、「親アイテム」と「サブアイテム」の2つの列ができます。もう一度押すと外れます（2つの列はふつうのリレーションの列として残ります）。
- 行のメニューの ［サブアイテムを足す］ で、その行の中に行を足します。子のある行は、題名の前の ▸ で開け閉めします（題名のセルを選んで [[Alt+→]]・[[Alt+←]] でも開け閉めできます）。子は字下げして並びます。
- 親は1つの行だけです。自分の中の行を親にしようとすると「その行の中へは入れられません」と出ます。
- 絞り込みは子にも効きます。当たった子の親は、灰色で出ます。
- 子のある行を消すと、中の行も一緒にゴミ箱へ入り、[[Ctrl+Z]] や ［ゴミ箱］ の ［戻す］ で一緒に戻ります。
- サブアイテムを入れている間は、2つの列の ［削除］ は灰色です。外してから消してください。

## インラインの表とリンクドビュー {#inline}

白紙のページの本文に、データベースの表を置けます（議事録の ［AI 要約］ には置けません）。表の頭には 🗃️ と題名の欄と ⤢ があり、題名を変えると元のデータベースの題名が変わります。⤢ を押すと、データベースのページを開きます。表は 15 行ほどの高さで、それより多い行は表の中を捲って見ます。

- **インラインの表:** /データベース で作った表です。データベースそのものなので、タブも列も行もデータベースのページと同じです。本文の行のメニューの ［ページの行に変える］ で「🗃️ 題名」の1行に、［インラインにする］ で表に戻ります。本文の行を消すと、データベースがゴミ箱へ入ります（[[Ctrl+Z]] で戻せます）。
- **リンクドビュー:** 本文で /リンクドビュー と打って選ぶと、「つなぐデータベース」の窓が開きます。データベースを選び、続けて「元のビューを写す」のビューか ［新しい表から始める］ を選ぶと、ほかの所にあるデータベースの表をここに置きます。[[Esc]] で窓を閉じると、何も置きません。

リンクドビューで行・セル・列・題名を書くと、元のデータベースに書きます。
リンクドビューで変えた列と題名は、元のデータベースの Ctrl+Z で戻せます。リンクドビューのタブ（並べ替えや絞り込み）は、そのリンクドビューだけのものです。

- リンクドビューのタブの ［リンクを写す］ は、置いたページのその表へのリンクです。
- リンクドビューの行を消しても、元のデータベースは消えません。リンクドビューの行は複製できません（「リンクドビューは複製できません」と出ます）。
- 元のデータベースがゴミ箱にあるときや、もう無いときは、表の代わりに灰色の「（このデータベースは見られません）」が出ます。
- サイドバーのデータベースを、開いている白紙のページの本文へ引っ張って落とすと、そのページの中へ動き、落とした所に「🗃️ 題名」の行ができます。［インラインにする］ で表にできます。本文のインラインの表の ⠿ をサイドバーの木へ引っ張って落とすと、落とした所へ動き、本文の行は消えます（[ページを動かす](find/page-tree.md#move)）。

## 行のページ {#row}

- 題名のセルに乗せると出る ［開く］ か、セルを選んで [[Space]] で、行のページを今のタブに開きます。[[Ctrl]] を押しながら ［開く］ を押すと、新しいタブで開きます。
- 行のページは、頭に 📄 と題名、その下に列の値の並び、その下に本文があります。値を押すと、表と同じ書き手が開きます（書けない列は灰色です）。本文は白紙のページと同じに書けます。
- パンくずには、データベースの段と行の段が出ます。データベースの段を押すと、データベースのページに戻ります。
- 行のページの「···」の ［削除］ は、確かめずに行をゴミ箱へ入れ、データベースのページに戻ります。

## 上限 {#limits}

- 1つのデータベースの行は 10,000 まで・列は 100 まで（消した列も数えます）・ビューは 20 までです。越えると「1つのデータベースの行は 10,000 までです。」「列は 100 までです。」「ビューは 20 までです。」と出ます。
- 1回に貼れるのは 2,000 個の値までです（「1回に貼れるのは 2,000 個の値までです。」）。選んだ行の ［削除］ と ［列の値を変える ▸］ は 2,000 行までです。
- 1つのページに置けるデータベースの表（インラインの表とリンクドビュー）は 10 までです（「1つのページに置けるデータベースの表は 10 までです。」）。
- 1つのリレーションのセルにつなげる行は 100 まで・1つの列の選択肢は 200 まで・テキストのセルは 10,000 字までです。
