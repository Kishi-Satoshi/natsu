## どこでも効くキー {#global}

ほかのアプリを使っていても効くキーです。

| キー | 動き |
| --- | --- |
| [[Ctrl+Shift+Space]] | 音声入力を始める・止める |
| [[Alt+M]] | 議事録の録音を始める・止める |

## キーを変える {#change}

1. ［設定］→［一般］の「ホットキー」の「音声入力ホットキー」か「議事録ホットキー」の欄を押します。
2. 使いたいキーの組を押すと、欄に入ります。Ctrl・Shift・Alt のどれかとの組にしてください（F1 などの F キーは、1つでも使えます）。組でないと「修飾キー（Ctrl/Shift/Alt）との組み合わせにしてください」と出ます。
3. 同じ ［一般］ の中のチェックを1つ（例: 「起動と終了」の「効果音」）2回押して元に戻します。設定が保存され、「保存しました」と出ます。

> [!WARNING]
> この版では、キーを欄に入れただけでは保存されません。手順3 をしないと、前のキーのままです。

- 左右の Alt は区別しません（どちらでも効きます）。
- 欄にフォーカスがあるときの [[Esc]] と [[Tab]] はキーとして入りません（[[Esc]] は欄から抜け、[[Tab]] は次の部品へ移ります）。
- 録音バーのボタンに乗せると出る名前（「停止して議事録を作成（Alt+M）」など）には、今使っているキーが入ります。

## ほかのアプリと重なったとき {#conflict}

ほかのアプリが同じキーを使っていると、NaTsu はそのキーを登録できません。欄の名前の下に赤い文が出ます。

- 「このキーは他のアプリが使用中のため登録できていません」: 別のキーに変えてください。
- 「設定した … は他のアプリが使用中のため、代わりに既定の … を使っています」: 起動のときに登録できず、既定のキーで動いています。

## NaTsu の窓の中だけで効くキー {#in-app}

| キー | 動き |
| --- | --- |
| [[Ctrl+P]] | 検索の窓を開く |
| [[Ctrl+Shift+P]] | 録音の一時停止・再開 |
| `Ctrl+\` | サイドバーを畳む・出す |
| [[Ctrl+Shift+L]] | ライトとダークを切り替える |
| [[Esc]] | 設定を閉じる（設定の検索の欄に文字があるときは、文字を消す） |
| [[Ctrl+Tab]]・[[Ctrl+Shift+Tab]] | 次・前のタブへ |
| `Ctrl+＋`・`Ctrl+－`・`Ctrl+0` | 拡大・縮小・元の大きさ（200% まで） |
