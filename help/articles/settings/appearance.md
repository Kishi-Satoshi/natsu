NaTsu の窓の配色を、明るい配色と暗い配色から選べます。

## 選ぶ {#choose}

1. サイドバーの ［設定］ を押します。設定は、今のページの上に開きます。
2. 左の列の ［一般］ を押します。
3. いちばん上の「外観」で選びます。選ぶとすぐ配色が変わり、そのまま保存されます。
4. 右上の × か [[Esc]] で設定を閉じます（[設定の画面の使い方](#settings-screen)）。

| 選ぶもの | 配色 |
| --- | --- |
| ［システム設定を使用］ | Windows の設定（明るい・暗い）に合わせます |
| ［ライト］ | いつも明るい配色 |
| ［ダーク］ | いつも暗い配色 |

外観は、この PC の NaTsu の見た目の設定です。

## キーで切り替える {#shortcut}

NaTsu の窓で [[Ctrl+Shift+L]] を押すと、ライトとダークを切り替えます。

- ［システム設定を使用］ のときは、今見えている配色の反対にします。
- 切り替えたものは「外観」の選択に残ります（次に起動しても同じ配色です）。

## 設定の画面の使い方 {#settings-screen}

［設定］ は、今のページの上に開く画面です（タブでは開きません）。

| 左の列の項目 | 中身 |
| --- | --- |
| ［アカウント］ | ログイン・ログアウト |
| ［一般］ | 外観・ホットキー・起動と終了（自動起動・トレイに残す・効果音） |
| ［録音］ | 録音バーの置き場所・マイクと相手の声・話し声が無いとき（自動で止める）・文字起こし・ユーザー辞書 |
| ［要約］ | 要約（Claude Code） |
| ［ローカル AI］ | PC の上で動く文字起こしの準備（任意） |
| ［更新］ | 更新の確認 |

- 前に選んだ項目は、NaTsu を閉じるまで覚えています（初めは「一般」）。
- どの設定も、説明は1行だけ出ます。くわしい説明は、名前や見出しの横の ⓘ を押すと出ます。もう一度 ⓘ を押すか、[[Esc]] を押すか、説明の外を押すと閉じます（説明が開いているときの [[Esc]] は、まず説明だけを閉じます）。
- 「※ 録音していることは、会議の参加者に伝えてください。」のような大事な注意は、ⓘ に入れず、いつも見えています。
- 説明の下の「ヘルプで詳しく見る ↗」を押すと、その話のヘルプの記事がブラウザで開きます。
- 左の列の上の「検索」の欄に設定の名前や説明の言葉（例: 「マイク」「ホットキー」「イヤホン」）を打つと、当たる設定だけが項目ごとに出ます。ⓘ の中の言葉で当たったときは、その ⓘ に薄い色が付きます。無いときは「当てはまる設定はありません」と出ます。欄で [[Esc]] を押すと、文字が消えて前の項目に戻ります。
- 閉じるときは、右上の × か [[Esc]] を押すか、設定の外の暗い所を押します。
- 左の列のいちばん下の ［ヘルプ］ を押すと、このヘルプセンターがブラウザで開きます。その下に、今の版（「NaTsu 0.9.2」のように）が出ます。
